# Project rules

- Use TypeScript. Keep rendering separate from deterministic game logic.
- The server is authoritative for multiplayer game state.
- Keep scenario content data-driven; do not hardcode story logic into UI components.
- Use 2D isometric visuals; do not use a 3D engine.
- Implement only the requested task; do not refactor unrelated modules.
- Prefer existing dependencies; ask before introducing major dependencies.
- Run relevant tests and build checks, and report results briefly.
- Do not add authentication, databases, AI services, or paid APIs without explicit approval.
- Keep player-facing text in Thai.
- Do not implement future phases early.
