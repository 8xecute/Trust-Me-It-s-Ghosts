# CASE 001 v5.2 — No Timer / Event-Driven Migration

**Source:** `CASE001_StoryScript_v5.1.2_Natural_Thai_Dialogue.md`
**Target:** `CASE001_StoryScript_v5.2_No_Timer_Event_Driven.md`

## สิ่งที่ยืนยันให้เลิกใช้

- ไม่ต้องมีนาฬิกาในเกม, ตัวนับนาที/จำนวนรอบการสืบสวน/Countdown หรือ Turn Limit
- ไม่เกิด `F6` หรือการตาย/ปรับสถานะพิธีจาก 03:00 / เวลาในเรื่อง
- เอา `TIME_MINUTES`, `RITUAL_0300_PRESTATE`, `RITUAL_0300_FULL_POWER`, `ritual_toll` ออกจากจุดที่ใช้เป็นเงื่อนไขใหม่
- `entrenched` ไม่ใช่สถานะที่เวลาในเรื่องสร้างได้อีก
- ใช้เหตุการณ์จริง (การแตะ/ตัดด้ายผิดวิธี หรือวิชัยมีโอกาสลงมือจริง) เพื่อกระตุ้น F6 แบบ **ทางเลือกและมีการเตือน**; ห้ามเพิ่มความตายอัตโนมัติ, Damage หรือ Check ใหม่
- ย้ายประวัติกฎเวลาเก่าออกจาก Active Script ไปเก็บเป็น Legacy Notes ต่างหาก

## ต้องคงไว้

- ความจริงคดีปี 2534 และวันเวลาในเอกสารเปิดประตู/อพยพ (หลักฐานสำคัญ)
- ฉาก 31 จุด, Dice Checks 16 จุดและ DC/Full/Partial/Failure ทั้งหมด
- การต่อสู้จริง, E5 Crossfire, F5 Execution Attempt, HP0 เฉพาะที่กติกาอนุญาต
- บุคลิก/บทสนทนา/หลักฐาน v5.1.2, กำไลเป็นแกนเดียว, Ending A–D

## Codex migration checklist

1. ตรวจ source code หาตำแหน่งอ้าง `TIME_MINUTES`, `RITUAL_0300`, `03:00`, `ritual_toll`, `entrenched`, time-skip event, countdown widget, timer-based scene selectors.
2. ปรับ State initializer/reducer ให้ไม่ผูกเวลาหรือสะสมเวลาสืบสวน และไม่ตั้งค่า deprecated ใน session ใหม่.
3. ปรับ Scene Router: F1 เมื่อทีมเข้าจัดการแกนจริง, F6 เฉพาะ action-trigger, F5 หลัง `RITUAL_STATUS=stopped`.
4. ปรับเงื่อนไข Dialogues ใน D2/E4/F1/F4/F6 ไม่ให้พูดว่าพิธีจะฆ่าใครเมื่อนาฬิกาถึงกำหนด.
5. ลบ trigger death=ritual_toll และ guard 03:00; อย่าลบการตายจาก E5/F5/Combat.
6. ไม่ลบ `H1_FLOOD_TIMELINE` หรือวันที่/เวลาในหลักฐานน้ำท่วม; มันคือประวัติศาสตร์ไม่ใช่ระบบจับเวลา.
7. ทดสอบทั้งหมด: ผู้เล่นคุยยาวโดยไม่ถูกลงโทษ, ข้าม F6 ได้, หยุดพิธีโดยไม่สู้, E5/F5 ยังทำงานตามตำแหน่ง, F6 ต้องมีการกระทำจริงและช่องโต้ตอบ, และ Ending A–D ไม่ตรวจตัวนับเวลา.
8. เก็บ compatibility สำหรับ Save เก่าหากมี แต่ไม่ให้ legacy time fields trigger ความตายในคดีที่เริ่มใหม่.

## Acceptance tests ตัวอย่าง

| สถานการณ์ | ต้องเกิด |
|---|---|
| สนทนาหรือสำรวจนานเท่าใดก็ได้ | ไม่มี Countdown, ไม่มี penalty, ไม่มี death จากเวลา |
| พาเพิ่มออกแล้วไม่ปลดสาย | เพิ่มยังถูกผูก แต่ไม่ตายเพราะนาฬิกา |
| ทีมใช้ลำดับปลดกำไลถูกต้อง | ไป F5 โดยไม่ต้องผ่าน F6 |
| ผู้เล่นลองกระชากแกนผิดวิธีหลังเตือน | F6 เปิดโอกาสตอบสนอง; ไม่มี scripted death |
| วิชัยหนีหรือถูกคุมตัวไปแล้ว | ไม่เกิด F6 จากวิชัยที่ไม่อยู่ และไม่เกิด F5 execution ระยะไกล |
| E5 Crossfire เกิดตามเงื่อนไขจริง | ความเสี่ยงถึงตายยังอยู่ |
| เอกสารปี 2534 สองชุดเทียบกันได้ | H1 ยังใช้ INT DC17 และผลทอยเดิม |
| พิธียังทำงานเมื่อทีมถอนตัว | Ending D ตามภัยค้าง ไม่ใช่ตามนาที |
