## 6 ส่วนที่อัปเดตแล้ว

1. **ลูปเข้าบท → สังเกต → สำรวจ/ถาม → ทอยเมื่อสมควร → สรุป → ยืนยันไปบทต่อไป**
2. **หัวข้อ Investigation Prompts** เกิดหลัง DM ให้เห็น cue และยังถามอิสระได้
3. **Main Path เดินหน้าเท่านั้น** A→B→C→D→E→Final; ไม่ย้อนบทเก่าเพื่อถามคนเดิม
4. **Missing Clue Forward Recovery** ผ่านหลักฐาน/พยานใหม่ข้างหน้า ไม่วาร์ป NPC ไปตามผู้เล่น
5. **ระบบคำใบ้ 3 ระดับ** ต่อบท: สะกิด / ชี้จุด / เสนอ Action
6. **สรุปสมุดคดีก่อนเปลี่ยนบท** รู้แล้ว/ยังสงสัย/เหตุผลไปต่อ; แสดงเฉพาะข้อมูลที่ได้รับจริง

## ความเปลี่ยนแปลงที่สำคัญ

- **เนื้อเรื่องและบทพูดหลักจาก v4.2 ยังอยู่ครบ** โดยนำ `[เชื่อมฉาก v4.2]` ที่อาจอนุญาตข้าม/ย้อนบทออก แล้วแทนด้วย `🧭 [v4.3 การนำฉาก]` ทั้ง 31 ฉาก
- **16 จุดทอยเดิม** เก็บ Full/Partial/Failure เป็นข้อความเดิม ไม่เพิ่มจุดที่ต้องทอยเพื่อเปิดทางหลัก
- **H1** ไม่ใช่ Phase ที่เดินทางกลับไปหา NPC: เป็นการวิเคราะห์หลักฐาน ณ จุดที่พบจริง; ประเสริฐสารภาพได้เฉพาะถ้าอยู่หรือมีช่องทางที่เชื่อได้
- E2 ช่วยคน / E4 ตรวจห้องพิธี ทำลำดับใดก่อนใน E ก็ได้; หากปิด E ทั้งที่ยังไม่ได้ช่วยคน ให้บันทึกผลจริง ไม่เพิ่ม `HOSTAGES_SAFE` ฟรี
- ไม่บังคับสู้ผีเงาจมน้ำ C, ไม่บังคับสู้แม่แก้ว D/Final และไม่เกิดวิชัย E5 เมื่อถูกจับไปก่อนแล้ว
- วันที่/เวลาในโลก 23:00–03:00 ไม่เท่ากับเวลาจริงหรือจำนวนคลิก; 03:00 เป็นกฎพิธีฝังแน่น ไม่ใช่ Game Over
