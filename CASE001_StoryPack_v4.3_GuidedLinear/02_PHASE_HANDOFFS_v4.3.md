# สคริปต์เปลี่ยนบทและสมุดคดี — CASE 001 v4.3

> ใช้เมื่อผู้เล่นเลือกจบบทปัจจุบันเท่านั้น (ไม่ตัดฉากทันทีเมื่อเข้าเงื่อนไข). เนื้อหา `รู้แล้ว` ต้องถูกกรองจาก Clue/Check/Dialogue ที่ผู้เล่นพบจริง อย่าแสดงข้อความในวงเล็บลับ

## UI ที่แนะนำตอนจบบท

1. **รู้แล้ว:** 2–4 ข้อจากหลักฐานและคำให้การที่ทีมมีจริง
2. **ยังสงสัย:** 1–3 คำถามจากสิ่งที่เห็นแต่ยังไม่ได้พิสูจน์
3. **เหตุผลที่ไปต่อ:** เหตุ/ตำแหน่งที่ได้จากเรื่อง ไม่ใช่บอกว่า “ต้องไปบท C”
4. **ตัดสินใจ:** `สำรวจต่อในบทนี้` / `ยืนยันเดินทางไปจุดหมายถัดไป` โดยแสดงคำเตือนว่าเมื่อออกแล้วจะไม่ย้อนกลับมาถาม NPC เดิม

## ตัวอย่างข้อความเชื่อมต่อแบบมีเงื่อนไข

### บท A → B

**เงื่อนไข:** ทีมเลือกเดินทางไปบ้านผู้ใหญ่และรู้ตำแหน่ง B1; ไม่ต้องผ่าน A2_RADIO_ECHO

**[DM อ่าน]**

> ประเสริฐพับรายชื่อคนหายแล้วเงยหน้ามองบ้านที่ยังเปิดไฟอยู่ท้ายถนน

**[NPC เฉพาะเมื่ออยู่ตรงนั้นจริง]** “ข้อมูลเวลาเห็นพวกเขาครั้งสุดท้ายกับแผนที่ทั้งหมดอยู่ที่บ้านผมครับ ไปดูด้วยกันเถอะ”

**[DM ลับ: ปรับตามสิ่งที่พบ]** ทุกคนรู้ว่าดล นิด เพิ่มหายและเอกสารอยู่ที่บ้านผู้ใหญ่; ไม่เผยเรื่องวิชัย

**คำถามให้ผู้เล่นคิดต่อ:** รู้ว่าคนหายสามคนคือใคร และทำไมต้องตรวจข้อมูลที่บ้านผู้ใหญ่

**Missing clue → ข้อมูลใหม่ข้างหน้า:**
- A2 วิทยุ: เรื่องร่องรอยน้ำจะถูกขยายจากบ้านดลและคำของยายบุญมี

---

### บท B → C

**เงื่อนไข:** รู้ LOCATION_C_KNOWN จากแผนที่ หรือประเสริฐบอกทาง; ทีมเลือกยืนยันออกเดินทาง

**[DM อ่าน]**

> บนแผนที่มีวงกลมล้อมชื่อดลและตรอกเล็กที่พาไปบ้านของเขา แฟ้มเอกสารปิดลง แต่คำถามเรื่องที่ดินยังค้างอยู่

**[NPC เฉพาะเมื่ออยู่ตรงนั้นจริง]** ประเสริฐ: “ดลเป็นคนจดทุกอย่าง ถ้าเขาตามเรื่องนี้อยู่ เขาน่าจะทิ้งเบาะแสไว้ที่โต๊ะทำงาน”

**[DM ลับ: ปรับตามสิ่งที่พบ]** ถ้า B3 full ให้ทีมสงสัยวิชัยมีส่วนขนของ; ถ้า B3 failure ให้ใช้ข้อสงสัยเรื่องดลและแฟ้ม ไม่ระบุความผิดของวิชัย

**คำถามให้ผู้เล่นคิดต่อ:** รู้ว่าดลกำลังติดตามเรื่องผิดปกติและมีเหตุผลไปค้นสมุดที่บ้าน

**Missing clue → ข้อมูลใหม่ข้างหน้า:**
- B3 ต้น: สมุดดล C2 ชี้รูปแบบที่ดิน และคำให้การ E3 ยืนยันการลักพาตัว
- B4 น้ำท่วม: ยายบุญมี C5 และเอกสาร E4/H1 ย้อนให้ข้อมูล

---

### บท C → D

**เงื่อนไข:** มี LOCATION_D_KNOWN จากสมุดหรือคำยาย และทีมเลือกมุ่งสวน; C4 เป็น optional

**[DM อ่าน]**

> ใต้หน้าท้ายของสมุดยังมีชื่อศาลสวนกล้วย ขณะที่คำเตือนของยายบุญมีเรื่องด้ายดำทำให้สวนดูไม่ใช่แค่ที่เกิดข่าวลือ

**[NPC เฉพาะเมื่ออยู่ตรงนั้นจริง]** ยายบุญมี (ถ้ายังอยู่ตรงนั้น): “เข้าไปให้เริ่มจากศาลก่อน แล้วถ้าเห็นอะไรผูกต้นกล้วย อย่าดึงมั่ว”

**[DM ลับ: ปรับตามสิ่งที่พบ]** ถ้าไม่ได้พบยาย ให้สมุดข้อความไปศาลเป็นเหตุให้ทีมไป D; ห้ามสร้างบทพูดยายทั้งที่ไม่ได้เจอ

**คำถามให้ผู้เล่นคิดต่อ:** เห็นความเกี่ยวข้องของด้ายดำกับสวนและเข้าใจว่าแม่แก้วมีอดีตที่เกี่ยวกับน้ำท่วม

**Missing clue → ข้อมูลใหม่ข้างหน้า:**
- C4 ไม่ได้ภาพจากผี: D2/D5 มีรอยพิธีและทางไปบ้านร้าง
- C5 ไม่ได้รู้วิชัยเป็นเด็กที่รอด: เอกสารอพยพ E4 และแม่แก้ว D3 ให้ข้อมูลตามสิ่งที่ตนรู้

---

### บท D → E

**เงื่อนไข:** LOCATION_E_KNOWN และทีมเลือกไป E1; D4 optional; D5 ไม่ล็อกด้วย PER

**[DM อ่าน]**

> หลังศาล รอยล้อรถเข็นตัดผ่านดินชื้นและเศษกระสอบที่ติดกิ่งกล้วย ปลายทางมีเรือนไม้หลังหนึ่งตั้งอยู่โดดเดี่ยว

**[NPC เฉพาะเมื่ออยู่ตรงนั้นจริง]** แม่แก้ว (เฉพาะเมื่อยังพูดคุยและอยู่ในพื้นที่): “คนที่เอ็งหาไม่ได้อยู่ที่ศาล... ระวังคนเป็นด้วย”

**[DM ลับ: ปรับตามสิ่งที่พบ]** ไม่ว่าทอย PER11 ผ่านหรือไม่ ทีมมองเห็นรอยทางและเลือกติดตามได้

**คำถามให้ผู้เล่นคิดต่อ:** รู้ว่าผีถูกผูกด้วยอาคมเดียวกัน และตามรอยคนเป็นที่ขนของไปเรือนไม้ได้

**Missing clue → ข้อมูลใหม่ข้างหน้า:**
- D3 เจรจาพลาด: คำให้การผู้รอดชีวิตและตำรา E4 ยืนยันการผูกวิญญาณ
- D2 อ่านพิธีไม่ออก: E4 มีตำราพิธีและกำไล

---

### บท E → FINAL

**เงื่อนไข:** ทีมยืนยันรับมือพิธีและความเสี่ยงที่เหลือ → F ตามสถานะจริง; ไม่บังคับว่าต้องซัก E3 หรือเผชิญ E5

**[DM อ่าน]**

> ด้ายทุกเส้นบนคานเริ่มกระตุกแรง ความร้อนจากกำไลทำให้เทียนลุกขึ้นพร้อมกัน เสียงแม่แก้วดังในห้องที่ทุกคนยืนอยู่

**[NPC เฉพาะเมื่ออยู่ตรงนั้นจริง]** แม่แก้ว (เฉพาะเมื่อพิธียังทำงาน): “เอาของข้าคืนมา...”

**[DM ลับ: ปรับตามสิ่งที่พบ]** หากหยุดพิธีก่อนแล้ว ใช้คำบรรยายความเงียบ/อิสระแทนการปะทุ และไม่ spawn Boss

**คำถามให้ผู้เล่นคิดต่อ:** ช่วยคนหายให้ปลอดภัย เจอแกนอาคม และมีแผนหยุดพิธีโดยไม่ต้องย้อนถามคนเก่า

**Missing clue → ข้อมูลใหม่ข้างหน้า:**
- ถ้าไม่คุยต้น/ยาย: คำให้การ E3 กับเอกสาร E4 ให้ข้อเท็จจริงที่ตนรองรับ
- ถ้า H1 ยังไม่พร้อม: สามารถแก้พิธีและจบคดีได้ แต่ความจริงน้ำท่วมอาจเปิดเผยไม่ครบ

---

### บท FINAL → ENDING

**เงื่อนไข:** ยุติวิกฤตหรือถอนตัว/หมดทางรับมือ และคำนวณ Ending จาก State

**[DM อ่าน]**

> เสียงใบกล้วยค่อย ๆ แผ่วลง หรือดังยิ่งขึ้นตามผลที่ทีมทำจริง ผู้รอดชีวิตและหลักฐานยังมีผลต่อความจริงที่จะถูกเล่าต่อหลังคืนนี้

**[NPC เฉพาะเมื่ออยู่ตรงนั้นจริง]** ไม่มีบทพูดบังคับ; ใช้ Ending A–D ตาม State จริง

**[DM ลับ: ปรับตามสิ่งที่พบ]** ไม่ให้ผู้เล่นเลือก Ending เอง; หากเวลา 03:00 แล้วแต่ยังแก้ได้ต้องยังเล่นต่อได้

**คำถามให้ผู้เล่นคิดต่อ:** หยุดพิธี ประคองความปลอดภัย และยุติภัยตามหลักฐานจริง

**Missing clue → ข้อมูลใหม่ข้างหน้า:**
- หากยังไม่ได้สารภาพประเสริฐ: เปิดเผยจากหลักฐานที่เก็บได้อย่างเหมาะสม ไม่วาร์ปเขามาในห้องพิธี
- หากไม่ได้พูดกับแม่แก้วใน D: ยังเจรจา F5 ได้ แต่ TRUST ไม่ได้โบนัสย้อนหลัง
