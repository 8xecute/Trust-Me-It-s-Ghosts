# บริษัท เรื่องผีไว้ใจผม จำกัด

**Trust Me, It’s Ghosts Co., Ltd.**

A Thai cooperative ghost-hunting browser game for 2–6 online investigators, with one human GM. The GM leads the team between illustrated scenes and answers player questions. The team resolves scripted D20 checks, and uses a grid during encounters.

## Development

Requires Node.js 20.19+ or 22.12+ and npm.

```sh
npm install
npm run dev
```

Open the Vite URL printed in the terminal (normally http://localhost:5173). The Socket.IO server listens on port 3001 by default. Set `PORT` for the server and `VITE_SERVER_URL` for the client if needed; restart the relevant process after changing them.

Set `VITE_SERVER_URL` to the public HTTPS server origin before running `npm run build`. Run `npm run typecheck` to check types and `npm start` to start the built server. For Render settings and production smoke tests, see [DEPLOYMENT.md](DEPLOYMENT.md).

## Structure

- `packages/client`: React shell, Phaser rendering, and Socket.IO client adapter.
- `packages/server`: Node.js Socket.IO connection boundary.
- `packages/shared`: framework-independent types, rules boundary, and scenario data.

Game rules and scenario data are independent of Phaser and networking. The shared package is built first and watched during development. Assets are deliberately minimal and generated by the placeholder renderer.

### CASE 001 ฉบับทดสอบ v4.0

ห้องโหมดเล่าเรื่องใช้บทและเงื่อนไขจาก Story Script v4.0 และอ้างอิงรหัสฉากกับหลักฐานจาก Story Flow v4.0 ข้อมูลเกมอยู่ใน [case-001.v4.json](packages/server/scenarios/case-001/case-001.v4.json) ผู้ดำเนินเรื่องเริ่มคดี พาทีมเปลี่ยนฉาก และจ่ายบทเล่ากับคำตอบผ่านคิว ผู้เล่นส่งคำถามหรือเสนอจุดหมายเป็นข้อความได้

Final ใช้ฉากเรือนไม้ร้างเดิม หลังหยุดพิธีจะกลับสู่บทสนทนาและทางเลือกจัดการแม่แก้ว หากทีมชนะการต่อสู้ในสวน จะเหลือจุดพันธนาการให้คลายน้อยลงใน Final โดยใช้ค่าพลังชีวิตจากระบบต่อสู้เดิม เมื่อตีสามขณะพิธียังทำงาน เกมใช้โทษความหลอนสูงสุดที่มีอยู่และให้ทีมเล่นต่อ

ข้อมูลชุดนี้ยังเป็นฉบับ Playtest ใช้ Story Script ต้นฉบับสำหรับบทด้นสดและจังหวะย่อยที่ยังไม่มีคำสั่งในเกม ระยะเวลารวมร่างและตัวเลข Combat Lite ต้องยืนยันแยกก่อนปรับกติกา

### CASE 001 v4.1 และการบันทึกห้อง

ห้องเนื้อเรื่องใหม่ใช้บท v4.1 และจุดทอยเสริม 16 รายการ คำขอแสดง Core Stat และ DC ก่อนส่งการ์ด ผลทอยและข้อความตามผลถูกส่งจากเซิร์ฟเวอร์ถึงทั้งทีม ส่วนบทเต็มและเงื่อนไขอยู่ในหน้า DM

ตั้ง `CASE_SAVE_DIR` เป็นโฟลเดอร์ส่วนตัวที่เซิร์ฟเวอร์เขียนได้ เพื่อบันทึกห้องเนื้อเรื่องหลังเริ่มคดีและโหลดอัตโนมัติเมื่อเปิดเซิร์ฟเวอร์ใหม่ ผู้เล่นรีเฟรชเพื่อกลับห้องเดิม หรือเปิดเบราว์เซอร์เดิมแล้วเลือก “เล่นคดีที่บันทึกไว้ต่อ” ไฟล์บันทึกมีข้อมูลลับของคดีและกุญแจกลับเข้าห้อง จึงต้องอยู่บนพื้นที่เก็บข้อมูลส่วนตัวและคงอยู่ข้ามการรีสตาร์ต ใช้โฟลเดอร์หนึ่งต่อเซิร์ฟเวอร์หนึ่งตัว หากไม่ตั้งค่า ห้องอยู่ในหน่วยความจำ
