# ฉากทดลอง: คืนแรกที่บ้านหนองตาล

- ส่งผู้เล่นเฉพาะ `player.html` หรือ `PLAYER-PACK.zip`
- DM อ่าน `DM-ONLY.md` ก่อนเล่น และเก็บไว้กับตัว
- เล่นผ่านเสียงประมาณ 10–15 นาที ไม่มีนาฬิกาบังคับในเกม
- หน้าเดียว: ภาพฉาก / สมุดส่วนตัว / ฟีดแบ็คหลังเล่น
- ใช้เบราว์เซอร์ ไม่ต้องติดตั้งหรือสมัคร ไม่มีการเชื่อมต่อเครือข่ายในไฟล์
- แต่ละคนมีสมุดของตนเอง ไม่ซิงก์กัน ผู้เล่นเลือกดาวน์โหลดฟีดแบ็คและส่งให้ DM
- ไม่ทดสอบ encounter รอบนี้ ยังไม่แก้เกมหลัก และไม่ใช้ผลจากฉากเดียวตัดสินระบบต่อสู้
- หากเปิด HTML บนมือถือไม่ได้ ให้ DM แชร์ภาพฉากผ่านสายสนทนาและให้ผู้เล่นจดเองได้ จดปัญหานี้แยกจากฟีดแบ็คเนื้อเรื่อง

ไฟล์ภาพฝังใน player.html แล้ว ไม่ต้องส่งโฟลเดอร์ภาพ คำตอบ/ความลับ NPC ไม่อยู่ในไฟล์ผู้เล่น

รอบทดลองฝั่ง DM: เปิด `DM-ONLY.html` บนเครื่อง DM เท่านั้น หน้าเดียวช่วยดูขอบเขตข้อมูลและทำเครื่องหมายว่าเล่าอะไรไปแล้ว อ่าน `DESIGN-DECISIONS.md` สำหรับโจทย์เก็บฟีดแบ็ครอบนี้ ไม่ส่งสองไฟล์นี้ให้ผู้เล่น
