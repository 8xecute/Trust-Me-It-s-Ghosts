# ผลตรวจชุดทดลอง A1

- ตรวจภาพหน้าเล่นบนเบราว์เซอร์ desktop แล้ว
- ทดสอบสมุดจริง: เพิ่ม แก้ไข เปลี่ยนประเภท ลบ คืนบันทึก และ reload แล้วยังอยู่ ผ่าน
- เปิดฟอร์มฟีดแบ็คจริงแล้ว การดาวน์โหลดจริงถูกขัดจังหวะเพราะเครื่องมือเบราว์เซอร์หยุดให้บริการ จึงยังไม่อ้างว่าดาวน์โหลดบนเบราว์เซอร์หรือมือถือผ่าน
- Unit harness ของสคริปต์: CRUD/undo/persistence, ข้อความไม่ถูกตีความเป็น HTML, JSON ฟีดแบ็ค, การแนบสมุดเฉพาะเมื่อยินยอม, กรณี storage ใช้ไม่ได้ ผ่าน
- ตรวจ source ของ player.html ไม่พบบทตอบ ชื่อ/วัตถุปมลับ และไม่มีคำสั่งส่งข้อมูลผ่านเครือข่าย
- ZIP มีไฟล์ player.html เพียงไฟล์เดียว ไม่มี DM-ONLY.md หรือเฉลย
- ยังไม่ได้ทดลองกับผู้เล่นจริง และยังไม่มีฟีดแบ็คจริง ห้ามใช้ข้อมูลทดสอบระบบแทนผลเล่น
- ยังไม่ได้ตรวจ mobile browser จริง การเปิดไฟล์ HTML ขึ้นกับแอปที่ผู้เล่นใช้ ให้ดาวน์โหลดแล้วเปิดด้วย browser หรือใช้แชร์หน้าจอเป็นทางรอง

สร้างไฟล์ส่งผู้เล่นใหม่: python artifacts/playtests/a1-rescue-first/build.py
ตรวจ script: node artifacts/playtests/a1-rescue-first/verify.mjs

ไม่แก้ source/runtime ของเกมหลัก ไม่ commit/push และไม่เปลี่ยนกติกา


## เพิ่มหน้า DM ตามลำดับปัญหา 2 → 3 → 1

สร้าง DM-ONLY.html โดยคง player.html/PLAYER-PACK.zip เดิม หน้า DM ใช้ข้อมูล A1 จริง 6 หัวข้อ ไม่รวมคำถามเงื่อนไขที่ชวนเฉลยปมก่อนเวลา

Unit harness ผ่าน: เปิดอ่านไม่ทำเครื่องหมายเอง, บันทึกเมื่อ DM ยืนยัน, ยกเลิกเครื่องหมาย, reload แล้วจำ, พิมพ์แผนไม่เท่ากับยืนยันแผน, export JSON, ไม่มี API เปลี่ยน State เกม และไม่มีหน้า DM ใน public preview หรือ ZIP ผู้เล่น

ยังไม่ได้ตรวจภาพ/คลิกหน้า DM ผ่านเบราว์เซอร์ เพราะเครื่องมือควบคุมเบราว์เซอร์ไม่พร้อมใช้งานในรอบนี้ และยังไม่มีผลการทดลองหน้า DM ใหม่นี้กับผู้เล่นจริง
