# ทิศทางหลังฟีดแบ็คฉาก A1

ผู้ใช้รายงานว่าผู้เล่นเข้าใจรายละเอียดและชอบภาพฉากใหญ่ จึงคง player.html และ PLAYER-PACK.zip เดิม ไม่เพิ่มข้อความหรือแผงควบคุมทับภาพ

ลำดับปัญหา DM ที่ผู้ใช้ยืนยัน:
1. ไม่แน่ใจว่าข้อมูลใดเปิดเผยได้ตอนนี้
2. ไม่แน่ใจว่าต้องกดบันทึกอะไรและเมื่อไร
3. นึกบทพูดหรือสวมบทไม่ต่อเนื่อง

สร้าง DM-ONLY.html สำหรับทดลอง A1 รอบต่อไป หน้าเดียวแสดงขอบเขตคำตอบก่อน รายการข้อมูลที่ DM เล่าแล้ว และสรุปแผนต่อของทีม ส่วนช่วยสวมบทเป็นข้อมูลรอง ไม่ทำระบบตอบอัตโนมัติหรือบังคับผู้เล่นเลือกคำถาม

ข้อมูลคำตอบมาจาก Runtime A1 โดยตรง ไม่เพิ่มผู้ต้องสงสัย หลักฐาน หรือค่า DC ช่องทำเครื่องหมายเป็นสมุดช่วยจำของ DM เท่านั้น ไม่ส่งข้อมูลให้ผู้เล่นและไม่เปลี่ยน State เกมหลัก

ทดสอบรอบต่อไปด้วยผู้เล่นกลุ่มเดิมและฉากเดิม โดยคงหน้าผู้เล่นและบทเปิด ใช้คู่มือ DM แบบหน้าเดียวแทนเอกสารยาว จดว่า DM ลังเลตรงไหน ต้องหยุดค้นข้อมูลเมื่อไร และยังเผลอบอกข้อมูลเกินขอบเขตหรือไม่ ฟีดแบ็คจากการเล่นฉากซ้ำอาจดีขึ้นเพราะจำบทได้ จึงไม่สรุปว่าเป็นผลจากหน้าใหม่ทั้งหมด

ไม่เพิ่ม encounter ใน A1 ไม่แทนที่ multiplayer และไม่ commit/push รอบนี้
