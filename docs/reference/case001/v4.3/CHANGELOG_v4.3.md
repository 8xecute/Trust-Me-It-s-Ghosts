# CHANGELOG — CASE 001 v4.3

## ปรับอะไรจาก v4.2

- เพิ่มการนำบทแบบ **Guided Linear Investigation** เดินหน้า A→B→C→D→E→Final โดยปิดบทเก่าเมื่อทีมยืนยันไปต่อ
- แทรก `🧭 [v4.3 การนำฉาก]` ใน Story Script ทุกฉาก 31/31: cue, prompts, guaranteed facts, optional check, bridge, fallback
- เพิ่ม DM Quick Playbook ที่อ่านเร็วกว่าไฟล์ Story Script ฉบับเต็ม รวมคำใบ้ 3 ระดับครบ 6 ช่วง
- เพิ่มสคริปต์ handoff และสมุดคดีที่สรุปเฉพาะความรู้ของผู้เล่น ไม่เฉลย DM Secret
- แทนที่การเชื่อมฉาก v4.2 ที่อนุญาตข้ามบท/ย้อนกลับด้วยเส้นนำทางเดินหน้าแบบใหม่
- แยกข้อมูลฉากสำหรับ Scripted DM เป็น JSON และอัปเดต StoryFlow ให้ใช้ GuidedScenes
- เพิ่ม checklist สำหรับการเล่นเส้นตรงและ multiplayer/save-load

## คงอะไรจาก v4.2

- ความจริงของคดี, การเปิดประตูผันน้ำปี 2534, วิชัยลักพาตัว 3 คน, แม่แก้วถูกผูกกำไลหนึ่งพิธี, ผีเงาจมน้ำเป็น Tutorial เท่านั้น
- บทพูดเดิม DM Read-Aloud และบทพูดเงื่อนไข, Check Full/Partial/Failure ทั้ง 16 จุด, Ending A–D
- Combat Lite v1.1 และ Universal Rules v1.3 ไม่ถูกเขียนทับ
