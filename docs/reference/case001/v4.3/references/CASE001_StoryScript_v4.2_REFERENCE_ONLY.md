## 0. จุดประสงค์และแนวทางการใช้งาน

เอกสารนี้มีทั้งข้อความที่ DM สามารถอ่านให้ผู้เล่นฟัง บทพูด NPC ที่ต้องเกิดตามเหตุการณ์ คำตอบแบบแตกแขนงตาม Action ของผู้เล่น ความจริงลับสำหรับ DM และเงื่อนไขเปลี่ยนฉาก ผู้พัฒนาสามารถนำไปแยกเป็นข้อมูลเชิงโครงสร้างภายหลังได้

**รูปแบบข้อความ**

- `[DM อ่าน]` = ข้อความเล่าให้ผู้เล่นฟัง; ไม่ใช่คำพูด NPC
- `[NPC พูดหลัก]` = บทพูดที่ควรเกิดเมื่อพบ NPC/เข้า Trigger นั้น ไม่ต้องรอผู้เล่นถาม
- `[หากผู้เล่น...]` = ประโยคทางเลือกเมื่อมี Action/คำถาม/หลักฐานตามเงื่อนไข
- `[DM ลับ]` = ห้ามแสดงแก่ผู้เล่นจนกว่าจะค้นพบด้วยการกระทำหรือหลักฐาน
- `[Trigger]` = เงื่อนไขเริ่มฉากหรือปลดล็อกคำพูด
- `[ผลต่อสถานะ]` = การเปลี่ยนสถานะที่มีผลในฉากหลัง ๆ

**หลักการ**: เดินเรื่องหลัก A → B → C → D → E → Final แต่ในแต่ละบทผู้เล่นเลือกวิธีสำรวจ/ถาม/สู้/ถอยได้ ควรเปิดโอกาสให้พบ NPC หลัก ไม่บังคับให้พูดคำตอบใดจึงจะผ่านฉากได้ ห้ามให้ NPC พูดข้อมูลที่ตนไม่รู้ และห้าม Spawn ตัวละครผิดตำแหน่งเพียงเพื่อรักษาฉากที่เขียนไว้

**สิ่งที่ปรับจาก v2.2**: แม่แก้วช่วย **วิชัยคนเดียว** จากน้ำท่วมปี 2534; เหตุการณ์ประตูน้ำใช้ **การเปิดประตูผันน้ำ** (ไม่ใช่ปิด); เหลือ **พิธีผูกวิญญาณเพียงพิธีเดียว**; ศัตรูผีตัวเล็กระหว่างทางมี **ผีเงาจมน้ำตัวเดียวที่ C**; แม่แก้วเป็น Final Boss แต่ผู้เล่นโจมตีได้ตั้งแต่ D และหากร่างสลาย จะฟื้นใหม่ชั่วคราวตราบใดที่ต้นเหตุยังคงอยู่; คนหายทั้งสามยังมีชีวิต ณ เปิดเกม; มี **4 Ending หลัก**

### 0.1 แกนความจริงที่ DM ต้องรู้ล่วงหน้า — ห้ามเปิดเผยทีเดียว

- ในปี **2534** มีน้ำท่วมใหญ่ ฝ่ายบริหารหมู่บ้านตัดสินใจ **เปิดประตูผันน้ำ** เข้าพื้นที่เกษตรเพื่อปกป้องชุมชนส่วนใหญ่ โดยยังไม่ยืนยันการอพยพครบ ประเสริฐอายุ 23 ปีมีส่วนช่วยดำเนินการ แต่ไม่ได้ตัดสินใจคนเดียว และภายหลังร่วมปกปิดความผิดพลาด
- **ยายบุญมี** (ปัจจุบันประมาณ 75 ปี) เคยช่วยงานศูนย์อพยพ เธอรู้ว่าเด็กชาย **วิชัยอายุ 10 ปี** ยังติดในสวน จึงมีส่วนทำให้ข่าวไปถึงแม่แก้ว แต่ไม่ได้เห็นเหตุการณ์ทุกส่วนด้วยตนเอง
- **แม่แก้ว** อายุ 26 ปี กลับไปช่วยวิชัย เธอพาเขาข้ามสะพานไม้ไปยังคันดินสูงได้ เด็กถึงที่ปลอดภัยก่อน แต่สะพานที่ถูกน้ำกัดเซาะทรุดพังในขณะที่แม่แก้วยังอยู่บนนั้น เธอถูกน้ำพัดและเสียชีวิต ต่อมาวิญญาณผูกพันกับสวนกล้วยเป็น **นางตานี**
- ปัจจุบัน **วิชัยอายุ 45 ปี** เป็นผู้ช่วยผู้ใหญ่บ้าน มีหนี้สินและหวังผลจากราคาที่ดิน เขาเข้าหาแม่แก้วโดยอ้างว่าจะช่วยเปิดเผยความจริงในอดีต แม่แก้วจำวิชัยได้และยอมให้เขาใกล้ชิด/ร่วมสร้างความกลัวในบางระดับ **โดยไม่ได้ยินยอมต่อพิธีควบคุม**
- วิชัยขโมย **กำไลทองเหลือง** ของแม่แก้วไปทำ **พิธีผูกวิญญาณเพียงชุดเดียว** ที่เรือนไม้ร้าง โดยใช้ด้ายดำส่งพลังไปยังศาลและต้นกล้วย การควบคุมบังคับพฤติกรรม/ขัดขวางการพูดบางเรื่อง แต่ไม่ลบความคิดและความทรงจำของเธอ
- วิชัยจับ **ดล นิด เพิ่ม** ซึ่งเจอหลักฐานคนละด้านไปขังในเรือนไม้ร้างเพื่อปิดปาก ยังมีชีวิตเมื่อเกมเริ่ม ผีเงาจมน้ำที่ C **ไม่ได้จับใครไป** แต่เป็นเศษพลังอาฆาตและความทรงจำที่ถูกรบกวนโดยพิธี จึงทำหน้าที่เป็น Red Herring และ Tutorial Combat
- **03:00** เป็นเส้นตายที่อำนาจผูกวิญญาณจะฝังแน่น การเลยเวลาไม่ได้ฆ่าตัวประกันโดยอัตโนมัติ แต่ทำให้หยุดพิธียากขึ้น หากวิชัยถูกจับก่อนพิธีหยุด พิธียังคงทำงาน
- การทำลายร่างปรากฏแม่แก้ว **ไม่ทำให้วิญญาณตาย** เธอกลับได้เมื่อพลังรวมตัวใหม่ การหยุดพิธีทำให้วิชัยบังคับเธอไม่ได้แล้ว แต่ความโกรธของเธอยังต้องได้รับการจัดการ
- ปริศนา **CASE 017**: ตำราที่วิชัยได้มาจากคนกลางลึกลับ อาจมีตรา/เครื่องหมายเชื่อมคดีถัดไป ไม่ต้องเฉลยผู้บงการใน Case 001

## กติกา Dice-Integrated Dialogue v4.2 (อ่านก่อนเล่น)

**นี่เป็นชั้นสคริปต์ที่เพิ่มเข้าไปในเนื้อเรื่อง v4.0 ไม่ใช่พล็อตใหม่**: ทุกฉากมีบทพูดหลักและข้อความตามคำถามเดิมอยู่ครบ ส่วน Check ที่มีป้าย `[ทอยเต๋า — ...]` จะเกิด **เฉพาะเมื่อผู้เล่นเลือกทำ Action ตาม Trigger** ไม่ใช่บังคับทอยทันทีเมื่อเข้าฉาก

- สูตร: `D20 + BODY/PER/INT/SOC/SPI/RES ที่ตรงกับวิธีลงมือ + situational bonus` เทียบ `DC 11/14/17` ตามรายการ; ไม่มี Skill/Proficiency และไม่บวก Stat Modifier ซ้ำ
- **Full**: คะแนนรวม `>= DC`; **Partial**: ต่ำกว่า DC `1–3`; **Failure**: ต่ำกว่า DC ตั้งแต่ `4` ขึ้นไป. การทอย 1 หรือ 20 บนหน้าเต๋า **ไม่ใช่** auto fail/success ใน Prototype
- **บทพูดที่รับรองไว้ใน v4.0 ยังได้รับตามเดิม** เมื่อถามถูกคนและ NPC ยอมเล่า; ผลเต๋าไม่ลบข้อความที่ได้ฟังไปแล้ว ไม่ทำให้ NPC รู้เรื่องที่ไม่เคยรู้ และไม่สร้างหลักฐานใหม่ที่ไม่อยู่ในฉาก
- ถ้าผู้เล่นเลือกวิธีที่ให้ผลแน่นอนอย่างสมเหตุสมผล เช่น แสดงหลักฐานจริงให้ประเสริฐ หรือคุยต้นตามลำพังพร้อมความปลอดภัยที่น่าเชื่อถือ ให้ใช้ **Bypass** ของ Check นั้น ไม่ต้องทอย. ค่าสูงไม่ได้บังคับให้ผีเปิดเผยชื่อผู้ควบคุมที่พิธีห้ามไว้
- `Full / Partial / Failure` เป็น **ระดับผลการพยายามนั้น** ไม่ใช่ข้อสรุปว่าผู้เล่นตีความถูกเสมอ; คำโกหกของ NPC และภาพสะท้อนของผีอาจไม่สมบูรณ์ตามเจตนาเดิม
- ไม่มีการทอยซ้ำแบบเดิมไม่จำกัด: อนุญาตเมื่อมี **หลักฐานใหม่ วิธีใหม่ ความช่วยเหลือใหม่ หรือสถานการณ์เปลี่ยน**; บันทึก Check ตาม ID และผลเดิม
- นอก Combat ไม่คิด AP สำหรับการถามหรือหยิบสิ่งของทั่วไป; ใน Combat ใช้ AP/Focus ตามท่าและ Combat Lite v1.1 (ห้ามบวกต้นทุน AP ซ้ำ)
- สถานะเรื่องเล่าเดิมยังเป็นแหล่งความจริงหลัก เช่น `TON_TRUST`, `FLOOD_TRUTH`, `KAEW_TRUST`, `RITUAL_STATUS`, `WICHAI_STATUS`. บันทึก `CHECK_RESULTS` และระดับความเข้าใจเพิ่ม โดย **ห้ามลดระดับข้อมูลจาก FULL เป็น PARTIAL** หากรู้แล้ว
- **ข้อมูลวิกฤตไม่ถูกล็อกด้วยการทอยเดียว**: ชื่อคนหาย, สมุดดลเมื่อค้นถูกจุด, ชื่อสามคนบนด้าย, ทางไปเรือนไม้, วิชัยเป็นผู้ลักพาตัวจากพยานที่ปลอดภัย, กำไลเป็นแกนพิธี. การทอยใช้เพื่อความลึก ความเร็ว ความปลอดภัย และวิธีแก้ที่ดีกว่า

### A2 — วิทยุบริษัทส่งเสียง (เหตุการณ์บรรยากาศ)

#### 🎲 [ทอยเต๋า — A2_RADIO_ECHO] แยกเสียงวิญญาณจากคลื่นรบกวน

**PARTIAL SUCCESS — คะแนนรวม 11–13**

**FAILURE — คะแนนรวมไม่เกิน 10**

- **[DM อ่าน]** คุณปรับคลื่นและตั้งใจฟังซ้ำ แต่สัญญาณหายไปแล้ว ไม่มีอะไรยืนยันได้มากกว่าที่ทุกคนได้ยิน

### D3 — แม่แก้วปรากฏตัว

**[Trigger]** ตรวจศาลหรือแสดงตัวในอาณาเขตพอให้เธอรู้

**[DM อ่าน]**

> ลมเงียบสนิท ใบกล้วยทุกต้นหยุดพร้อมกัน หญิงสาวชุดเขียวยืนอยู่หลังศาล เส้นผมดำยาวและสีหน้าเคร่งเครียด เธอไม่เข้ามาใกล้ เพียงเอ่ยถาม

**[แม่แก้ว พูดหลัก]** “พวกเอ็งเป็นใคร? เข้ามาในสวนข้าทำไม? มาหาคน... หรือมาหาของ?”

**[ตอบสนอง]**

- **แนะนำตัว/ตามหาคน:** “คนที่หาย... ข้าได้ยินเสียงพวกเขา แต่พวกเขาไม่ได้อยู่ที่นี่ มีบางอย่างเอาพวกเขาไปซ่อน”
- **ถามว่าเธอจับคนไหม:** “ข้าไม่ได้พาพวกเขาไป ข้าเคยทำให้พวกเขากลัว... ข้าไม่ปฏิเสธ แต่ข้าไม่ได้ขังใคร”
- **ถามทำไมหลอกคน:** “คนเป็นลืมง่าย บางคนเลือกจะลืมทั้งที่จำได้ ข้าอยากให้กลัวพอที่จะหยุดฟัง แต่ไม่อยากให้ใครต้องตาย”
- **ถามด้ายดำ:** “อย่าแตะมัน! มันดึงข้าไว้ ข้าขยับได้ แต่เลือกไม่ได้ทุกครั้ง บางคืนข้าได้ยินตัวเองกรีดร้องทั้งที่ไม่อยากกรีดร้อง”
- **ถามว่าใครควบคุม:** “คนที่เอาของข้าไป... มันอยู่... ที่...” → ด้ายดำกระชากข้อมือจนเธอพูดต่อไม่ได้
- **ถามชี้ตรงวิชัย:** “วิชัย... ข้ารู้จักชื่อนั้นดี ข้า...” → ด้ายกระตุก เธอพูดชื่อผู้ควบคุมเชิงกล่าวหาไม่ได้ ไม่ใช่แกล้งจำไม่ได้

- **บอกยายบุญมีฝากขอโทษ:** “บุญมี... นางยังอยู่หรือ? ข้าไม่ได้โกรธที่นางรอด ข้าโกรธที่คนรอดบางคนทำเหมือนไม่มีอะไรเกิดขึ้น” → ความไว้วางใจเพิ่ม
- **บอกว่าจะช่วย:** “ทุกคนบอกว่าจะช่วย แล้วข้าจะรู้ได้อย่างไรว่าพวกเอ็งไม่โกหก?”
- **ขู่ว่าจะปราบ:** “ข้าเคยถูกคนเป็นตัดสินแทนมาแล้ว ถ้าพวกเอ็งจะทำเหมือนกัน... ก็เข้ามา”

- **[ผลต่อสถานะ]** CHECK_RESULTS.E3_HOSTAGES_ORDER=failure

### E4 — ห้องพิธีและกำไล

**[Trigger]** ตรวจห้องชั้นบน

**[DM อ่าน]**

> ห้องสุดท้ายมีวงผงสีดำ ด้ายดำพาดตามคานมารวมบนโต๊ะไม้ กล่องไม้ใบเล็กเปิดออกเผยกำไลทองเหลืองเก่าซึ่งสลักคำว่า “แก้ว” เส้นด้ายทั้งหมดสั่นเป็นจังหวะเหมือนหัวใจของบางสิ่งกำลังเต้นอยู่

**[ตรวจอาคม/อ่านตำรา — ข้อเท็จจริงพื้นฐาน]** “กำไลเป็นแกนของพิธีผูกวิญญาณ ด้ายทั้งหมดเป็นเส้นส่งอำนาจจากพิธีเดียว ถ้าหยุดอาคมกำไลได้ ผู้ทำพิธีจะบังคับแม่แก้วไม่ได้อีก แต่ไม่ได้หมายความว่าวิญญาณจะสงบตามไปด้วย” เมื่อทีมพยายาม **อ่านวิธีปลดอาคมอย่างปลอดภัย** ให้ใช้ **Check E4_BRACELET_DECODE** ด้านล่าง

**เอกสารในห้อง:** แผนการซื้อขายที่ดิน; บันทึกกำไล/วิธีผูกวิญญาณ; บันทึกเก่าเรื่องเปิดประตูผันน้ำ (ถ้าทีมยังไม่พบที่อื่น); ตราตำราลึกลับเป็น Easter egg CASE 017



#### 🎲 [ทอยเต๋า — E4_BRACELET_DECODE] อ่านขั้นตอนปลดแกนกำไลอย่างปลอดภัย

**เรียกทอยเมื่อ:** เมื่อผู้เล่นอ่านตำราหรือวิเคราะห์วิธีคลายพิธีที่กำไล หลังเห็นกำไลและด้ายบนโต๊ะแล้ว

**ค่าสถานะ:** `INT` · **DC 14** · **ไม่ต้องทอยเมื่อ:** เพียงพบกำไล/อ่านชื่อบนกำไล/เก็บเอกสาร ไม่มีการทอย; ไม่ให้ผล Failure ทำให้กำไลหายไป

**ข้อมูลที่ได้แน่ ๆ:** กำไลสลัก “แก้ว” และเส้นด้ายดำรวมที่โต๊ะ; เมื่อค้นเอกสารและตรวจเชื่อมโยงได้ ผู้เล่นรู้ว่ากำไลเป็นแกนที่ต้องจัดการ แต่การหยุดพิธีไม่ได้ทำให้ผีสงบอัตโนมัติ

**FULL SUCCESS — คะแนนรวมตั้งแต่ 14 ขึ้นไป**

- **[DM อ่าน]** เมื่อเทียบภาพในตำรากับการพันด้าย คุณเรียงลำดับการคลายแกนได้: ป้องกันแรงสะท้อน แยกเส้นผูกจากกำไล แล้วหยุดวงบังคับโดยไม่ทำให้วิญญาณรับผลสะท้อนรุนแรง

- **[บทพูด / เสียง]** หากแม่แก้วสื่อสารได้: “อย่าให้ด้ายนั่นกลับมารัดข้าอีก...”

- **ข้อมูล:** วิธีลดความเสี่ยงระหว่างหยุดพิธี; พิธีเดียวเชื่อมศาลกับกำไล

- **[ผลต่อสถานะ]** CHECK_RESULTS.E4_BRACELET_DECODE=full; RITUAL_PLAN=prepared (แนวทางใหม่; ไม่เปลี่ยน RITUAL_STATUS จนหยุดจริง)

**PARTIAL SUCCESS — คะแนนรวม 11–13**

- **[DM อ่าน]** คุณพบจุดที่ต้องตัดพลังบนกำไลแล้ว แต่ยังอ่านวิธีรับแรงสะท้อนไม่ครบ

- **[บทพูด / เสียง]** ถ้าวิชัยอยู่ใกล้: “พวกคุณคิดว่าตัดเส้นเดียวแล้วมันจะจบเหรอ?”

- **ข้อมูล:** กำไลเป็นแกนควบคุม; รู้ทางแก้ขั้นพื้นฐานแต่ไม่ครบข้อระวัง

- **[ผลต่อสถานะ]** CHECK_RESULTS.E4_BRACELET_DECODE=partial; RITUAL_PLAN=basic

**FAILURE — คะแนนรวมไม่เกิน 10**

- **[DM อ่าน]** ภาพในตำราและการพันเส้นด้ายไม่ตรงกับสิ่งที่คุณคาด คุณยังยืนยันกำไลเป็นแกนได้ แต่ยังไม่มั่นใจวิธีหยุดอย่างปลอดภัย

- **[บทพูด / เสียง]** หากวิชัยอยู่: “อย่าแตะมันมั่ว ๆ! พวกคุณจะทำให้แย่ลง”

- **ข้อมูล:** รู้กำไลเป็นแกนจากหลักฐานฉาก; ยังไม่รู้วิธีที่ปลอดภัย

- **[ผลต่อสถานะ]** CHECK_RESULTS.E4_BRACELET_DECODE=failure; RITUAL_PLAN=unknown หากยังไม่มีแผนจากแหล่งอื่น

**ถ้าทอยพลาดแล้วไปต่ออย่างไร:** การทดลองระหว่าง Final, การช่วยของหมอพิธี, ข้อมูลจากด้ายที่ D2 หรือความร่วมมือของวิชัยยังเปิดทางหยุดพิธีได้; อย่าปิดทางเลือกเพราะทอยต่ำ

### E5 — เผชิญหน้าวิชัย (เฉพาะเมื่อเดินทางมาถึงจริง)

> แสงเช้ามาถึงถนนดินแดง หมู่บ้านเริ่มมีคนออกจากบ้าน แต่คำถามยังไม่มีคำตอบ ผู้รอดชีวิตบางคนไม่กล้าพูดเรื่องเมื่อคืน และชื่อวิชัยยังถูกพูดถึงด้วยเสียงกระซิบ

**[ต้น หากยังอยู่]** “ผมน่าจะพูดเร็วกว่านี้ ถ้าผมไม่กลัว บางทีเรื่องอาจไม่หนักขนาดนี้”

**[ยายบุญมี]** “อย่างน้อยพวกเอ็งก็ทำให้บางคนกลับบ้านได้ แต่เรื่องที่เหลือยังรอคนกล้าพูดอยู่”

**[แม่แก้ว หากสื่อสารได้]** “ข้าไม่รู้ว่าจะต้องรออีกนานเท่าไร แต่คราวนี้อย่างน้อยก็มีคนเริ่มถามแล้ว”

**[สะพานบทสรุป v4.2 — ENDING_C]**

**[ใช้เมื่อ]** หยุดภัยหลักได้ แต่ช่วยหรือพิสูจน์คดีไม่ครบ

> รายงานบริษัทมีช่องที่ต้องเขียนว่า “รอตรวจสอบเพิ่มเติม” สิ่งที่ทีมช่วยได้ถูกบันทึกอย่างตรงไปตรงมา บางหน้าถูกทำเครื่องหมายว่ายังต้องติดตาม คนในหมู่บ้านรู้แล้วว่าคำตอบไม่ได้อยู่ที่ผีเพียงอย่างเดียว

**[DM ลับ]** ระบุ modifier จริง เช่น 2/3 คน วิชัยหนี หรือหลักฐานไม่พอ

### ENDING D — หมู่บ้านต้องสาป

**เงื่อนไขหลัก:** ทีมสิ้นสุดภารกิจ/ถอนตัวโดยที่พิธียังเป็นภัยและควบคุมสถานการณ์ไม่ได้

**[DM อ่าน]**

> ตีสามผ่านไป เสียงผู้หญิงร้องจากสวนกล้วยดังทั่วหมู่บ้าน ใบกล้วยเริ่มงอกตามรอยแตกถนน ประตูบ้านปิดพร้อมกัน เงาหญิงชุดเขียวปรากฏที่ทางเข้าสวน ไม่มีใครรู้ว่าเธอจะหยุดตรงไหน

**[ประเสริฐ หากยังอยู่]** “เราเรียกพวกคุณมาเพราะคิดว่าจะช่วยได้... แต่ตอนนี้ผมไม่รู้แล้วว่าจะพาคนไปที่ไหน”

**[แม่แก้วที่ยังถูกควบคุม]** “อย่า... ออก... ไป... คำสั่งยังอยู่... ข้ายังไปไหนไม่ได้...”

**[รายงานบริษัท]** “ภารกิจ BS-001 — สถานะ: ไม่สามารถปิดคดีได้ แนะนำให้ยกระดับหมู่บ้านหนองตาลเป็นเขตเฝ้าระวังเหนือธรรมชาติ รายงานผู้สูญหายตามจำนวนที่ยืนยันได้จริง”

**[สะพานบทสรุป v4.2 — ENDING_D]**

**[ใช้เมื่อ]** ทีมสิ้นสุดภารกิจทั้งที่พิธียังเป็นภัยและไม่มีทางควบคุมที่เลือกใช้ได้

> เมื่อภารกิจสิ้นสุดลงทั้งที่ภัยยังไม่ได้รับการควบคุม เสียงจากสวนกล้วยยังดังข้ามรั้วบ้าน ผู้ใหญ่บ้านต้องแจ้งเตือนคนที่เหลือ โดยไม่มีใครรับประกันได้ว่ารุ่งเช้าจะปลอดภัย แต่คนหายไม่ได้ตายเพราะแค่ถึงเวลาตีสาม

**[DM ลับ]** ยังบันทึกสภาพคนหาย วิชัย และแม่แก้วตามจริง ไม่สรุปว่าทุกคนเสียชีวิต

### Ending Resolver (ตรวจตามลำดับ)

1. ถ้าพิธียังเป็นภัยและทีมไม่สามารถควบคุมได้ → **D**
2. ถ้าหยุดภัยได้ แต่คนหายไม่ปลอดภัยครบ/ไม่มีหลักฐานคดีปัจจุบันที่ใช้ต่อได้/วิชัยหลุดรอดจนคดีไม่สมบูรณ์ → **C**
3. ถ้าหยุดพิธี คนหายปลอดภัยครบ คดีปัจจุบันคลี่คลาย แต่แม่แก้วยังเป็นภัยหรือถูกสะกดแทนการยุติ → **B**
4. ถ้าหยุดพิธี คนหายครบ หลักฐานเอาผิดวิชัยและเปิดเผยอดีตพร้อม และแม่แก้วยุติภัยโดยสมัครใจ → **A**

> กรณีที่ผลผสมกันและไม่เข้าเงื่อนไขตรง ๆ ให้ DM อิงข้อเท็จจริงของคดีและบันทึก **Ending + Modifiers** (เช่น วิชัยหนี, ช่วยได้ 2/3, แม่แก้วยังอยู่) แทนการตัดรายละเอียดทิ้ง

### 7.3 กฎกันเรื่องขัดแย้ง

1. ไม่เปิดความลับเพียงเพราะผู้เล่นพิมพ์ชื่อถูก NPC ต้องรู้เรื่องและยอมพูดได้จริง
2. ถ้าต้นถูกขู่จนนิ่ง เกมยังต้องมีเบาะแสจากสมุดดล
3. ถ้าผีเงาจมน้ำไม่ให้ข้อมูล เกมยังต้องไป D ได้
4. ถ้ายายบอกชื่อวิชัยตั้งแต่ C ไม่ห้าม: หักมุม E ยังเหลือเรื่องพิธี/การลักพาตัว/แรงจูงใจ
5. ถ้าสู้แม่แก้วที่ D จนร่างสลาย ต้องบอกอย่างมีนัยว่าพลังยังคงอยู่ และมีผลกับ Final จริง
6. ถ้าวิชัยถูกจับ/ตายก่อน E อย่าให้โผล่ผิดตำแหน่ง พิธียังทำงานเอง
7. ถ้าช่วยผู้สูญหายออกจากห้อง แต่ยังอยู่ในจุดอันตราย อย่านับว่า `HOSTAGES_SAFE=3`
8. เวลาใกล้ 03:00 ต้องเกิดจากการกระทำจริง ไม่เร่งตามลำดับฉากโดยไม่มีเหตุ
9. ถ้าพิธีหยุดก่อนบอส อย่าบังคับ Combat เพื่อให้ครบบท ให้ Final Confrontation กับแม่แก้วตามสถานะจริง
10. ไม่มีวิญญาณตัวอื่นให้ต่อสู้นอกจากผีเงาจมน้ำใน C และแม่แก้วตามสถานการณ์

## ภาคผนวก v4.1 — สิ่งที่ไม่ควรเข้าใจผิดเมื่อพัฒนาบทพูดใน Codex

1. **Check ทั้ง 16 ตัวเป็น optional triggers**: ไม่ได้บังคับให้ผู้เล่นทอยครบ; การตรวจเบาะแสหรือถามตรง ๆ ที่ให้ข้อมูลแน่นอนให้ผ่านด้วยการบรรยาย/บทพูดแทน
2. **สถานะ `CHECK_RESULTS` เก็บผลการพยายาม**; อย่าใช้แทนสถานะข้อเท็จจริง (`SUSPECT_WICHAI`, `FLOOD_TRUTH`, `HOSTAGES_SAFE`) และอย่าล้างข้อมูลที่ผู้เล่นได้จากวิธีอื่น
3. **อาจใช้ Full อย่างอื่นแทนได้** เมื่อทีมช่วยคนหายเรียบร้อยและยืนยันจากพยานโดยตรง หรือมีหลักฐานเต็มสำหรับ H1/F5 ไม่ต้องทอยเพื่อให้ NPC บอกความจริงซ้ำ
4. **ข้อกำหนดทีม**: นักศึกษาฝึกงานช่วยทอย +2 ตามท่า; นักสืบมีความสามารถค้นรายละเอียดอัตโนมัติหนึ่งอย่างตามข้อจำกัด; หมอพิธีอ่านประเภทอาคมแบบ Passive; ร่างทรงติดต่อผี; ห้ามเปลี่ยนระบบนี้เป็น Skill Tree
5. **`RITUAL_PLAN` และ `WICHAI_COOPERATING` เป็นข้อเสนอ State ใหม่** ใน Check v4.1 ไม่ใช่การเปลี่ยนเรื่องเดิม หาก Codex ใช้ชื่อ State อื่นอยู่ให้ map ทีหลัง โดยคงความหมาย
6. การสู้ C4, D4 และ F3–F4 ใช้ **Combat Lite v1.1**; อย่าใช้ Partial Success ของการสืบสวนกับ Attack Roll. พิธีหยุดเมื่อทีมลงมือสำเร็จจริง ไม่ใช่เพราะได้ข้อมูลจาก E4
7. **เนื้อเรื่องปี 2534** เป็นการ **เปิดประตูผันน้ำ**; ประเสริฐมีส่วนร่วมแต่ไม่ใช่ผู้สั่งคนเดียว; แม่แก้วช่วยวิชัยคนเดียว; วิชัยลักพาตัวผู้สูญหายทั้งสาม; ไม่มีผีเล็กตัวที่สอง
8. ข้อความใน Check เป็นบทอ่านของ DM และ NPC *เพิ่ม* สำหรับใช้แทนบทสนองแบบทั่วไปเมื่อ trigger ตรงกัน ไม่ใช่คำสั่งให้ Scripted DM พูดทุกผลลัพธ์ให้ผู้เล่นพร้อมกัน
