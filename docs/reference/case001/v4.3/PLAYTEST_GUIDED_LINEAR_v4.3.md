- [ ] แม่แก้วไม่กล่าวชื่อคนควบคุมตรง ๆ ใน D แม้ SPI Full ถ้ายังถูกผูก

- [ ] ใน E1 ขึ้นชั้นบน E4 ก่อนช่วย E2 ได้ และยังมีทางกลับไปช่วยใน **บท E ปัจจุบัน**
- [ ] ช่วยคนไม่ครบ ไม่เพิ่ม `HOSTAGES_SAFE` ฟรีเมื่อเข้า Final
- [ ] วิชัยไม่อยู่ใน E5 หากถูกจับ/ตาย/หนีอย่างมีเหตุผลในบทก่อนหน้า
- [ ] H1 เปิดจากหลักฐานที่ผู้เล่นมีจริง; ถ้าประเสริฐไม่อยู่ ไม่มีบทสารภาพต่อหน้าใน E

- [ ] สมุดคดี `known_facts` ไม่ปน `DM secret`, `open_questions` คงหลังเปลี่ยนบท
- [ ] ทั้ง 16 Checks มี Full/Partial/Failure และการทอยไม่ผ่านไม่ปิดทาง A–Final

- [ ] Save/Load ไม่รีเซ็ตจุดทอย, เบาะแส, NPC, PHASE หรือตัวเลือกคำใบ้ที่ใช้ไปแล้ว
- [ ] Ending A/B/C/D มีทางเกิดได้ตาม State จริง ไม่ใช่เมนูให้เลือก

## ตัวอย่างการทดสอบฉากที่ผู้เล่นหลุดเนื้อเรื่อง

| สถานการณ์ | สิ่งที่ควรเกิด |
|---|---|
| B ไม่ถามต้น | ไปบ้านดลได้จากแผนที่; C2 เพิ่มข้อสงสัยวิชัย |
| B ถามต้นแล้วพลาด | ไม่บังคับทอยใหม่หรือกลับ B; E3 ยังมีพยานตัวจริง |
| C สงบผีไม่ได้ | ไปสวนกล้วยได้จากสมุด/ยาย; ไม่ต้องใช้ภาพจากผี |
| D แม่แก้วไม่ยอมคุย | รอยล้อ D5 ยังพาไปเรือนไม้ |
| E ขึ้นบนก่อน | ระบบยังจำคนหายที่ยังรอความช่วยเหลือ |
| H1 มีเอกสารแต่ไม่มีประเสริฐ | แสดงเหตุการณ์จากเอกสาร ไม่พูดว่าเขาสารภาพ |
| F ไม่ต้องสู้ | เปิดฉากปลดพิธี/เจรจาแทน Boss ที่ไม่เกิดจริง |
