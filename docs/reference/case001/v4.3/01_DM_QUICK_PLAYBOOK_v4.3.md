# คู่มือ DM แบบเร็ว — CASE 001 v4.3

> เอกสารนี้ช่วยเปิดเกมและคุมจังหวะโดยไม่ต้องอ่าน Story Script ทั้งฉบับก่อนเริ่ม **บทพูดเต็มและสคริปต์ทอย Full/Partial/Failure ให้ใช้ `CASE001_StoryScript_v4.3.md`**

## กติกาการเดินเรื่องที่ใช้จริง

- เดินบทหลัก **A → B → C → D → E → FINAL → ENDING**; เมื่อออกจากบทแล้ว *ไม่เปิดกลับไปถาม NPC ในบทเดิม* (อนุญาตให้ทำฉากย่อยภายในบทปัจจุบันตามสถานการณ์)
- DM ต้องให้เห็นสิ่งผิดสังเกตก่อนเสนอหัวข้อคำถาม; เสนอได้ 2–3 ข้อ และอนุญาตถามอิสระเสมอ
- ไม่ต้องทอยเพื่อถามชื่อคนหาย หาสมุดในที่ที่ค้นถูกจุด เห็นป้ายชื่อ ตามรอยล้อ หรือฟังผู้รอดชีวิตเมื่อปลอดภัย
- ทอยเฉพาะความไม่แน่นอนด้าน *ความลึก ความน่าเชื่อถือ ความเร็ว ความปลอดภัย หรือผลเชิงสัมพันธ์*; ผล Full/Partial/Failure อยู่ใน Story Script และ JSON เดิม
- เมื่อค้าง ให้คำใบ้ระดับ 1 → 2 → 3; อย่าเฉลยชื่อผู้ร้ายหรือคำตอบที่ไม่ได้อยู่ในฉาก
- ก่อนเปลี่ยนบท: สรุป **รู้แล้ว / ยังสงสัย / จุดหมายต่อไป** จากข้อมูลที่ทีมพบจริง และยืนยันเดินทาง; เรื่องยังไม่รู้มีคำตอบจาก *แหล่งใหม่ในบทถัดไป* ไม่ใช่การย้าย NPC
- H1 เป็น *การเปิดเผยข้อมูล* จากหลักฐาน ไม่ใช่การวาร์ปกลับไป B; คำรับสารภาพจากประเสริฐใช้ได้เฉพาะเมื่อเขาอยู่ต่อหน้า/สื่อสารได้จริง
- ไม่บังคับ Combat ที่ C4, D4 หรือ Final หากผู้เล่นแก้สถานการณ์ได้ด้วยวิธีอื่น; เวลา 03:00 ทำให้อาคมฝังแน่น ไม่ใช่ Game Over ทันที

## บท A — รับคดีที่ทางเข้าหมู่บ้าน

**เป้าหมาย:** รู้ว่าคนหายสามคนคือใคร และทำไมต้องตรวจข้อมูลที่บ้านผู้ใหญ่

**DM เปิดเรื่อง:** ประเสริฐมารอรับทีมกลางหมู่บ้านที่เงียบผิดปกติ เขารายงานคนหายสามคน ก่อนเสียงวิทยุจะย้ำว่าอาจยังมีคนอยู่

**ก่อนออกบทควรรู้:** ชื่อคนหาย ดล/นิด/เพิ่ม; ตำแหน่งบ้านผู้ใหญ่และแฟ้มข้อมูลคนหาย

**คำใบ้เมื่อทีมติดขัด**

1. *ระดับ 1 — สะกิด:* ประเสริฐดูมีข้อมูลอยู่ในมือมากกว่าที่เล่าครั้งแรก
2. *ระดับ 2 — ชี้ทิศ:* เขาเอ่ยว่าที่บ้านมีแฟ้มและแผนที่ของคนหายทั้งสาม
3. *ระดับ 3 — บอก Action ที่ลองได้:* ลองถามประเสริฐถึงแฟ้มข้อมูลและขอให้พาไปบ้านผู้ใหญ่

**จังหวะเปลี่ยนบท:** หลังผู้เล่นได้รับรายชื่อและยืนยันเดินทาง ประเสริฐพาทีมไปดูเอกสารที่บ้านผู้ใหญ่

**เงื่อนไขจบบท:** ทีมเลือกเดินทางไปบ้านผู้ใหญ่และรู้ตำแหน่ง B1; ไม่ต้องผ่าน A2_RADIO_ECHO

**ถ้าพลาดข้อมูลในบทนี้:**
- A2 วิทยุ: เรื่องร่องรอยน้ำจะถูกขยายจากบ้านดลและคำของยายบุญมี

**ฉากในบทนี้**

### A1 — ทางเข้า: รถบริษัทถึงหมู่บ้าน (23:00)

- **เห็นก่อนถาม:** เมื่อรถบริษัทมาถึง ประเสริฐรอพร้อมรายชื่อคนหาย สีหน้าเขาเปลี่ยนทุกครั้งที่พูดถึงสวนกล้วย
- **หัวข้อชวนถาม:** ทั้งสามหายคนละคืนหรือคืนเดียวกัน? / ใครเห็นพวกเขาเป็นคนสุดท้าย? / ทำไมจึงเรียกบริษัทนี้?
- **ข้อมูลพื้นฐาน:** A1: ชื่อดล นิด เพิ่ม และข่าวลือสวนกล้วยเป็นข้อมูลที่ประเสริฐตอบได้ทันที
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** ให้ผู้เล่นถามประเสริฐก่อน; ระหว่างคุยวิทยุเริ่มส่งเสียงแปลก → A2; หากทีมข้ามการตรวจ ก็ได้ยินเสียงนั้นขณะเตรียมเดินทาง
- **พลาดแล้วไปต่อ:** รายชื่อคนหายและแผนที่ยังอยู่ที่บ้านผู้ใหญ่ใน B ไม่ต้องย้อนมาทางเข้าหมู่บ้าน

### A2 — วิทยุบริษัทส่งเสียง (เหตุการณ์บรรยากาศ)

- **เห็นก่อนถาม:** วิทยุมีเสียงสำลักกับคำว่า “ยังมีคนอยู่” แล้วคลื่นเงียบลง
- **หัวข้อชวนถาม:** เสียงนั้นเป็นสัญญาณวิทยุจริงหรือไม่? / เสียงพูดเป็นผู้หญิงหรือผู้ชาย? / มีแหล่งคลื่นอยู่แถวไหน?
- **ข้อมูลพื้นฐาน:** เสียงที่ได้ยินเป็นข้อมูลทุกคนได้รับ ไม่ต้องทอย; ตรวจความผิดปกติด้วย SPI DC14 เท่านั้น
- **ทอยเพิ่ม:** SPI DC 14 (`A2_RADIO_ECHO`)
- **ทางไปต่อ:** ประเสริฐเปิดแผนที่และบอกว่าเอกสารเวลาเห็นคนหายครั้งสุดท้ายอยู่ที่บ้าน → A3
- **พลาดแล้วไปต่อ:** หากตรวจคลื่นล้มเหลว เรื่องน้ำและผีจะกลับมาใน C; ไม่มีการปิดทาง B

### A3 — ชี้ทาง B

- **เห็นก่อนถาม:** ประเสริฐชี้ว่าข้อมูลคนหายอยู่ในบ้านที่ยังเปิดไฟสว่าง
- **หัวข้อชวนถาม:** แฟ้มคนหายมีอะไรบ้าง? / ไปที่บ้านผู้ใหญ่ไกลไหม?
- **ข้อมูลพื้นฐาน:** รู้ตำแหน่งบ้านผู้ใหญ่และไปได้โดยไม่ทอย
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** เมื่อทีมตัดสินใจตามข้อมูล ให้บรรยายถนนเปลี่ยวและแผนที่ที่หน้าต่างบ้านผู้ใหญ่ → B1
- **พลาดแล้วไปต่อ:** ถ้าไม่สนใจ A2 ก็ยังต้องถึง B1 ได้; ไม่กลับ A

**สมุดคดีก่อนออกบท (แสดงเฉพาะข้อมูลที่ผู้เล่นทราบจริง)**

- รู้แล้ว: ข้อมูลที่ทีมได้รับในบทนี้และหลักฐานใน Inventory
- ยังสงสัย: คำถามที่ทีมตั้งเองและยังไม่มีข้อยืนยัน
- ไปต่อเพราะ: หลังผู้เล่นได้รับรายชื่อและยืนยันเดินทาง ประเสริฐพาทีมไปดูเอกสารที่บ้านผู้ใหญ่

## บท B — บ้านผู้ใหญ่และพยานที่ไม่กล้าพูด

**เป้าหมาย:** รู้ว่าดลกำลังติดตามเรื่องผิดปกติและมีเหตุผลไปค้นสมุดที่บ้าน

**DM เปิดเรื่อง:** แผนที่และแฟ้มถูกจัดไว้บนโต๊ะ วิชัยเป็นมิตรแต่คุมข้อมูล ส่วนต้นมีท่าทีกังวล

**ก่อนออกบทควรรู้:** รู้ว่าบ้านดลอยู่ที่ไหน; รู้ว่าดลเก็บบันทึกไว้ที่โต๊ะทำงานของบ้าน

**คำใบ้เมื่อทีมติดขัด**

1. *ระดับ 1 — สะกิด:* สังเกตว่าต้นมองวิชัยซ้ำ ๆ และวิชัยวางมือทับมุมแผนที่
2. *ระดับ 2 — ชี้ทิศ:* ในแฟ้มมีชื่อดลซ้ำกับหัวข้อที่ดิน และประเสริฐบอกว่าดลจดรายละเอียดเอง
3. *ระดับ 3 — บอก Action ที่ลองได้:* ตรวจแผนที่แล้วถามประเสริฐว่าบ้านดลอยู่ไหนและมีสิ่งใดควรค้น

**จังหวะเปลี่ยนบท:** ประเสริฐชี้บ้านดลบนแผนที่ ทีมรู้ว่าสมุดที่ดลเก็บไว้อาจให้ข้อมูลว่าทำไมเขาจึงหาย

**เงื่อนไขจบบท:** รู้ LOCATION_C_KNOWN จากแผนที่ หรือประเสริฐบอกทาง; ทีมเลือกยืนยันออกเดินทาง

**ถ้าพลาดข้อมูลในบทนี้:**
- B3 ต้น: สมุดดล C2 ชี้รูปแบบที่ดิน และคำให้การ E3 ยืนยันการลักพาตัว
- B4 น้ำท่วม: ยายบุญมี C5 และเอกสาร E4/H1 ย้อนให้ข้อมูล

**ฉากในบทนี้**

### B1 — บ้านผู้ใหญ่: พบวิชัยและต้น (23:20)

- **เห็นก่อนถาม:** บนโต๊ะมีแผนที่รายชื่อสามคน วิชัยวางมือทับมุมแผนที่ ส่วนต้นยืนใกล้ประตูและหลบสายตา
- **หัวข้อชวนถาม:** วิชัยรู้เรื่องสวนอย่างไร? / ต้นทำไมไม่กล้าสบตา? / มีอะไรผิดปกติในแผนที่และแฟ้ม?
- **ข้อมูลพื้นฐาน:** ข้อมูลพื้นฐานเกี่ยวกับดลและสถานที่อยู่บนโต๊ะ ไม่ต้องทอย
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** ให้ทีมเลือกคุยวิชัย B2 ต้น B3 หรือดูแฟ้ม B4 ตามความสนใจ; เบาะแสทั้งหมดมุ่งสู่ B5
- **พลาดแล้วไปต่อ:** แม้ไม่ถาม NPC ทั้งคู่ ประเสริฐยังอธิบายว่าดลจดข้อมูลส่วนตัวที่บ้าน

### B2 — คำถามสำหรับวิชัย

- **เห็นก่อนถาม:** วิชัยตอบเรื่องสวนคล่อง แต่จังหวะตอบเรื่องกลางคืนชะงักอยู่ครู่หนึ่ง
- **หัวข้อชวนถาม:** เข้าไปสวนกลางคืนทำไม? / เรื่องซื้อขายที่ดินเกี่ยวกับคนหายอย่างไร? / มีใครยืนยันกิจกรรมคืนนั้นได้บ้าง?
- **ข้อมูลพื้นฐาน:** วิชัยบอกว่าทำงานที่ดินและตรวจสวนได้โดยการถาม; PER14 ช่วยสังเกตความไม่สอดคล้อง ไม่พิสูจน์ลักพาตัว
- **ทอยเพิ่ม:** PER DC 14 (`B2_WICHAI_TELL`)
- **ทางไปต่อ:** วิชัยเบนไปว่าให้ถามคนที่เห็นเอง หากต้นอยู่ยังคุย B3 ได้ หรือเทียบแฟ้ม B4 ก่อนออก B5
- **พลาดแล้วไปต่อ:** ไม่เจอพิรุธก็ยังรู้ว่าดลจดเรื่องที่ดินไว้ C2 จะเชื่อมข้อสงสัย

### B3 — ต้น พยานที่กลัว

- **เห็นก่อนถาม:** ต้นพูดว่าเห็นบางอย่าง แต่เหลือบมองวิชัยจนพูดไม่จบ
- **หัวข้อชวนถาม:** ต้นเห็นใครหรือเห็นแค่เงา? / คุยที่เป็นส่วนตัวได้ไหม? / ต้องทำอย่างไรให้ต้นปลอดภัย?
- **ข้อมูลพื้นฐาน:** เห็นคนขนของเป็นสิ่งที่ต้นอาจเล่าเมื่อปลอดภัย; SOC14 เฉพาะเมื่อทีมพยายามโน้มน้าวโดยยังไม่ได้จัดความปลอดภัยจริง
- **ทอยเพิ่ม:** SOC DC 14 (`B3_TON_DISCLOSURE`)
- **ทางไปต่อ:** คำให้การหรือความเงียบของต้นชี้ว่าเบาะแสต้องตรวจสอบจากบันทึกที่ดลเก็บ → B5
- **พลาดแล้วไปต่อ:** ถ้าทอยพลาดหรือไม่ถามต้น สมุดดล C2 และคำให้การผู้รอดชีวิต E3 รองรับ; ต้นไม่ถูกย้ายไปฉากหลัง

### B4 — ภาพถ่ายและเอกสารเก่า

- **เห็นก่อนถาม:** ภาพเก่าประตูน้ำมีหยดน้ำด้านในกรอบ แฟ้มบันทึกปี 2534 ถูกคั่นไว้ผิดหมวด
- **หัวข้อชวนถาม:** คนในรูปเป็นใคร? / ทำไมรายงานเกี่ยวกับน้ำท่วมถูกเก็บกับแฟ้มคนหาย? / ตำแหน่งประตูน้ำสัมพันธ์กับสวนอย่างไร?
- **ข้อมูลพื้นฐาน:** เห็นปีและรูปได้โดยไม่ทอย; INT14 ใช้โยงความผิดปกติ ไม่ให้สรุปผู้สั่งเปิดประตูทันที
- **ทอยเพิ่ม:** INT DC 14 (`B4_FLOOD_PHOTO`)
- **ทางไปต่อ:** คำตอบประเสริฐชี้ว่ายังไม่พร้อมเล่าทั้งหมด ทีมสามารถเก็บคำถามไว้ในสมุดคดีแล้วมุ่งบ้านดล → B5
- **พลาดแล้วไปต่อ:** บันทึกยายบุญมี C5 และเอกสาร E4/H1 ให้ข้อมูลประตูน้ำภายหลังโดยไม่ต้องกลับมา B

### B5 — การเดินทางไปบ้านดล

- **เห็นก่อนถาม:** ประเสริฐวงตำแหน่งบ้านดลบนแผนที่และชี้ไปยังโต๊ะทำงานที่ยังไม่มีใครเก็บของ
- **หัวข้อชวนถาม:** ดลสืบอะไรอยู่ก่อนหาย? / มีแผนที่ไปบ้านดลหรือไม่? / ควรนำหลักฐานอะไรติดตัวไป?
- **ข้อมูลพื้นฐาน:** ตำแหน่ง C เปิดอัตโนมัติเมื่อได้รับแผนที่ ไม่ต้องทอย
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** แสดงสรุปบท B ตามข้อมูลจริง แล้วให้ทีมยืนยันออกเดินทางไปบ้านดล → C1
- **พลาดแล้วไปต่อ:** ถ้าไม่ได้สนทนาต้น/วิชัย ความลับไม่ถูกให้ฟรี; แต่ยังเข้าบ้านดลได้

**สมุดคดีก่อนออกบท (แสดงเฉพาะข้อมูลที่ผู้เล่นทราบจริง)**

- รู้แล้ว: ข้อมูลที่ทีมได้รับในบทนี้และหลักฐานใน Inventory
- ยังสงสัย: คำถามที่ทีมตั้งเองและยังไม่มีข้อยืนยัน
- ไปต่อเพราะ: ประเสริฐชี้บ้านดลบนแผนที่ ทีมรู้ว่าสมุดที่ดลเก็บไว้อาจให้ข้อมูลว่าทำไมเขาจึงหาย

## บท C — บ้านดล เศษความทรงจำ และยายบุญมี

**เป้าหมาย:** เห็นความเกี่ยวข้องของด้ายดำกับสวนและเข้าใจว่าแม่แก้วมีอดีตที่เกี่ยวกับน้ำท่วม

**DM เปิดเรื่อง:** บ้านดลเหมือนถูกทิ้งกะทันหัน มีสมุดที่โต๊ะและความชื้นแปลก ๆ ที่เชื่อมกับผีเงาจมน้ำ

**ก่อนออกบทควรรู้:** รู้ว่าสวนกล้วยมีศาลและด้ายดำ; มีเหตุผลไปตรวจศาล: ข้อความในสมุด/คำยายบุญมี/ร่องรอย

**คำใบ้เมื่อทีมติดขัด**

1. *ระดับ 1 — สะกิด:* ข้อความท้ายสมุดกล่าวถึงศาล และคราบชื้นไม่เหมือนฝนตก
2. *ระดับ 2 — ชี้ทิศ:* ยายบุญมีรู้เรื่องแม่แก้วและสิ่งที่ไม่ควรแตะในสวนกล้วย
3. *ระดับ 3 — บอก Action ที่ลองได้:* อ่านหน้าท้ายสมุดหรือถามยายบุญมีว่าจะเริ่มตรวจสวนที่ไหน

**จังหวะเปลี่ยนบท:** คำเตือนยายบุญมีเรื่องด้ายดำและชื่อแม่แก้วบรรจบกับหน้าท้ายสมุดดล ทีมจึงเลือกไปศาลสวนกล้วย

**เงื่อนไขจบบท:** มี LOCATION_D_KNOWN จากสมุดหรือคำยาย และทีมเลือกมุ่งสวน; C4 เป็น optional

**ถ้าพลาดข้อมูลในบทนี้:**
- C4 ไม่ได้ภาพจากผี: D2/D5 มีรอยพิธีและทางไปบ้านร้าง
- C5 ไม่ได้รู้วิชัยเป็นเด็กที่รอด: เอกสารอพยพ E4 และแม่แก้ว D3 ให้ข้อมูลตามสิ่งที่ตนรู้

**ฉากในบทนี้**

### C1 — บ้านดล (00:00)

- **เห็นก่อนถาม:** ประตูบ้านดลปิดไม่สนิท อาหารยังวางอยู่ เสื้อพาดเก้าอี้และมีคราบชื้นทั้งที่ฝนไม่ตก
- **หัวข้อชวนถาม:** ใครเข้ามาที่นี่ล่าสุด? / โต๊ะทำงานอยู่ตรงไหน? / เสียงและคราบชื้นมาจากอะไร?
- **ข้อมูลพื้นฐาน:** สภาพบ้านและจุดค้นบริเวณโต๊ะมองเห็นได้; ไม่จำเป็นต้องทอยเพื่อหาประตู
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** ทางเดินและร่องรอยไปยังโต๊ะกระตุ้นการค้นสมุด → C2
- **พลาดแล้วไปต่อ:** หากผู้เล่นยังไม่รู้เรื่องที่ดิน บันทึกบนโต๊ะจะเปิดประเด็นได้ใน C2

### C2 — สมุดดล E02

- **เห็นก่อนถาม:** สมุดปกดำมีรายการที่ดินหลายรายและชื่อวิชัยซ้ำ ๆ ที่สันมีเศษด้ายดำ
- **หัวข้อชวนถาม:** ทำไมเจ้าของที่ดินหลายคนเริ่มขายพร้อมกัน? / ด้ายดำติดสมุดมาได้อย่างไร? / หน้าสุดท้ายพูดถึงศาลเพราะอะไร?
- **ข้อมูลพื้นฐาน:** พบสมุดเมื่อค้นโต๊ะ ไม่ต้องทอย; INT14 ใช้วิเคราะห์ลำดับข่าวผีกับการกดราคา
- **ทอยเพิ่ม:** INT DC 14 (`C2_LAND_PATTERN`)
- **ทางไปต่อ:** เมื่ออ่านจนถึงข้อความ “ไปดูศาล” ได้ยินเสียงเคาะจากใต้พื้นและผนัง → C3
- **พลาดแล้วไปต่อ:** หากอ่านไม่เข้าใจ เก็บสมุดใน Inventory; การพบเอกสาร E4 ยืนยันได้ในภายหลัง

### C3 — เสียงเคาะสามครั้ง

- **เห็นก่อนถาม:** มีเสียงเคาะสามครั้งจากใต้พื้น แล้วดังซ้ำจากผนังที่ไม่มีช่องว่าง
- **หัวข้อชวนถาม:** มีใครติดอยู่ใต้พื้นหรือไม่? / คราบน้ำเชื่อมกับด้ายดำหรือเปล่า? / ควรถอยหรือสืบต่อ?
- **ข้อมูลพื้นฐาน:** ตรวจแล้วไม่พบคนถูกขังใต้บ้านดล; SPI14 วิเคราะห์พลังพิเศษเมื่อสนใจ
- **ทอยเพิ่ม:** SPI DC 14 (`C3_SPIRIT_RESIDUE`)
- **ทางไปต่อ:** แสดงสัญญาณอันตรายให้ชัด เปิดทางสู้/สงบ/หนีใน C4 โดยไม่บังคับ Combat
- **พลาดแล้วไปต่อ:** หากไม่ตรวจพลัง ผู้เล่นยังหลบผีและไปพบยายบุญมีได้ตามทางเดิน

### C4 — Encounter เดียว: ผีเงาจมน้ำ (Tutorial Combat)

- **เห็นก่อนถาม:** ร่างคนจมน้ำค่อย ๆ ปรากฏจากคราบน้ำ มันเปล่งเสียง “ช่วย...” ไม่ใช่พยานที่สนทนาได้อย่างมีเหตุผล
- **หัวข้อชวนถาม:** นี่ใช่คนหายหรือเป็นเศษความทรงจำ? / จะช่วยสงบผีหรือถอย? / ภาพที่มันเห็นเชื่อถือได้แค่ไหน?
- **ข้อมูลพื้นฐาน:** ไม่มีการเปิดเผยผู้ลักพาตัวจากผี; SPI14 สำหรับขอภาพสะท้อนเพิ่มเติมเมื่อมีช่องให้สื่อสาร
- **ทอยเพิ่ม:** SPI DC 14 (`C4_DROWNED_ECHO_VISION`)
- **ทางไปต่อ:** หลังจบผล encounter จะเห็นข้อมูลติดต่อยายบุญมีหรือเรื่องศาลจากสมุด/ปากชาวบ้าน → C5
- **พลาดแล้วไปต่อ:** หนีหรือแพ้ไม่ปิด C5; ข้อมูลจากผีไม่ใช่กุญแจจำเป็นของ D

### C5 — บ้านยายบุญมี

- **เห็นก่อนถาม:** ยายบุญมีเตรียมผ้าเขียวกับธูป และสะดุ้งเมื่อได้ยินชื่อแก้ว
- **หัวข้อชวนถาม:** เด็กที่แก้วช่วยเป็นใคร? / ปี 2534 เกิดอะไรกับสะพานไม้? / ด้ายดำที่ศาลมีมาตั้งแต่เมื่อไร?
- **ข้อมูลพื้นฐาน:** เมื่อถามชื่อเด็ก ยายตอบวิชัยทันที; ยายไม่เห็นคำสั่งเปิดประตูกับตา; INT17 เฉพาะเมื่อมีบันทึกสองชุดให้เทียบ
- **ทอยเพิ่ม:** INT DC 17 (`C5_EVACUATION_RECORDS`)
- **ทางไปต่อ:** ยายบอกให้เริ่มที่ศาลและอย่าดึงด้ายดำด้วยมือเปล่า → D1 เมื่อทีมยืนยันออกเดินทาง
- **พลาดแล้วไปต่อ:** ถ้าไม่ได้ตรวจสมุด ลักษณะด้ายดำที่ศาล D2 และเอกสาร E4 จะรองรับ; หากพลาดยาย เอกสารกับแม่แก้วเปิดตัวตนได้ภายหลัง

**สมุดคดีก่อนออกบท (แสดงเฉพาะข้อมูลที่ผู้เล่นทราบจริง)**

- รู้แล้ว: ข้อมูลที่ทีมได้รับในบทนี้และหลักฐานใน Inventory
- ยังสงสัย: คำถามที่ทีมตั้งเองและยังไม่มีข้อยืนยัน
- ไปต่อเพราะ: คำเตือนยายบุญมีเรื่องด้ายดำและชื่อแม่แก้วบรรจบกับหน้าท้ายสมุดดล ทีมจึงเลือกไปศาลสวนกล้วย

## บท D — ศาลสวนกล้วยและแม่แก้ว

**เป้าหมาย:** รู้ว่าผีถูกผูกด้วยอาคมเดียวกัน และตามรอยคนเป็นที่ขนของไปเรือนไม้ได้

**DM เปิดเรื่อง:** ศาลมีด้ายดำและป้ายชื่อคนหายสามคน แม่แก้วปรากฏโดยไม่โจมตีทันที

**ก่อนออกบทควรรู้:** รู้ตำแหน่งทางไปเรือนไม้จากรอยล้อ/เสียง/คำใบ้; รู้ว่าสามคนยังไม่จำเป็นต้องเสียชีวิตเพราะชื่ออยู่บนด้าย

**คำใบ้เมื่อทีมติดขัด**

1. *ระดับ 1 — สะกิด:* ด้ายสามป้ายชื่อโยงไปคนหาย แต่รอยล้อบนดินเกิดจากของจริง
2. *ระดับ 2 — ชี้ทิศ:* ด้านหลังศาลมีเศษกระสอบติดกิ่งและทางรถเข็นพาดต่อ
3. *ระดับ 3 — บอก Action ที่ลองได้:* เดินตามรอยรถเข็นหลังศาลไปยังเรือนไม้ร้าง

**จังหวะเปลี่ยนบท:** รอยล้อชัดขึ้นเมื่อพ้นศาล มุ่งตรงไปเรือนไม้ที่มีแสงเทียนอยู่ไกล ๆ ทีมเลือกตามไป

**เงื่อนไขจบบท:** LOCATION_E_KNOWN และทีมเลือกไป E1; D4 optional; D5 ไม่ล็อกด้วย PER

**ถ้าพลาดข้อมูลในบทนี้:**
- D3 เจรจาพลาด: คำให้การผู้รอดชีวิตและตำรา E4 ยืนยันการผูกวิญญาณ
- D2 อ่านพิธีไม่ออก: E4 มีตำราพิธีและกำไล

**ฉากในบทนี้**

### D1 — เข้าสวน (00:50)

- **เห็นก่อนถาม:** เสียงแมลงหายไปทีละชนิด ใบกล้วยเคลื่อนสวนลม มีรอยเปียกพาไปศาล
- **หัวข้อชวนถาม:** รอยเปียกพาไปที่ไหน? / มีใครกำลังเฝ้าดูอยู่? / ศาลเป็นต้นทางเสียงร้องหรือเปล่า?
- **ข้อมูลพื้นฐาน:** ผู้เล่นมองเห็นทางเดินไปศาลได้ ไม่ต้องผ่าน PER
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** เสียงกระซิบและด้ายดำดึงสายตาไปศาล → D2
- **พลาดแล้วไปต่อ:** ถ้าทีมไม่รู้เรื่องแม่แก้ว ศาลมีชื่อและเครื่องไหว้ช่วยแนะนำตัวตน

### D2 — ศาลและด้ายดำ

- **เห็นก่อนถาม:** ด้ายดำพันศาลกับต้นกล้วยและป้ายผ้าชื่อ “ดล นิด เพิ่ม” แขวนอยู่
- **หัวข้อชวนถาม:** ป้ายสามชื่อหมายความว่าพวกเขาตายหรือแค่ถูกหมายหัว? / ด้ายต่อไปถึงไหน? / ตัดด้ายจะช่วยหรือทำให้พิธีปะทุ?
- **ข้อมูลพื้นฐาน:** อ่านชื่อครบได้โดยไม่ทอย; INT14 แยกโครงสร้างพิธี; การตัดด้ายแค่ทำให้พิธีอ่อนลง
- **ทอยเพิ่ม:** INT DC 14 (`D2_BINDING_PATTERN`)
- **ทางไปต่อ:** ด้ายกระตุกตอบสนองเมื่อทีมแตะ และแม่แก้วปรากฏตัว → D3
- **พลาดแล้วไปต่อ:** ผู้เล่นที่อ่านพิธีไม่ออกยังรู้ว่ามีคนใช้ด้ายกับทั้งสาม; ตำราที่ E4 อธิบายแกนต่อ

### D3 — แม่แก้วปรากฏตัว

- **เห็นก่อนถาม:** แม่แก้วยืนหลังศาลและถามว่าพวกผู้เล่นมาหาคนหรือมาหาของ
- **หัวข้อชวนถาม:** คนที่หายอยู่ไหน? / ด้ายดำบังคับอะไรเธอ? / เธออยากให้ทีมทำอย่างไร?
- **ข้อมูลพื้นฐาน:** แม่แก้วบอกว่าไม่ได้ขังคน; ผีถูกอาคมขัดขวางไม่ให้ชี้ตัววิชัยตรง ๆ; SPI14 รับรู้อารมณ์ ไม่ลบผนึก
- **ทอยเพิ่ม:** SPI DC 14 (`D3_KAEW_CONTACT`)
- **ทางไปต่อ:** หากพูดคุยได้ แม่แก้วส่งคำใบ้ทิศทาง; หากก้าวร้าวจริงจึงเข้าสู่ D4; ทางเดิน D5 ยังมีอยู่
- **พลาดแล้วไปต่อ:** ถ้าคุยพลาด ไม่ต้องย้อนมาหาเธอ: ทางไปเรือนไม้ตามรอยล้อ D5 และเอกสาร E4 รองรับ

### D4 — เผชิญหน้าหรือสู้แม่แก้วที่ D (เลือกได้)

- **เห็นก่อนถาม:** เมื่อผู้เล่นโจมตีหรือภัยคุกคามจริงเริ่มขึ้น รากไม้แทรกดิน แม่แก้วตอบโต้
- **หัวข้อชวนถาม:** จะยอมถอยแทนสู้หรือไม่? / ทำอย่างไรจึงหยุดพันธนาการ? / เมื่อร่างสลายแล้ววิญญาณยังอยู่ไหม?
- **ข้อมูลพื้นฐาน:** Combat เป็นทางเลือกตาม trigger ไม่ใช่บังคับ; สลายร่างได้แต่ไม่ฆ่าวิญญาณ
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** ไม่ว่าผลสู้/ถอน/เจรจา ทีมยังติดตามรอยขนย้ายจากศาลได้ → D5
- **พลาดแล้วไปต่อ:** หาก D4 ไม่เกิด ให้ไป D5 โดยไม่สร้างการต่อสู้ปลอม

### D5 — ทางไปเรือนร้าง

- **เห็นก่อนถาม:** รอยล้อรถเข็นและเศษกระสอบทอดจากศาลไปเรือนไม้ร้างท้ายสวน
- **หัวข้อชวนถาม:** รอยล้อมาจากคนหรือผี? / มีเสียงอะไรจากปลายทาง? / ทีมควรช่วยคนหายหรือจัดการพิธีก่อน?
- **ข้อมูลพื้นฐาน:** ทางไปเรือนไม้อยู่ตรงหน้าเสมอ; PER11 ใช้รู้รายละเอียดการขนย้าย ไม่ใช้ล็อกทิศทาง
- **ทอยเพิ่ม:** PER DC 11 (`D5_CART_TRACKS`)
- **ทางไปต่อ:** แสดงสรุปบท D แล้วทีมยืนยันเดินตามรอยล้อไปเรือนไม้ → E1
- **พลาดแล้วไปต่อ:** ถ้าพลาด PER ทีมก็ยังเห็นทาง; ข้อมูลการลักพาตัวยืนยัน E2/E3

**สมุดคดีก่อนออกบท (แสดงเฉพาะข้อมูลที่ผู้เล่นทราบจริง)**

- รู้แล้ว: ข้อมูลที่ทีมได้รับในบทนี้และหลักฐานใน Inventory
- ยังสงสัย: คำถามที่ทีมตั้งเองและยังไม่มีข้อยืนยัน
- ไปต่อเพราะ: รอยล้อชัดขึ้นเมื่อพ้นศาล มุ่งตรงไปเรือนไม้ที่มีแสงเทียนอยู่ไกล ๆ ทีมเลือกตามไป

## บท E — เรือนไม้ร้าง: ช่วยคนและแกนพิธี

**เป้าหมาย:** ช่วยคนหายให้ปลอดภัย เจอแกนอาคม และมีแผนหยุดพิธีโดยไม่ต้องย้อนถามคนเก่า

**DM เปิดเรื่อง:** มีเสียงคนขอความช่วยเหลือใต้ถุนและแสงเทียนชั้นบน ข้อเท็จจริงสองสายแยกกันแต่โยงที่วิชัย

**ก่อนออกบทควรรู้:** มีโอกาสช่วยคนทั้งสามอย่างสมเหตุสมผล; ค้นพบกำไลทองเหลืองและร่องพิธีเดียว; รู้ว่าวิชัยเกี่ยวข้องจากพยาน/หลักฐานตามจริง

**คำใบ้เมื่อทีมติดขัด**

1. *ระดับ 1 — สะกิด:* เสียงร้องใต้ถุนเกิดจากคนมีชีวิต ขณะที่ด้ายดำพาดขึ้นชั้นบน
2. *ระดับ 2 — ชี้ทิศ:* ถ้าแก้คำสาปโดยไม่ช่วยคน สามคนอาจยังไม่ปลอดภัย
3. *ระดับ 3 — บอก Action ที่ลองได้:* ตรวจประตูใต้ถุนเพื่อช่วยคน และตรวจห้องบนเพื่ออ่านตำราและกำไล

**จังหวะเปลี่ยนบท:** เมื่อทีมพร้อมและมีโอกาสจัดการความปลอดภัย ด้ายบนคานกระตุก กำไลร้อนและเสียงแม่แก้วดังขึ้น จึงเข้าสู่ช่วงตัดสินใจ Final

**เงื่อนไขจบบท:** ทีมยืนยันรับมือพิธีและความเสี่ยงที่เหลือ → F ตามสถานะจริง; ไม่บังคับว่าต้องซัก E3 หรือเผชิญ E5

**ถ้าพลาดข้อมูลในบทนี้:**
- ถ้าไม่คุยต้น/ยาย: คำให้การ E3 กับเอกสาร E4 ให้ข้อเท็จจริงที่ตนรองรับ
- ถ้า H1 ยังไม่พร้อม: สามารถแก้พิธีและจบคดีได้ แต่ความจริงน้ำท่วมอาจเปิดเผยไม่ครบ

**ฉากในบทนี้**

### E1 — เรือนไม้ร้าง (01:40)

- **เห็นก่อนถาม:** ใต้ถุนเรือนมีกระสอบข้าวปิดประตูเล็ก ข้างบนมีแสงเทียนและเสียงกระซิบขอความช่วยเหลือ
- **หัวข้อชวนถาม:** เสียงคนมาจากตรงไหน? / จะช่วยคนก่อนหรือขึ้นไปตรวจกำไลก่อน? / วิชัยอาจกลับมาไหม?
- **ข้อมูลพื้นฐาน:** พบเบาะแสว่ามีคนอยู่ใต้ถุนได้โดยสำรวจ; ไม่ล็อกด้วยการทอย
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** ทีมเลือกช่วย E2 หรือขึ้นห้องพิธี E4 ภายในบท E เดียวกัน ก่อนเชื่อม Final
- **พลาดแล้วไปต่อ:** หากขึ้นบนก่อน เสียงผู้รอดชีวิตยังดังอยู่; ไม่แปลงเป็น HOSTAGES_SAFE โดยอัตโนมัติ

### E2 — พบคนหายสามคน

- **เห็นก่อนถาม:** หลังเปิดกลอนใต้ถุนพบคนหายสามคนอ่อนแรงแต่ยังมีชีวิต
- **หัวข้อชวนถาม:** ใครจับพวกเขา? / ใครต้องการการรักษาก่อน? / พาพวกเขาไปจุดปลอดภัยได้อย่างไร?
- **ข้อมูลพื้นฐาน:** เมื่อปลอดภัยพอ ดลบอกชื่อวิชัยโดยไม่ทอย; FOUND ไม่เท่ากับ SAFE
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** ถ้าคนปลอดภัย ให้ E3 ซักข้อมูล หรือขึ้น E4 ตามทาง; หากยังเสี่ยงเน้นช่วยออกก่อน
- **พลาดแล้วไปต่อ:** ถ้าขึ้น E4 ก่อนช่วย E2 ต้องเปิดตัวเลือกช่วยกลับมาภายใน E ก่อนปิดบท

### E3 — ซักผู้รอดชีวิต (NPC มีข้อมูลต่างกัน)

- **เห็นก่อนถาม:** คนหายแต่ละคนเห็นคนละด้านของคดี และเริ่มแยกเล่าความทรงจำ
- **หัวข้อชวนถาม:** ดลมีหลักฐานที่ดินอะไร? / นิดเห็นด้ายดำเมื่อไร? / เพิ่มเห็นใครยกกล่องขึ้นชั้นบน?
- **ข้อมูลพื้นฐาน:** เมื่อปลอดภัยพอ พยานยืนยันคนจับได้ตรง ๆ; SOC11 ใช้เรียงเหตุการณ์ละเอียด ไม่ใช้ล็อกชื่อวิชัย
- **ทอยเพิ่ม:** SOC DC 11 (`E3_HOSTAGES_ORDER`)
- **ทางไปต่อ:** คำให้การกล่องและเสียงพิธีพาคนขึ้นห้องบน → E4; นำข้อมูลติดตัวไป Final
- **พลาดแล้วไปต่อ:** ถ้าพยานตื่นกลัวและไม่ได้เรียงเวลา สัญญาณพิธีที่ E4 และเอกสารจะช่วยให้ต่อเรื่องได้

### E4 — ห้องพิธีและกำไล

- **เห็นก่อนถาม:** ด้ายดำบรรจบที่โต๊ะกำไลทองเหลืองสลักคำว่า “แก้ว” และมีตำราพิธี
- **หัวข้อชวนถาม:** กำไลเป็นของใคร? / มีวิธีหยุดการควบคุมอย่างปลอดภัยหรือไม่? / บันทึกเก่าระบุเรื่องเปิดประตูน้ำว่าอย่างไร?
- **ข้อมูลพื้นฐาน:** พบกำไลและเอกสารพื้นฐานเมื่อสำรวจ ไม่ทอย; INT14 ใช้หาแนวทางปลดที่ปลอดภัย
- **ทอยเพิ่ม:** INT DC 14 (`E4_BRACELET_DECODE`)
- **ทางไปต่อ:** หากวิชัยอยู่จริงและยังเป็นอิสระ อาจเข้าสู่ E5; มิฉะนั้นนำไป E6 เมื่อทีมพร้อมและคนหายมีโอกาสได้รับการช่วย
- **พลาดแล้วไปต่อ:** ถ้า INT ไม่ผ่าน ให้ตำราเป็นหลักฐานค้าง; ยังปลดพิธีด้วยการทดลองหรือวิธีอื่นที่มีความเสี่ยงและเบาะแสประกอบ

### E5 — เผชิญหน้าวิชัย (เฉพาะเมื่อเดินทางมาถึงจริง)

- **เห็นก่อนถาม:** หากวิชัยอยู่จริง เขาหยุดที่บันไดเมื่อเห็นทีมใกล้กำไล
- **หัวข้อชวนถาม:** จะให้วิชัยวางอาวุธหรือสารภาพอย่างไร? / ใครให้ตำราวิชัย? / จะจัดการกับผู้รอดชีวิตอย่างไร?
- **ข้อมูลพื้นฐาน:** SOC17 ใช้ลดการขัดขืน ไม่ลบหลักฐานที่ทีมมี ไม่บังคับให้ยอมรับสารภาพโดยไม่มีข้อมูล
- **ทอยเพิ่ม:** SOC DC 17 (`E5_WICHAI_NEGOTIATE`)
- **ทางไปต่อ:** หลังวิชัยหนี ถูกจับ หรือยอมร่วมมือ พิธียังทำงาน จึงต้องกลับไปที่กำไลภายใน E และเข้า E6
- **พลาดแล้วไปต่อ:** ถ้าวิชัยไม่ได้อยู่ ไม่สร้าง E5; เอกสารและคำให้การยังใช้กล่าวหาได้

### H1 — เฉลยอดีตจากหลักฐาน (Flexible Reveal; จะเกิดตั้งแต่ B/C ก็ได้)

- **เห็นก่อนถาม:** เมื่อมีบันทึกน้ำท่วมและบันทึกอพยพ ข้อมูลเวลาไม่ตรงกันและต้องเรียงเหตุการณ์
- **หัวข้อชวนถาม:** ประตูน้ำถูกเปิดเมื่อใด? / ประเสริฐมีบทบาทระดับไหน? / เอกสารระบุว่าอพยพครบจริงหรือไม่?
- **ข้อมูลพื้นฐาน:** ตรวจหลักฐานได้แม้ประเสริฐไม่อยู่; คำสารภาพประเสริฐเกิดเฉพาะเมื่อเขาอยู่ในฉากจริงหรือผ่านช่องทางที่สมจริง
- **ทอยเพิ่ม:** INT DC 17 (`H1_FLOOD_TIMELINE`)
- **ทางไปต่อ:** เก็บผลการวิเคราะห์ลงสมุดคดีและกลับกิจกรรม E ปัจจุบัน; H1 ไม่ใช่การเดินทางย้อนบท
- **พลาดแล้วไปต่อ:** หากขาดคำสารภาพ รายงานท้ายคดียังชี้การกระทำได้จากหลักฐาน; ไม่ spawn ประเสริฐ

### E6 — ขยับไป Final

- **เห็นก่อนถาม:** ด้ายดำบนคานกระตุก กำไลร้อนขึ้น และเสียงผู้หญิงดังใกล้ห้อง
- **หัวข้อชวนถาม:** ผู้รอดชีวิตปลอดภัยหรือยัง? / ต้องหยุดพิธีทันทีหรือรับมือผีก่อน? / อาคมกำลังเปลี่ยนไปอย่างไร?
- **ข้อมูลพื้นฐาน:** Final ขึ้นกับสภาพพิธี/วิญญาณจริง ไม่ใช่ต้องมีบอสทุกครั้ง
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** เมื่อทีมยืนยันรับมือเหตุปะทุ หลังบันทึกสรุปบท E → F1 หรือ F5 ตามสถานะพิธี
- **พลาดแล้วไปต่อ:** หากวิชัยไม่อยู่ พิธียังทำงาน; หากหยุดแล้วไม่สร้างการสู้บอสเพื่อเติมฉาก

**สมุดคดีก่อนออกบท (แสดงเฉพาะข้อมูลที่ผู้เล่นทราบจริง)**

- รู้แล้ว: ข้อมูลที่ทีมได้รับในบทนี้และหลักฐานใน Inventory
- ยังสงสัย: คำถามที่ทีมตั้งเองและยังไม่มีข้อยืนยัน
- ไปต่อเพราะ: เมื่อทีมพร้อมและมีโอกาสจัดการความปลอดภัย ด้ายบนคานกระตุก กำไลร้อนและเสียงแม่แก้วดังขึ้น จึงเข้าสู่ช่วงตัดสินใจ Final

## บท FINAL — หยุดการควบคุมและเลือกชะตาแม่แก้ว

**เป้าหมาย:** หยุดพิธี ประคองความปลอดภัย และยุติภัยตามหลักฐานจริง

**DM เปิดเรื่อง:** อาคมปะทุตามสถานะปัจจุบัน แต่การปรากฏตัว/Combat ของแม่แก้วต้องมาจากเหตุการณ์ที่เกิดขึ้นจริง

**ก่อนออกบทควรรู้:** ทราบสถานะพิธี คนหาย และแม่แก้วก่อน Resolve ตอนจบ

**คำใบ้เมื่อทีมติดขัด**

1. *ระดับ 1 — สะกิด:* ด้ายและกำไลเป็นแกนเดียวกับที่พบในห้องบน
2. *ระดับ 2 — ชี้ทิศ:* แม่แก้วอาจต้องการความจริงมากกว่าการต่อสู้ และผู้รอดชีวิตต้องปลอดภัยก่อน
3. *ระดับ 3 — บอก Action ที่ลองได้:* ใช้หลักฐานพร้อมจัดการกำไล เมื่อพิธีหยุดแล้วคุยกับแม่แก้วตามความจริง

**จังหวะเปลี่ยนบท:** เมื่อภัยยุติหรือทีมถอนอย่างมีผลจริง ใช้ Ending Resolver A/B/C/D พร้อม Modifiers ไม่ให้ผู้เล่นเลือกตอนจบจากเมนู

**เงื่อนไขจบบท:** ยุติวิกฤตหรือถอนตัว/หมดทางรับมือ และคำนวณ Ending จาก State

**ถ้าพลาดข้อมูลในบทนี้:**
- หากยังไม่ได้สารภาพประเสริฐ: เปิดเผยจากหลักฐานที่เก็บได้อย่างเหมาะสม ไม่วาร์ปเขามาในห้องพิธี
- หากไม่ได้พูดกับแม่แก้วใน D: ยังเจรจา F5 ได้ แต่ TRUST ไม่ได้โบนัสย้อนหลัง

**ฉากในบทนี้**

### F1 — สัญญาณก่อนตีสาม

- **เห็นก่อนถาม:** เทียนและด้ายดำสั่น แม่แก้วร้องขอให้หยุดการควบคุม
- **หัวข้อชวนถาม:** พิธีหยุดหรือยัง? / ยังมีคนในพื้นที่อันตรายไหม? / ทีมจะใช้หลักฐานหรือป้องกันผีก่อน?
- **ข้อมูลพื้นฐาน:** ปรากฏเมื่อพิธียังทำงานตาม trigger; ไม่จำเป็นต้องมี combat
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** แสดงร่าง/ปฏิกิริยาตามผลที่ D → F2 หรือไป F5 หากพิธีหยุดแล้ว
- **พลาดแล้วไปต่อ:** ถ้าหยุดพิธีก่อนไม่ต้องสร้าง F1 เพื่อบังคับฉาก

### F2 — บทปรากฏตัวเปลี่ยนตาม D

- **เห็นก่อนถาม:** แม่แก้วปรากฏตามสภาพที่ผู้เล่นเคยปฏิบัติต่อเธอในสวนกล้วย
- **หัวข้อชวนถาม:** เธอจำทีมได้อย่างไร? / ยังถูกด้ายบังคับอยู่ไหม? / มีทางสื่อสารโดยไม่สู้หรือไม่?
- **ข้อมูลพื้นฐาน:** ท่าทีขึ้นกับ KAEW_D_RESULT ไม่ใช่การทอยใหม่เพื่อเขียนทับเหตุการณ์ก่อน
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** ถ้าพิธียังบังคับหรือทีมเลือกโจมตี จึงอาจ F3; ถ้าพิธีหยุดแล้วไป F5
- **พลาดแล้วไปต่อ:** หากเคยสลาย D และยังไม่ฟื้น ไม่บังคับ spawn F2/F3

### F3 — Boss Phase 1: พันธนาการ

- **เห็นก่อนถาม:** รากกล้วยเริ่มตรึงพื้นที่ ทีมอาจต้องป้องกันตัวระหว่างปลดกำไล
- **หัวข้อชวนถาม:** จะยืนคุ้มกันคนทำพิธีไหม? / ยังมีทางตัดพลังโดยไม่โจมตีแม่แก้วไหม? / ใครดูแลผู้รอดชีวิต?
- **ข้อมูลพื้นฐาน:** Combat Lite v1.1 ใช้เมื่อเกิดจริง ไม่ใช่ทอยข้อมูลเพิ่ม
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** พิธีที่ทำต่อเนื่องอาจหยุดการบังคับ → F5; ถ้าอาคมยังทำงานอาจเกิด F4
- **พลาดแล้วไปต่อ:** หากไม่มี Combat ทางสังคม/พิธียังดำเนินไปได้ ไม่ต้องสร้าง F3

### F4 — Boss Phase 2: คืนที่น้ำท่วม

- **เห็นก่อนถาม:** ภาพน้ำท่วมซ้อนกับห้องพิธีเมื่อแรงอาคมสูงขึ้น
- **หัวข้อชวนถาม:** ภาพที่เห็นเป็นความทรงจำหรือคำสั่ง? / ใครเป็นคนเปิดประตูผันน้ำ? / ยังมีวิธีหยุดความรุนแรงหรือไม่?
- **ข้อมูลพื้นฐาน:** คำบอกเล่าความทรงจำไม่อาจแทนหลักฐานเต็ม; ใช้เงื่อนไขบอสและพิธีเดิม
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** เมื่อพิธีหยุดหรือลดอันตรายสำเร็จ → F5; ถ้าไม่สำเร็จใช้ F6 เมื่อถึงเวลา
- **พลาดแล้วไปต่อ:** ไม่บังคับเปลี่ยนเป็น Boss Phase 2 หากผู้เล่นจัดการพิธีก่อน

### F5 — Boss Phase 3: อิสรภาพ (เมื่อแกนพิธีถูกหยุด)

- **เห็นก่อนถาม:** เมื่อด้ายขาด แม่แก้วได้ขยับด้วยตัวเองเป็นครั้งแรก และถามว่าผู้เล่นจะทำอย่างไรกับเธอ
- **หัวข้อชวนถาม:** ทีมจะเปิดเผยความจริงอย่างไร? / คนร้ายต้องรับผิดชอบแบบไหน? / แม่แก้วต้องการอะไรเพื่อไม่ทำร้ายใครอีก?
- **ข้อมูลพื้นฐาน:** SOC/SPI DC17 เฉพาะเมื่อต้องโน้มน้าวจริง; หลักฐานและการกระทำมาก่อนการทอย
- **ทอยเพิ่ม:** SOC|SPI DC 17 (`F5_KAEW_RECONCILE`)
- **ทางไปต่อ:** ใช้ RITUAL_STATUS, HOSTAGES_SAFE, หลักฐานและ KAEW_FINAL ตัดสิน Ending ไม่ใช่เมนูเลือกตอนจบ
- **พลาดแล้วไปต่อ:** การทอยพลาดไม่ทำให้แม่แก้วโจมตีทันทีอัตโนมัติ; ทางยุติภัยอื่นยังได้ตามเหตุผล

### F6 — เส้นตาย 03:00

- **เห็นก่อนถาม:** ถึง 03:00 หากพิธียังทำงาน ด้ายเปลี่ยนสีเข้มและแม่แก้วถูกรั้งหนักขึ้น
- **หัวข้อชวนถาม:** ยังถอนตัวพร้อมผู้รอดชีวิตได้หรือไม่? / พิธีที่ฝังแน่นยังปลดได้อย่างไร? / อะไรต้องแก้ก่อนเพื่อรักษาชีวิต?
- **ข้อมูลพื้นฐาน:** เวลา 03:00 ทำให้ RITUAL_STATUS=entrenched ไม่ได้เกมโอเวอร์/ฆ่าคนหายอัตโนมัติ
- **ทอยเพิ่ม:** ไม่มี
- **ทางไปต่อ:** ทำพิธีต่อหรือถอนกำลังตามเหตุการณ์จริง ก่อนสรุป Ending เมื่อคดีสิ้นสุด
- **พลาดแล้วไปต่อ:** ห้ามนับความล้มเหลวเพียงเพราะเวลาผ่าน แต่เพิ่มความยากตามกติกาที่กำหนด
