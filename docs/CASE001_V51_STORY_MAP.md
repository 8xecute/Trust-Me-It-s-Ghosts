# CASE 001 v5.1 — แกนเรื่องและสารบัญก่อนแก้

เอกสารสำหรับ DM และผู้พัฒนา มีความลับคดี ไม่ส่งให้ผู้เล่น

## แกนเรื่อง

วิชัยลักพาตัวดล นิด เพิ่มเพื่อปิดปากและซื้อเวลารอเงินที่ดินก่อนหนี เขาใช้ข่าวผีกดราคาที่ดินและหลอกแม่แก้วว่าจะเปิดโปงเหตุปี 2534 ก่อนบังคับเธอด้วยพิธีด้ายดำ ป้ายชื่อ และกำไลแกนเดียวกัน แม่แก้วเคยช่วยวิชัยคนเดียวเมื่อเขาเป็นเด็กและเสียชีวิตในน้ำท่วม ประเสริฐร่วมรับผิดจากการเปิดประตูผันน้ำก่อนอพยพครบ แต่ยังไม่มีหลักฐานว่าเขาสั่งสูงสุด ยายบุญมีไม่ได้เห็นการเปิดประตูเอง

ผู้เล่นต้องแยกสามงาน: ช่วยคนมีชีวิต เก็บและเปิดเผยหลักฐานคดีมนุษย์ และหยุดการบังคับวิญญาณ การชนะร่างแม่แก้วไม่หยุดพิธี การช่วยคนออกจากเรือนไม่ปลดสายผูก เวลา 03:00 ไม่จบเกม

## ลำดับเวลาและเส้นเบาะแส

23:00 A → ประมาณ 23:20 B → ประมาณ 00:00 C → ประมาณ 00:50 D → ประมาณ 01:40 E → FINAL → ENDING เวลาโดยประมาณไม่บังคับเลื่อนนาฬิกา ใช้ต้นทุนการกระทำจริง

B1 แฟ้มคนหายและแผนที่ที่ดินมาก่อน B2; B5 ชี้สมุด C2 แม้ข้ามต้น; C2 ชี้ศาลและยาย; D1 ปูรอยพื้นก่อน D5; D5 ชี้เรือน E1; E2/E3 ยืนยันผู้ลักพาตัว; E4 ให้หลักฐานและแกนพิธี; H1 ประมวลเอกสารจากแหล่งจริง ไม่วาร์ป NPC การทอยเปลี่ยนความลึก/ความเสี่ยง ไม่ปิดทางหลัก

## ขอบเขตความรู้และอารมณ์

- ประเสริฐกลัวอดีตแต่เลือกขอความช่วยเหลือ ไม่สารภาพตั้งแต่ A
- วิชัยใช้ความจริงบางส่วนบังความผิด ไม่รู้บทสนทนาลับที่ไม่ได้ยิน
- ต้นเห็นคนเข็นห่อคลุมหนัก ไม่เห็นการลักพาตัวหรือมือชัดในสวน
- ยายรู้ประวัติแม่แก้ว ไม่รู้วิธีปลดกำไลหรือผู้ลักพาตัว
- แม่แก้วรู้ผู้บงการแต่ถูกอาคมห้ามกล่าวหา ไม่ใช่ความจำเสื่อม
- ดลโกรธและห่วงเพื่อน นิดกลัวถูกทิ้ง เพิ่มช็อก พูดเฉพาะคนยังมีชีวิตและอยู่จริง

## สารบัญฉาก

- **A1** — ทางเข้า: รถบริษัทถึงหมู่บ้าน (23:00)
- **A2** — วิทยุบริษัทส่งเสียง (บรรยากาศ/ตรวจได้)
- **A3** — จากทางเข้าหมู่บ้านสู่บ้านผู้ใหญ่
- **B1** — บ้านผู้ใหญ่: เปิดแฟ้มคนหายและแผนที่สองชั้น (ประมาณ 23:20)
- **B2** — วิชัย: ผู้รับผิดชอบแผนที่สีน้ำเงิน
- **B3** — ต้น: พยานที่ไม่กล้าพูด
- **B4** — ภาพปี 2534 และแฟ้มเก่า
- **B5** — จากแฟ้มไปบ้านดล
- **C1** — บ้านดล (ประมาณ 00:00)
- **C2** — สมุดดล E02: รูปแบบการขายที่ดิน
- **C3** — เคาะสามครั้ง: สิ่งที่เหลืออยู่หลังน้ำ
- **C4** — ผีเงาจมน้ำ: บทสอนการเผชิญหน้า (Encounter ทางเลือก)
- **C5** — ยายบุญมี: ผู้จำได้ แต่ไม่ได้เห็นทุกอย่าง
- **D1** — เข้าสวนกล้วย (ประมาณ 00:50)
- **D2** — ศาล: ชื่อคนหายบนเส้นด้าย
- **D3** — แม่แก้ว: คนที่อยากบอกแต่ถูกห้าม
- **D4** — เผชิญหน้าแม่แก้วในสวน (optional)
- **D5** — รอยล้อไปยังเรือนไม้
- **E1** — เรือนไม้ร้าง (ประมาณ 01:40)
- **E2** — เปิดห้องใต้ถุน: คนหายทั้งสามยังมีชีวิต
- **E3** — ดล นิด เพิ่ม: ความจริงคนละชิ้น
- **E4** — ห้องพิธี: กำไลของแม่แก้ว
- **E5** — วิชัย: เผชิญหน้ากับคนร้าย (conditional)
- **H1** — คืนปี 2534: ความจริงจากเอกสาร (Flexible Reveal, ไม่ใช่สถานที่)
- **E6** — ก่อนเข้าสู่ Final: เลือกว่าจะรับมืออะไร
- **F1** — เสียงที่ไม่ได้มาจากสวนอีกแล้ว
- **F2** — แม่แก้วจำสิ่งที่ทีมเคยทำในสวน
- **F3** — พันธนาการ: ปกป้องคนทำพิธีหรือปะทะ
- **F4** — คืนที่น้ำไหลกลับมา (conditional Phase 2)
- **F5** — อิสรภาพ: หลังด้ายไม่บังคับอีกต่อไป
- **F6** — 03:00: หนี้เลือดของพิธี (Lethal Variant)

## ตอนจบ

A ความจริงเปิดเผยและไม่มีผู้ตาย; B ช่วยครบแต่ภัยแม่แก้วยังไม่จบ หรือ Vigilante Ghost; C ช่วยไม่ครบ/หลักฐานไม่พอ/มีตัวประกันเสียชีวิตหลังหยุดพิธี; D ผู้เล่นเสียชีวิต หรือยุติทั้งที่พิธียังทำงาน ตรวจตามลำดับ resolver ไม่บังคับจบดี

## แยกข้อมูล

อ่านออกเสียงเฉพาะคำบรรยายและบทที่เข้าเงื่อนไข เป้าหมาย ผู้ที่อยู่จริง สายเบาะแส ทางสำรอง บทเชื่อม DM ลับ และ State Contract อยู่ฝั่ง DM เท่านั้น
