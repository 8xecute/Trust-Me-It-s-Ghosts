# ภาพฉาก CASE 001 v5.5

เพิ่มภาพใหม่ 13 ภาพ โดยอ้างอิงภาพเดิมของเกม รวมเป็น 18 ภาพสำหรับบทฉาก 31 ฉาก ฉากที่อยู่ในห้องและมุมเดียวกันใช้ภาพร่วมกัน ไม่เพิ่มสถานที่หรือเหตุการณ์ในเนื้อเรื่อง

## แนวภาพ

ใช้ภาพวาดสภาพแวดล้อมแบบเดิม: ขอบเส้นเข้ม รายละเอียดไม้เก่าและใบกล้วย แสงจันทร์น้ำเงินเทา โทนน้ำตาลและเขียวหม่น ตัดกับแสงตะเกียงสีอำพัน ไม่มีตัวละครหรือผีฝังในภาพใหม่ เพื่อให้ DM จัดตัวละครตามสถานการณ์จริง ไม่มีข้อความหลักฐานที่อ่านได้ และไม่เผยของที่บทกำหนดให้ซ่อนไว้ใต้โต๊ะ

ไฟล์ runtime อยู่ใน `packages/client/src/assets/case-001/scenes/` เป็น JPEG ขนาด 1672 × 941 เท่าภาพเดิม ทุกภาพใหม่มีขนาดต่ำกว่า 550 KB เก็บต้นฉบับ PNG ที่ได้จากการสร้างภาพแยกไว้ในพื้นที่ generated_images ของเครื่อง ไม่ทับภาพเดิม

## การแสดงผลในเกม

- `sceneArtCatalog.ts` เก็บการจับคู่บทฉากกับไฟล์ภาพ และเลือกภาพจากประวัติบทเปิดที่ส่งถึงผู้เล่นแล้วเท่านั้น
- `sceneArt.ts` โหลด URL ภาพผ่านระบบ asset ของ Vite ภาพยังถูกโหลดตามที่หน้าเกมใช้งาน ไม่ prefetch ทุกภาพ
- `CaseScene.tsx` รองรับภาพรายบทฉาก ขณะ DM จัดฉากใช้บทที่เลือก ส่วนปุ่มดูภาพฝั่งผู้เล่นใช้ประวัติที่ส่งจริง
- `OnlineGame.tsx` และ `DmPlayerView.tsx` ใช้บทเปิดที่ผู้เล่นคนนั้นได้รับ ไม่ใช้ชื่อฉากที่ DM เพิ่งเลือกแต่ยังไม่ได้ส่ง
- `DmWorkspace.tsx` ส่งฉากปัจจุบันให้เครื่องมือ DM และใช้ข้อมูลมุมมองผู้เล่นสำหรับภาพ preview ถ้ามุมมองนั้นยังไม่พร้อม ใช้ภาพสำรองของสถานที่
- `TurnEncounter.tsx` และ `EncounterBoard.tsx` เปลี่ยนเฉพาะแหล่งภาพพื้นหลัง ใช้ภาพห้องบ้านดล/สวน/ห้องพิธีตามบท โดยไม่เปลี่ยนกติกาหรือปุ่มการต่อสู้

การเพิ่มภาพไม่แก้ protocol, State เนื้อเรื่อง หรือเซฟ การวาง NPC ยังเก็บตามสถานที่ A–E ตามระบบเดิม ไม่มีตำแหน่ง NPC แยกรายห้องย่อย DM ต้องจัดว่าตัวละครใดควรแสดงในฉากนั้นด้วยเครื่องมือเดิม
