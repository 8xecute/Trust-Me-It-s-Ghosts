# การจัดภาพฉาก CASE 001

DM เปิดแท็บ **จัดฉาก** ได้โดยไม่ต้องเปิดมุมมองผู้เล่นก่อน ใช้ภาพฉากและ cutout เดิมในเกมจริง

## วิธีใช้งาน

1. เลือกตัวละครจากรายการ สถานะบอกว่ายังไม่วาง ซ่อน หรือแสดงอยู่
2. กด **เลือกจุดวาง** แล้วแตะจุดวางเท้าบนภาพ ตัวละครใหม่จะซ่อนจากผู้เล่นก่อน
3. ลากตัวละครเพื่อย้าย หรือเปิด **ตำแหน่งและขนาด** เพื่อกรอกพิกัดและขนาด การเลือกตัวละครด้วยคลิกไม่ย้ายภาพทันที
4. กด **แสดงให้ผู้เล่น** เมื่อพร้อม ผู้เล่นในสถานที่เดียวกันจะเห็นพร้อมกัน
5. **ซ่อนจากผู้เล่น** เก็บตำแหน่งและขนาดไว้ กดแสดงเพื่อคืนตัวละครเดิมได้ ส่วน **นำออกจากภาพ** ลบเฉพาะตำแหน่งภาพ
6. **ดูภาพฝั่งผู้เล่น** แสดงภาพโดยไม่รวมตัวที่ซ่อน มุมมองผู้สืบสวนในหน้าจัดการห้องยังอ่านข้อมูลตามสิทธิ์ผู้เล่นจริง

ใช้ปุ่มลูกศรเมื่อโฟกัสตัวละครเพื่อขยับทีละ 1% หรือ Shift พร้อมลูกศรเพื่อขยับทีละ 5% แบบฟอร์มเป็นทางเลือกสำหรับคีย์บอร์ดและจอเล็ก การลากที่ถูกยกเลิกไม่ส่งตำแหน่งใหม่

## ภาพและขอบเขต

- พิกัดอิงภาพเต็ม 1672 × 941 ไม่อิงขนาดหน้าจอ ภาพฉากระหว่างเล่นไม่ครอป จึงคงตำแหน่งเมื่อหน้าจอเปลี่ยนขนาด
- จุดยึดอยู่ที่เท้า ตัวที่อยู่ต่ำจะมีขนาดใหญ่ขึ้นและบังตัวด้านหลัง ขนาดที่ DM ปรับได้คือ 60–160% ของขนาดตามระยะ
- จำกัดตัวภาพให้อยู่ในขอบฉาก มีเงาพื้น วงเลือก และป้ายสถานะซ่อน เครื่องมือย้ายลงใต้ภาพบนหน้าจอแคบ
- ลำดับบังกันใช้ตำแหน่งเท้า การเลือกตัวละครไม่ดึงตัวละครนั้นมาหน้าสุด
- ยังไม่มีหน้ากากให้เสา ต้นไม้ หรือเฟอร์นิเจอร์ในภาพพื้นหลังบังตัวละคร DM ต้องเลือกตำแหน่งที่เหมาะกับภาพ

## สิทธิ์และข้อมูล

`dmPlaceNpc` ยังคงใช้ได้เฉพาะ DM ในฉากปัจจุบัน ขณะเปิดเล่นคดีที่ยังไม่จบและไม่มีการเผชิญหน้า ไม่เปิดการเคลื่อนที่อิสระให้ผู้เล่น

ข้อมูลเดิม `{id,x,y}` ยังใช้ได้ เพิ่ม `scale` และ `hidden` เป็นฟิลด์ทางเลือกในตำแหน่งภาพ เซิร์ฟเวอร์ตรวจชนิดและช่วงค่าก่อนบันทึก คำสั่งย้ายจาก client เก่าที่ส่งเฉพาะ x/y จะรักษาขนาดและสถานะซ่อนเดิม

ตัวที่ซ่อนถูกตัดออกจาก snapshot ผู้เล่น, snapshot ที่ไม่มีผู้ดู และ DM preview ของผู้เล่นตั้งแต่เซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนด้วย CSS รายการตัวละครทั้งหมดอยู่เฉพาะเครื่องมือ DM ในหน้าจอ ส่วนภาพผู้เล่นแสดงเฉพาะตัวที่ DM เปิดเผยในสถานที่นั้น ป้ายภาพผู้เล่นไม่แสดงคำใบ้เฟสบอส

การจัดภาพแก้เฉพาะ `caseMap.npcPlacements` ไม่เปลี่ยนสถานะ NPC ในเรื่อง สถานที่ของทีม เนื้อเรื่อง การส่งบท เทิร์น หรือค่าตัวละคร การซ่อนภาพไม่ใช่การเปลี่ยนเงื่อนไขเนื้อเรื่อง

## ผลตรวจ 14 พฤศจิกายน 2026

- ตรวจชนิดข้อมูลและ production build ผ่าน โดยตั้ง `VITE_SERVER_URL` ตามค่าที่ระบุในเอกสาร deploy
- ทดสอบ client 24 ข้อผ่าน รวมพิกัดที่ความกว้างภาพ 340, 768 และ 1440 พิกเซล และขอบภาพทุกด้านที่ขนาด 60%, 100%, 160%
- ทดสอบ placement และ session 14 ข้อผ่าน ครอบคลุมสิทธิ์ DM, ค่าไม่ถูกต้อง, การเก็บ State เนื้อเรื่องเดิม, พื้นที่แยกตามสถานที่, เซฟเดิม และ portable save
- ทดสอบ Socket.IO ผ่านด้วย DM หนึ่งคนและผู้เล่นสองคน ตรวจวาง ย้าย ซ่อน คืน นำออก ข้อมูลลับ และการคืนตำแหน่งหลังหยุดแล้วเปิดเซิร์ฟเวอร์ใหม่
- ชุด smoke ของ session และการส่งบท 5.1/5.2 ผ่าน ชุด `production-smoke.test.mjs` เดิมไม่ผ่านที่บรรทัด 140 เพราะยังคาดว่า `askGm` ใช้ได้ แต่คำสั่งนี้ถูกเลิกใช้แล้วใน HEAD ก่อนงานฉาก ไม่แก้ชุดทดสอบเก่านี้ในงานฉาก
- เครื่องนี้ขาดไฟล์ CLI ของ `tsx` จึงรันทดสอบ TypeScript ผ่าน loader ที่มีอยู่ใน `.local-logs/encounter-test-loader.mjs` แทน ไม่เพิ่ม dependency
- ยังไม่ได้ยืนยันภาพจริงหรือ gesture บน desktop/mobile: Computer Use หยุดก่อนควบคุม Chrome เพราะยืนยัน URL ปัจจุบันไม่ได้ การตรวจพิกัดเชิงคำนวณไม่ทดแทนการตรวจภาพจริง

สิ่งที่ต้องตรวจผ่านหน้าจอต่อ: วางและลากด้วยเมาส์/สัมผัส ตรวจเงาและป้ายชื่อเมื่อซ้อนกัน เปิด/ปิดตัวที่ซ่อน ตรวจภาพผู้เล่นพร้อมกัน และ resize ขณะมีตัวละครอยู่ รวมทั้งหน้าเข้าห้องซึ่งใช้ภาพชุดเดียวกัน
