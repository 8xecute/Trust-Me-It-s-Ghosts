# DM-controlled encounter start: v5.5

In v5.5 rooms with a human DM, only the DM can open C4, D4, and the Final encounter. The DM workspace shows a start button when the current scene has been presented, an eligible encounter exists, and a living active investigator is present at that site.

The server selects an eligible investigator to initialize the encounter without giving the DM a player character. Player start requests and direct Final-release actions are rejected. Public player menus omit the old start buttons. Final still requires the existing key, approached core, scene, and ritual conditions.

Starting is blocked while paused, during an existing encounter, or while roll requests remain pending. The DM must still publish the encounter opening before player actions become available. The new start command does not roll player dice, spend a player's action, or change combat rules.

Older versions and rooms without a human DM retain their existing behavior. Saves require no migration.
