# ปรับหน้าเกมและระบบเล่นต่อ

วันที่ 14 พฤศจิกายน 2026

## สิ่งที่เปลี่ยน

- ใช้ theme ร่วมสำหรับหน้าผู้เล่นและ DM เพิ่มมิติของพื้นผิว แสงเงา ปุ่ม สถานะที่เลือก และ focus สำหรับคีย์บอร์ด พร้อม layout responsive และ reduced motion
- ตัวละครแสดงเป็นการ์ดอาชีพทั้งหก เมื่อเลือกแล้วแสดงสถานะเลือกแล้ว แยกปุ่มเปลี่ยนตัวละคร/ชื่อ ยกเลิกการแก้ไข และยกเลิกการเลือกจริงก่อนเริ่มคดี ตัวละครที่เพื่อนเลือกแล้วกดเลือกซ้ำไม่ได้
- รวมชื่อผู้เล่นและชื่อในเกมเข้ากับการเลือกตัวละคร พร้อมอัปเดตชื่อในข้อมูลกลางและตัวละครให้ตรงกัน
- หน้าแรกแยกเริ่มคดีใหม่และเล่นต่อจากเดิม ผู้เล่นใช้สิทธิ์ในเครื่องเดิมหรือรหัสส่วนตัว DM เลือกไฟล์ ตรวจข้อมูลก่อนกดยืนยันนำเข้า ไม่มีการนำเข้าทันทีเมื่อเลือกไฟล์
- เก็บสิทธิ์กลับเข้าจากการสร้าง/เข้าห้องในเครื่องเดิม เมื่อห้องไม่พบยังเก็บสิทธิ์ไว้เพื่อกลับเข้าได้หลัง DM นำเข้าเซฟ พร้อมข้อความบอกขั้นตอนถัดไป
- หน้า DM ที่โหลดมาในสถานะพักเปิดหน้าจัดทีมโดยอัตโนมัติ แสดงการเชื่อมต่อจริงแยกจากรายชื่อที่บันทึกไว้ พักตัวละครของผู้ขาดได้ และไม่ให้เริ่มต่อหากสมาชิกที่เลือกยังไม่กลับครบ
- DM พักและดาวน์โหลดเซฟได้ในปุ่มเดียว คัดลอกรหัสรายคนได้ทันทีหลังโหลดเซฟ โดยไม่ต้องดาวน์โหลดเซฟซ้ำ รหัสทั้งหมดตรวจสิทธิ์ DM บนเซิร์ฟเวอร์ ไม่อยู่ใน public snapshot
- เก็บการจัดการคำขอค้าง การย้อนบท และการปิดคดีไว้ในส่วนคำสั่งรอง ไม่เปลี่ยนกติกาเนื้อเรื่อง การทอย หรือ combat
