# ตรวจแผงบันทึกเหตุการณ์ของ DM — CASE001 v5.5

วันที่ 14 พฤศจิกายน 2026 ตรวจ working tree ปัจจุบันแบบอ่านโค้ด ยังไม่ลบระบบหรือเปลี่ยน State

## เหตุที่ยังมีแผงในภาพ

DmWorkspace.tsx แสดง DmStoryEvents จาก storyEvents ของ server แยกจาก DmAdjudication ซึ่งเป็นแผงการ์ดทอย
การถอดตัวเลือกสำรวจทั่วไปออกจากแผงทอยจึงไม่ได้ถอดแผงบันทึกเหตุการณ์นี้

รายการ wichai-route:called / followed เขียน wichaiArrival53.reason ส่วน wichai-arrived เขียน arrived และย้ายวิชัยไป E
wichaiHere51, allowedGuidedScenes และ QA ใช้ตรวจว่าเขามาถึงจริงก่อนเปิด E5 หรือให้บทพูด
ปัจจุบันเสนอตัวเลือกเส้นทางตั้งแต่ B/C/D/E เมื่อวิชัยเป็นอิสระและส่งฉากแล้ว ไม่ได้แปลว่าเหตุโทรหาหรือการตามมาเกิดขึ้นแล้ว

## ข้อจำกัด UI ที่ต้องแก้ก่อนตัดเพิ่ม

DmAdjudication รับเฉพาะ option.check แล้ว จึงไม่แสดง search-ritual-bag, approach-ritual-core, escort และ begin-final55
OnlineGame ซ่อน caseActions ในโหมด DM-led ส่วน DmWorkspace ยังมี entry.choices ในส่วนเครื่องมือรายคน
ต้องตรวจ projection ของ actions/choices และทดสอบเส้นทาง UI จริงก่อนสรุปว่าปุ่มเหล่านี้มีทางใช้งานครบ
ห้ามลบ reducer หรือซ่อน event ที่จำเป็นโดยไม่มีทางบันทึกการลงมือจริงทดแทน

## ลำดับเสนอ

1. ย้ายข้อมูลการเดินทางวิชัยไปส่วน NPC ลดตัวเลือกนอกบริบทในหน้าดำเนินเกม
2. จัดปุ่มบันทึกเฉพาะวัตถุ/พยาน/เอกสารไว้กับฉากที่เกี่ยวข้อง
3. รวมขั้นซ้ำเฉพาะเมื่อ Action เดียวพิสูจน์ผลทั้งคู่จริง และคงทางอ่านโดยไม่เก็บ
4. ถอดปุ่มที่อ้างข้อสรุปเกินหลักฐาน และย้ายการติดต่อประเสริฐให้ตรงบทล่าสุด
5. ทดสอบเริ่ม B, ช่วยคนใน E2, อ่าน/ค้น E4, วิชัยมา/ไม่มา, เริ่ม Final และ Ending ก่อน commit

## ผลแก้ตามคำอนุมัติในแชท

- ย้ายเหตุเดินทาง/มาถึง/หลบหนีของวิชัยไปแฟ้ม NPC คงคำสั่งและ guard การมาถึงจริง
- แยกเอกสารและหลักฐานออกจากรายการผลเหตุการณ์ทั่วไป
- เพิ่มปุ่มปฏิสัมพันธ์ที่มีผลต่อ State แบบไม่ทอย: ตรวจหลักฐาน ค้นกระเป๋า เข้าถึงแกน และพาคนออกจากห้อง โดยใช้เฉพาะตัวเลือกที่ server ส่งให้ผู้ลงมือ
- ไม่คืนปุ่มสำรวจทั่วไปหรือเงินล่วงหน้าเข้าแผงทอย
- v5.5 ไม่เสนอ collect-flood ซ้ำกับ read-gate; การอ่านบันทึกจริงยังเพิ่ม E07 และบันทึกแหล่งข้อมูล
- v5.5 ไม่เสนอ flood-people-proven เพื่อไม่เปิดข้อสรุปเกินเอกสารที่มี
- ย้าย contactPrasert ของ v5.5 ไป F5 หลังหยุดพิธีและมี gate-truth; server ปฏิเสธการเรียกก่อนเวลา ไม่ทำให้รับสายเท่ากับสารภาพหรือเปิดเผยหลักฐาน
- คงเส้นทางรุ่นก่อน v5.5 ตามเดิม
