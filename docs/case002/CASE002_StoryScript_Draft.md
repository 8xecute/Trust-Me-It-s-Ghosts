## วิธีใช้บทและขอบเขตที่ห้ามข้าม

- อ่านเฉพาะข้อความใน **DM อ่านให้ผู้เล่น** และคำตอบที่ผ่านเงื่อนไขแล้ว หัวข้อฉากและส่วนอื่นเป็นข้อมูล DM ไม่ใช่ข้อความส่งผู้เล่น
- ผู้เล่นประกาศเป้าหมายและวิธีเอง DM ตรวจก่อนว่าทำได้แน่ ต้องทอยตามการ์ด หรือเป็น Situational Check ที่กติกาปัจจุบันรองรับ ไม่เสนอเมนูคำถามหรือเมนูทอยให้ผู้เล่น
- Q&A เป็นคำตอบเมื่อถูกถามจริง การเปิดอ่าน Q&A ไม่ให้หลักฐาน ไม่เปลี่ยน State ไม่ทำให้ NPC มาถึง และไม่ทำให้ผู้เล่นรู้ข้อความนั้น
- การเล่า/ตอบสำเร็จให้บันทึกผู้รับข้อมูล แหล่งข้อมูล และเหตุการณ์จริง แยกข้อสังเกต คำให้การ ข้อสันนิษฐาน และหลักฐาน ห้ามใช้การเปิดหัวข้อเป็น Event
- ไม่มี Timer, Countdown, การตายจากเวลาที่ผ่านไป หรือการย้ายตัวละครอัตโนมัติ ประยูรเดินตามหรือแยกจากทีมได้เฉพาะเมื่อมีการตัดสินใจและเดินทางจริง
- มนุษย์จริงในคืนปัจจุบันมีเฉพาะทีมบริษัท ประยูร และอิง บุคคลในเอกสารอดีตไม่กลายเป็น NPC ที่อยู่คืนนี้ แสงสี พ่อค้า ผู้ชม และนักแสดงอื่นเป็นภาพลวงตา วิญญาณ หรือหุ่น
- ทุกฝ่ายรู้ข้อมูลเท่าที่พบหรือได้รับบอกจริง เมื่อรวมทีมแล้วไม่รวมสมุด/ความรู้ให้อัตโนมัติ การพูดให้เพื่อนฟังคือเหตุให้เพิ่มผู้รับข้อมูล
- `C002-CHECK-01` ถึง `08` เป็นข้อเสนอจุดทอย มี Trigger เฉพาะและเส้นทางไม่ต้องทอย ตัวเลขยังไม่อนุมัติ ห้ามนำไปกดทอยด้วย DC ที่เดาเอง
- การ์ดสืบสวนไม่ใช่ Attack Roll การบาดเจ็บ การตาย และผลเครื่องสังเวยต้องอ้างอิง Action และ Combat Resolution จริง การมองเห็นผีไม่อนุญาตให้ Server เปลี่ยน HP หรือตำแหน่งจริง
- หากร่างนายโรงถูกสลายก่อน FINAL ให้คงผลนั้นและดำเนินการขัดพิธี/อพยพต่อจากสภาพจริง การคืนร่างต้องผ่าน D04 ที่อนุมัติพร้อม Event จริง ห้ามคืนร่างหรือ auto-respawn เพียงเพราะเปลี่ยนฉาก

## ความจริงสำหรับ DM

ครูสิงห์เคยเป็นหัวหน้าคณะมหรสพเร่ที่ควบคุมและหลอกใช้ผู้คน เขาจัดฉากให้ศักดิ์ฆ่าชด น้องชายของศักดิ์ โดยเชื่อว่าผู้สวมหน้ากากเป็นปีศาจ หลังตาย ครูสิงห์กลายเป็นนายโรง พิธีปิดโรงประจำปีกดอำนาจของมัน ปีนี้มีการปรับปรุงเวทีและพิธีไม่สมบูรณ์ นายโรงจึงใช้อำนาจ Physical และภาพลวงตาได้ตั้งแต่ต้นคดี

งานสำหรับประชาชนเลิกตั้งแต่คืนที่เจ็ด คืนที่แปดที่ทีมเห็นไม่ใช่งานซึ่งมีผู้เที่ยวงานเป็นมนุษย์ นายโรงต้องการให้มนุษย์ที่ยังมีชีวิตฆ่ามนุษย์ที่ยังมีชีวิตจริงในเขตการแสดงที่กำหนด จึงจะอยู่ถาวร การฆ่าด้วยมือนายโรง ผี หรือหุ่นไม่นับ การบาดเจ็บ/หมดสติไม่นับเป็นการตาย พิธีปิดโรงเดิมใช้สะกดกลับไม่ได้หลังเงื่อนไขสำเร็จ

ขอบเขตพื้นที่การแสดงต้องล็อกใน State Contract ก่อนใช้เงื่อนไขสังเวย ห้ามวาดขอบเขตย้อนหลังให้ครอบจุดตาย หากยังไม่ล็อก ให้ผลการสังเวยเป็นรอตัดสินจากหลักฐานเหตุการณ์ ไม่แต่งคำตอบสำเร็จ/ไม่สำเร็จ

## NPC: แหล่งความรู้และท่าที

| ผู้สวมบท | รู้จริง | ไม่รู้ | ปิดบัง/เหตุผล | เงื่อนไขให้ข้อมูลเพิ่ม |
|---|---|---|---|---|
| ประยูร | อิงเป็นลูกสาว หายหลังเข้าเขตโรง; งานจริงจบคืนเจ็ด; ปีนี้ซ่อมเวทีและพิธีไม่ครบ; นายโรงเสนอคืนลูกแลกกับการพาทีมเข้ามา | เงื่อนไขสังเวย รายละเอียดการตายในอดีต ตำแหน่งอิงขณะนี้ วิธีหยุดหลังสังเวย | กลัวทีมปฏิเสธช่วยลูก จึงลดทอนความอันตรายและไม่พูดข้อตกลงตั้งต้น | ถามเรื่องลูกตรง ๆ ให้ยอมรับว่าหาย; แสดงหลักฐานงานเลิกแล้วให้ยอมรับคืนเจ็ด; ชี้ความเสี่ยงที่เขาปิดบังและเปิดโอกาสช่วยลูกโดยไม่รับรองความผิดให้ เขายอมบอกข้อเสนอโดยไม่ต้องบังคับทอย |
| อิง | ประสบการณ์ของตัวเอง เสื้อ/รูป/ข้อความของตัวเอง ถูกพาตัวเข้าหลังเวที เคยได้ยินถ้อยคำขู่และเห็นหน้ากาก | แผนที่ทุกห้อง ชื่อผู้ตายในอดีต สูตรพิธีและเงื่อนไขสังเวยครบถ้วน | กลัวคนมองเธอเป็นศัตรู หยุดพูดเมื่อผู้ถืออาวุธเข้าประชิด | ให้พื้นที่ปลอดภัย ลดอาวุธ แสดงหลักฐานของเธอ หรือถามเรื่องส่วนตัวที่เธอตอบได้; ไม่ต้องผ่านการทอยเพื่อให้เธอมีสิทธิ์ร้องขอความช่วยเหลือ |

ผีผู้แสดงหน้ากากเป็นศัตรู ไม่มีชื่อมนุษย์ ประวัติส่วนตัว หรือบทสนทนาเพิ่ม มันมีหน้ากากไม้สีขาว คอเอียง ลากอาวุธเหล็ก และเข้าจู่โจมด้วยร่างที่จับต้องได้ ลักษณะนี้เป็นต้นแบบภาพลวงตา ACT D

## แผนพื้นที่เชิงเรื่องและการเดินทาง

ทางเข้า/ลานจอดรถ → ลานซุ้มและจุดเอกสาร → หน้าโรงเก่า → ทางแยกหลังเวที → ทางเก็บอุปกรณ์ (C2) / ห้องแต่งตัว (C3) → โถงกลาง → ห้องพักด้านหลังที่พบอิง → เวทีการแสดง

ทั้ง C2 และ C3 มีทางเดินจริงกลับโถงกลาง ไม่มีประตูปิดเพราะต้องบังคับแยกทีม ทีมเดียวสำรวจสองฝั่งตามลำดับได้ ประยูรต้องมีตำแหน่งแยกต่างหาก ไม่ย้ายไปทั้งสองทีมพร้อมกัน อิงเริ่มซ่อนอยู่ห้องพักด้านหลัง; ให้ร่องรอย C2/E1 นำไปถึงได้ แม้ไม่พบเอกสาร C3 การใช้ผังนี้เป็นข้อเสนอเนื้อเรื่อง ไม่กำหนดระยะโจมตีหรือ Movement เพิ่ม

## ACT A — คืนที่แปด

### A1 — ทางเข้าเขตงานวัด

**🎯 เป้าหมาย:** ให้ทีมเห็นความไม่สอดคล้องและได้จุดเริ่มตรวจเวที โดยเริ่มหลังบริษัทรับงานแล้ว

**👥 ตัวละครที่อยู่จริง:** ทีมที่มาถึง ประยูรที่ทางเข้า; อิงไม่อยู่ตรงนี้

**🧭 Action-Driven — DM ONLY:** Visible Cue คือลานจอดรถโล่งกับเสียงงานด้านใน ผู้เล่นอาจเทียบทางเข้า ป้าย ร้านค้า หรือถามประยูร ตรวจสิ่งที่มองเห็นชัดไม่ทอย; `C002-CHECK-01` ใช้เมื่อประกาศตรวจรายละเอียดที่ถูกเสียง/แสงบดบัง Situational Check ใช้เฉพาะความเสี่ยงที่ Core รองรับ Fail-forward คือประยูรชี้จุดเอกสารและเวทีได้แม้ไม่ตรวจ

**🎬 DM อ่านให้ผู้เล่น**

> รถบริษัทหยุดหน้าประตูวัด ด้านในมีแสงหลอดไฟทอดยาว เสียงเพลงกับเสียงประกาศแทรกกันจนฟังไม่ชัด แต่ลานจอดรถข้างประตูกลับว่างเกือบทั้งหมด ชายคนหนึ่งกำแฟ้มไว้แนบอก เขารีบเดินมาหาพวกคุณ แล้วหันมองทางเวทีเก่าหลังซุ้มร้านค้า

**🗣️ NPC Dialogue — ประยูรเมื่อเข้าพบ:** “ผมประยูรครับ ทางบริษัทคงแจ้งงานแล้ว ผมอยากให้ช่วยตรวจแถวเวทีเก่า มีอะไรบางอย่างผิดปกติ ผมไม่กล้าเข้าไปคนเดียว”

**💬 Q&A — เปิดเฉพาะเมื่อถามจริง**

- **A1-Q01 ทำไมไม่มีรถ?** ประยูรอยู่และถูกถาม: “ผมเห็นลานเงียบตั้งแต่กลับมาครับ แต่ข้างในยังเป็นอย่างที่เห็น” เขากำลังเลี่ยงเรื่องงานเลิกแล้ว; DM ไม่รับรองว่าเขาพูดครบ
- **A1-Q02 มีใครหายหรือไม่?** ถามตรง: “อิง ลูกสาวผมยังไม่กลับออกมา ผมขอให้ช่วยหาเธอด้วย” เขาไม่ทราบห้องที่ซ่อน; เมื่อบอกจริงให้บันทึกผู้รับ ไม่รอ B4 เพื่อยอมรับชื่อ
- **A1-Q03 เข้าออกได้ไหม?** ตรวจทางจริง: “ทางเข้ายังเปิด รถอยู่จุดเดิม ไม่มีสิ่งใดปิดถนนที่คุณเห็น” ไม่รับรองความปลอดภัยทั่วพื้นที่และไม่สร้างกำแพงผี

**🔎 เบาะแส:** พื้นฐาน ลานรถกับเสียงงาน; สืบสวน รอยเก็บป้ายบางส่วนด้านหลังป้ายใหม่; สำคัญ E01 เฉพาะส่วนที่เห็นจริง; สำรอง จุดเอกสารที่ประยูรบอกตำแหน่ง

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ให้ความผิดปกติทันที งานจบคืนเจ็ดเมื่ออ่านกำหนดการ/ถามตรง ไม่เฉลยภาพลวงตาหรือเงื่อนไขสังเวยในบทเปิด

**🎲 Dice Cards:** `C002-CHECK-01` ตัวเลข Pending; ไม่ใช้เพื่ออนุญาตเห็นลานรถว่าง

**🔒 DM ONLY:** CASE_ACCEPTED เริ่มจริงจากภารกิจบริษัทแล้ว การซักประยูรไม่ทำให้เขารู้กลไกสังเวย รอยเก็บป้ายเป็นหลักฐานประกอบไม่ใช่คำเฉลย

**➡️ ไปต่อ:** เมื่อทีมเดินเข้าเขตซุ้มใกล้เวที เปิดสัญญาณ A2; หากยังถามอยู่ให้ตอบตามรู้ ไม่เริ่มโจมตีเพราะคุยนาน

### A2 — เสียงเหล็กบนพื้น

**🎯 เป้าหมาย:** ให้พบภัย Physical และจำรูปลักษณ์ศัตรูตั้งแต่ต้น โดยผู้เล่นมีหน้าต่างลงมือ

**👥 ตัวละครที่อยู่จริง:** ทีมตามตำแหน่งจริง ผีผู้แสดงหน้ากาก; ประยูรเฉพาะถ้ายังเดินอยู่กับทีม

**🧭 Action-Driven — DM ONLY:** Visible Cue คือเสียงลากเหล็ก เงาคอเอียง และท่าเตรียมพุ่ง ผู้เล่นอาจหลบ ตั้งรับ คุ้มกัน ถอย หรือโจมตีตามกติกาจริง ไม่มี Scripted Check สืบสวนแทน Combat; Situational Check ไม่แทน Attack Roll Fail-forward คือถอยตามทางเปิดได้และจำลักษณะได้แม้ไม่ชนะ

**🎬 DM อ่านให้ผู้เล่น**

> เสียงเหล็กครูดพื้นดังมาจากช่องระหว่างซุ้ม ร่างหนึ่งก้าวออกมา หน้ากากไม้ขาวสะท้อนแสงเป็นรอยยิ้ม คอของมันเอียงผิดมุม ปลายอาวุธเหล็กลากผ่านพื้นจนเกิดร่อง มันหยุดหันมาทางพวกคุณ แล้วยกอาวุธเตรียมพุ่งเข้าใส่

**🗣️ NPC Dialogue:** ผีไม่มีบทพูด หากประยูรอยู่หลังแนวทีม เขาพูด “เหมือนที่ผมเห็น... ระวังครับ!” แล้วทำได้เฉพาะสิ่งที่ตำแหน่ง/การกระทำรองรับ ไม่ทำหน้าที่รับดาเมจแทนโดยอัตโนมัติ

**💬 Q&A**

- **A2-Q01 มันอยู่ตรงไหน?** เห็นแนวโจมตี: DM ชี้ช่องระหว่างซุ้มและตำแหน่งจริงที่บันทึกแล้ว ไม่เพิ่มระยะหรือทำให้วาร์ป
- **A2-Q02 เหล็กโดนพื้นจริงไหม?** ตรวจหรือมองรอยใกล้ตัวโดยปลอดภัย: “พื้นมีรอยขูดใหม่ตรงที่ปลายเหล็กผ่าน” ยังไม่ใช่หลักฐานว่าการโจมตีครั้งต่อไปโดนอัตโนมัติ
- **A2-Q03 ขอถอยได้ไหม?** ตรวจทางเดิม: “ช่องกลับทางเข้ายังเปิด คุณบอกได้ว่าจะถอยอย่างไร” ให้ Resolve การเคลื่อนที่/โอกาสโจมตีตามกฎที่มี ไม่สั่งให้หนีสำเร็จฟรี

**🔎 เบาะแส:** พื้นฐาน หน้ากาก คอเอียง เสียงเหล็ก; สืบสวน รอยขูด; สำคัญ E02 ตามสิ่งที่สัมผัส/เห็นจริง; สำรอง A3 ตรวจรอยหลังเหตุ

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** รูปลักษณ์ให้ทันที ผลจับต้องได้ให้ตามรอย/การต่อสู้ ไม่บอกว่ารูปลักษณ์นี้จะใช้แทนเพื่อนภายหลัง

**🎲 Dice Cards:** ไม่มี ใช้ Encounter ที่ผูก Enemy Preset อนุมัติแล้วเท่านั้น

**🔒 DM ONLY:** First Encounter เป็นเจตนาโจมตีจริง ไม่ใช่ HP หายจากบท Enemy Preset ยัง Pending จึงยังไม่ใช่ฉากที่ runtime พร้อมเปิดเล่น ห้ามตีความ “เป็นฝ่ายโจมตีก่อน” ว่าได้สิทธิ์ข้ามลำดับกติกา

**➡️ ไปต่อ:** เมื่อปะทะจบตามผลจริงหรือทีมพ้นแนวภัย เปิด A3 ณ จุดที่ทีมอยู่ ไม่คืน HP/ย้ายผี/ประกาศชนะให้เข้าบท

### A3 — ร่องรอยหลังเสียงเงียบ

**🎯 เป้าหมาย:** ให้ทีมประเมินผลจริง เห็นท่าทีประยูร และมีทางไปเอกสาร

**👥 ตัวละครที่อยู่จริง:** ผู้ที่อยู่หลังเหตุ; ประยูรต้องยังมีชีวิตและอยู่ในระยะสนทนาจึงพูดได้

**🧭 Action-Driven — DM ONLY:** Visible Cue คือรอยเหล็กและมือประยูรที่กำแฟ้ม ผู้เล่นอาจรักษา ตรวจร่องรอย หรือถามเรื่องที่เขารู้ ไม่มีการ์ดบังคับ การช่วยเหลือตามกฎเดิม; Fail-forward ป้ายจุดจัดงานและทางเข้าโรงยังนำไป B1/B2 ได้แม้เขาไม่ยอมพูด

**🎬 DM อ่านให้ผู้เล่น**

> เมื่อเสียงเหล็กไม่ได้ประชิดอีกแล้ว คุณกลับมาได้ยินเพลงจากลานด้านหน้า ร่องบนพื้นยังอยู่ ไฟตามซุ้มไม่ได้เปลี่ยนไปตามสิ่งที่เพิ่งเกิด แฟ้มกระดาษของจุดจัดงานวางอยู่ใต้ป้ายลูกศรไปโรงมหรสพเก่า

**🗣️ NPC Dialogue — ประยูรถ้าอยู่:** “ผมควรบอกให้มากกว่านี้ มีบันทึกอยู่ที่จุดจัดงาน แล้วก็มีสมุดเก่าของโรง ผมอยากให้คุณดูด้วยตัวเอง”

**💬 Q&A**

- **A3-Q01 คุณเคยเห็นมันหรือ?** ถ้าประยูรพูดประโยคใน A2 แล้วถูกถาม: “เคยเห็นอยู่แถวเวทีครับ ผมไม่รู้ว่ามันคือใคร ผมกลัวว่าถ้าบอกทั้งหมดจะไม่มีใครมา” ไม่รู้ประวัติผีหน้ากาก
- **A3-Q02 มีคนช่วยอยู่ข้างในหรือไม่?** ประยูรถูกถาม: “ผมไม่ได้เห็นใครที่ยืนยันได้ตั้งแต่กลับมาคืนนี้ ผมตามหาอิงอยู่” ไม่สร้างคนงาน/รปภ.ช่วยทีม
- **A3-Q03 ต้องกลับไปตามเอกสารที่ไหน?** อ่านป้ายหรือถาม: “โต๊ะจัดงานอยู่ริมลาน ส่วนโรงเก่าเดินตามป้ายจากตรงนั้นได้” เส้นทางหลักไม่ถูกล็อกด้วยการถาม NPC

**🔎 เบาะแส:** พื้นฐาน ร่องรอยคงอยู่; สืบสวน คำหลุดและแฟ้ม; สำคัญ E02 เพิ่มเฉพาะส่วนที่ตรวจจริง; สำรอง ป้ายและแฟ้มที่เปิดอ่านได้

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ข้อเท็จจริงภัย Physical ไม่ยืนยันว่าคนทุกคนในงานเป็นผี ความกลัวประยูรไม่ใช่หลักฐานว่าเขารู้เงื่อนไขสังเวย

**🎲 Dice Cards:** ไม่มีการ์ดใหม่ การรักษา/ใช้ Ability อ้างคำสั่งจริง

**🔒 DM ONLY:** หากประยูรตายหรือแยกไป ให้ตัดบทพูดทั้งหมด คดีไปต่อจากป้ายและเอกสารได้ ความตายต้องมี Resolution และ cause ID เดิม

**➡️ ไปต่อ:** ทีมเดินไปลาน B1 หรือเลือกตรงไปโต๊ะเอกสาร B2 ได้ บันทึกแค่การเดินทางและข้อมูลที่รับจริง

## ACT B — งานวัดที่ไม่มีคนจริง

### B1 — ซุ้มที่เปิดอยู่ในภาพ

**🎯 เป้าหมาย:** ให้ตรวจความขัดแย้งของประสาทสัมผัสโดยไม่ต้องเชื่อ DM ล่วงหน้า

**👥 ตัวละครที่อยู่จริง:** ทีมตามพื้นที่ ประยูรถ้ามาด้วย; ภาพพ่อค้าและผู้ชมไม่ใช่มนุษย์ใหม่

**🧭 Action-Driven — DM ONLY:** Visible Cue คือท่าทางซ้ำและโต๊ะที่ภาพกับสัมผัสไม่ตรงกัน ผู้เล่นอาจเรียก ซื้อของ มองด้านหลัง หรือสัมผัสโดยระวัง ไม่ทอยเพื่อเห็นร้านเก็บแล้วเมื่อเดินถึงหลังร้าน; Situational Check เฉพาะวิธีเสี่ยง Fail-forward เห็นแฟ้มกำหนดงานที่โต๊ะจัดงานได้โดยไม่ต้องพิสูจน์ภาพทุกซุ้ม

**🎬 DM อ่านให้ผู้เล่น**

> คนขายในซุ้มตักของลงถ้วยแล้ววางตรงมุมเดิม คนที่ยืนหน้าโต๊ะเอื้อมมือรับ ก่อนท่าทางทั้งคู่จะเริ่มขึ้นอีกครั้ง ด้านหลังซุ้มมีผ้าใบม้วนและกล่องวางปิดทางเข้าเล็กน้อย แต่เสียงเรียกขายยังดังจากด้านหน้าตามปกติ

**🗣️ NPC Dialogue:** ภาพซ้ำใช้เพียง “เชิญทางนี้” ตามจังหวะเดิม ไม่ตอบข้อมูลใหม่ ถ้าประยูรอยู่และถูกถาม เขาพูด “นี่ไม่ใช่แบบตอนที่ผมจัดร้านไว้”

**💬 Q&A**

- **B1-Q01 คนขายตอบคำถามฉันไหม?** เรียกถามจริง: “เสียงประโยคเดิมดังขึ้นอีกครั้งโดยไม่ตอบสิ่งที่คุณถาม” ห้ามให้คำใบ้ผ่าน NPC ปลอมที่รู้ทุกอย่าง
- **B1-Q02 ของในถ้วยมีจริงหรือไม่?** ตรวจสัมผัสอย่างปลอดภัย: “มือคุณผ่านตำแหน่งถ้วยไปถึงโต๊ะที่แห้ง มีเพียงถ้วยคว่ำเก็บไว้อีกฝั่ง” เป็นผลเฉพาะซุ้มนี้
- **B1-Q03 แปลว่าทุกอย่างเป็นภาพหรือ?** ถามเพื่อสรุป: “ตอนนี้คุณยืนยันได้เฉพาะสิ่งที่ตรวจตรงนี้ รอยเหล็กจากการปะทะยังไม่หายไป” แยกข้อค้นพบกับข้อสันนิษฐาน

**🔎 เบาะแส:** พื้นฐาน ท่าซ้ำ; สืบสวน สัมผัสโต๊ะจริง; สำคัญ E01 เพิ่มความขัดแย้ง; สำรอง กำหนดการ B2

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ตรวจซุ้มให้รู้ซุ้มนั้น ไม่เผยภาพลวงตาของ ACT D หรืออิงล่วงหน้า

**🎲 Dice Cards:** ไม่มีการ์ดบังคับ ห้ามสร้างการทอยซื้อของเพื่อเปิดเนื้อเรื่อง

**🔒 DM ONLY:** ห้ามให้ภาพร้านค้าทำดาเมจจากคำบรรยาย หากมีหุ่น Physical ต้องเปิด Action/Encounter ตามกฎ ไม่เปลี่ยนภาพพ่อค้าเป็นมนุษย์เมื่อผู้เล่นทำร้าย

**➡️ ไปต่อ:** เส้นทางสู่โต๊ะจัดงาน B2 และโรงเก่า B3 เปิดจริง ผู้เล่นเลือกตรวจตามลำดับใดก็ได้

### B2 — หน้าสุดท้ายของกำหนดงาน

**🎯 เป้าหมาย:** ยืนยันว่างานประชาชนจบคืนเจ็ด และให้เหตุย้อนหลังเป็นข้อมูล ไม่สร้างเหยื่อมนุษย์คืนนี้เพิ่ม

**👥 ตัวละครที่อยู่จริง:** ทีมที่เข้าถึงโต๊ะเอกสาร ประยูรถ้าอยู่; ผู้มีชื่อในบันทึกไม่อยู่ในฉาก

**🧭 Action-Driven — DM ONLY:** Visible Cue คือกำหนดการเจ็ดคืนกับแฟ้มเหตุ ผู้เล่นอาจอ่าน เทียบลำดับ ถ่ายสำเนา หรือถามประยูร อ่านกำหนดงานชัดเจนไม่ทอย; `C002-CHECK-02` สำหรับวิเคราะห์เหตุซ้ำจากหลายหน้า Fail-forward หน้าสุดท้ายมีข้อความปิดงานและทิศทางโรงเก่า

**🎬 DM อ่านให้ผู้เล่น**

> กระดาษกำหนดงานถูกหนีบไว้ใต้แผ่นใส มีช่องคืนที่หนึ่งถึงคืนที่เจ็ด ช่องสุดท้ายเขียนว่า “ปิดงานสำหรับประชาชน” อีกแฟ้มมีรอยพับและหมึกแก้หลายแห่ง หน้าหนึ่งบันทึกเหตุทะเลาะเพราะจำคนผิด อีกหน้าระบุการบาดเจ็บใกล้เวทีเก่า

**🗣️ NPC Dialogue — ประยูรเมื่อเห็นหลักฐาน:** “ใช่ครับ งานเลิกเมื่อคืนที่เจ็ด ผมกลับมาเพราะลูกยังไม่ออกมา ผมไม่ควรให้พวกคุณคิดว่าคืนนี้ยังมีคนเที่ยวอยู่จริง”

**💬 Q&A**

- **B2-Q01 มีรายการคืนแปดไหม?** เปิดตรวจ: “กำหนดการสาธารณะไม่มีรายการนั้น มีเพียงหมายเหตุให้เก็บของหลังปิดงาน” ไม่บอกว่าใครเป็นนายโรง
- **B2-Q02 คนในแฟ้มยังติดอยู่คืนนี้หรือไม่?** อ่านเฉพาะเอกสาร: “แฟ้มเป็นเหตุคืนก่อน ไม่ยืนยันว่าบุคคลเหล่านั้นอยู่ที่นี่ในตอนนี้” มนุษย์ปัจจุบันยังมีเพียงทีม/ประยูร/อิง
- **B2-Q03 ที่จำผิดมีอะไรเหมือนกัน?** เทียบหลายเหตุจริง: ให้ผลการ์ดหากเปิดใช้แล้ว หรือข้อความที่อ่านได้ว่าแต่ละเหตุสัมพันธ์กับหน้ากาก/แสงเวที ไม่อ้างว่าเจ้าทุกข์เห็นตัวตนจริง

**🔎 เบาะแส:** พื้นฐาน งานจบคืนเจ็ด; สืบสวน รูปแบบเหตุซ้ำ; สำคัญ E03; สำรอง สำเนาบางหน้า C3 และประยูรยอมรับเฉพาะสิ่งที่รู้

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ยืนยันงานเลิกแล้วได้ทันทีเมื่ออ่าน เหตุคนจำผิดเป็นเบาะแส ไม่ใช่คำเฉลยว่าทุกศัตรูคือมนุษย์

**🎲 Dice Cards:** `C002-CHECK-02` Pending; เส้นทางไป B3 ไม่ขึ้นกับผลทอย

**🔒 DM ONLY:** ไม่มีรายการเหตุใหม่เพราะผ่านเวลา ห้ามตั้งผู้บาดเจ็บในเอกสารเป็น NPC สด ไม่มีการยกระดับ “คนหาย” ในบันทึกเป็นตายจากการอ่าน

**➡️ ไปต่อ:** แฟ้มระบุว่าของจากเวทีเก่าเก็บที่โรงและมุมอาสา เปิด B3/B4 โดยไม่ต้องย้อนถามประยูร

### B3 — พิธีที่หยุดกลางหน้า

**🎯 เป้าหมาย:** ปูเหตุที่นายโรงกลับมา และฐานวิธีรับมือก่อน FINAL โดยยังแยกข้อเสนอที่ไม่ล็อก

**👥 ตัวละครที่อยู่จริง:** ทีมหน้าโรง ประยูรเฉพาะถ้ามาด้วย ไม่มีครูพิธีคนใหม่

**🧭 Action-Driven — DM ONLY:** Visible Cue คือแนวไม้ซ่อมใหม่ทับร่องเก่า สมุดพิธีเปิดค้าง ผู้เล่นอาจตรวจเทียบผัง/รอยจริง อ่านประวัติ หรือถ่ายภาพ ข้อความว่าปีนี้ทำไม่ครบอ่านได้ฟรี; `C002-CHECK-03` สำหรับวิเคราะห์ความสัมพันธ์ Fail-forward ผังชี้ห้องแต่งตัวและโถงกลางชัด

**🎬 DM อ่านให้ผู้เล่น**

> ไม้ใหม่สีอ่อนตัดกับพื้นโรงเก่าที่คล้ำกว่า ร่องบนพื้นขาดช่วงตรงแนวซ่อม สมุดบนหิ้งมีหัวข้อ “ปิดโรงประจำปี” หน้าปัจจุบันมีเครื่องหมายหยุดไว้กลางรายการ ข้างกันเป็นภาพคณะมหรสพซีดจาง ชื่อครูสิงห์เขียนอยู่ใต้คนที่ยืนกลางภาพ

**🗣️ NPC Dialogue — ประยูรถ้าอยู่:** “ซ่อมเวทีปีนี้ครับ พิธีทำไม่ครบจริง ผมคิดว่าจะกลับมาจัดให้เรียบร้อยทีหลัง ผมไม่รู้ว่าจะเป็นแบบนี้”

**💬 Q&A**

- **B3-Q01 พิธีนี้ทำเพื่ออะไร?** อ่านหัวข้อและหมายเหตุ: “หมายเหตุบอกว่าใช้กดอำนาจผู้ครองโรง ไม่ใช่กำหนดการแสดงทั่วไป” ให้ข้อความเอกสาร ไม่ประกาศวิธีชนะพร้อมตัวเลข
- **B3-Q02 ครูสิงห์คือใคร?** อ่านใต้ภาพ: “ภาพระบุว่าเป็นหัวหน้าคณะมหรสพเร่” ประยูรรู้เพียงชื่อจากของเก่า ไม่รู้การฆ่าศักดิ์/ชดครบถ้วน
- **B3-Q03 ทำพิธีให้ครบตอนนี้ได้เลยไหม?** ผู้เล่นเสนอจริง: “คุณมีร่องรอยและขั้นตอนบางส่วน แต่ยังต้องตรวจว่าตรงกับสิ่งที่กำลังเกิดหรือไม่” DM แจ้งข้อจำกัดที่เห็น ห้ามใช้คำนี้บังคับให้สืบครบก่อนช่วยคน; กลไก FINAL รออนุมัติ

**🔎 เบาะแส:** พื้นฐาน พิธีปีนี้ไม่ครบ; สืบสวน ความเชื่อมโยงรอยซ่อมกับผัง; สำคัญ E04; สำรอง สำเนาผัง C3

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** รู้ฐานพิธีเดิมก่อน รู้ข้อยกเว้นหลังสังเวยเมื่ออ่านหลักฐานเกี่ยวข้อง ไม่บอกว่าแก้ไม้ชิ้นเดียวแล้วชนะ

**D05 — ตรวจจุดยึดจริง:** เมื่อผู้เล่นตรวจฐานข้างเสาเวที ให้เห็นรอยไม้ทรงยาวกับส่วนตรึงที่เก่ากว่าแผ่นซ่อม ภาพเก่าที่หยิบมาดูมีครูสิงห์ถือไม้ชิ้นลักษณะเดียวกัน ยังไม่บอกว่าเป็นวิธีชนะทันที บันทึก E12 เฉพาะข้อสังเกตที่ตรวจและผู้รับจริง; แหล่งอธิบายสำรองอยู่ C3/E4

**🎲 Dice Cards:** `C002-CHECK-03` Pending; ผล Full ไม่ใช่การทำพิธีสำเร็จ

**🔒 DM ONLY:** นายโรงมี Physical ก่อน FINAL แล้ว การอ่านสมุดไม่สร้างร่างหรือเพิ่มพลังบอส ขั้นตอนหยุดฉบับเล่นจริงต้องเลือกจาก Pending Design Decision ก่อนเขียนให้เป็น Canon

**➡️ ไปต่อ:** ป้ายของอาสาและผังหลังเวทีให้ไป B4/B5 ได้ การสืบไม่ผ่านไม่ล็อกทาง

### B4 — รอยเย็บบนเสื้ออาสา

**🎯 เป้าหมาย:** ให้รู้จักอิงผ่านของส่วนตัวและมีสิ่งเปรียบเทียบตัวตนใน E2

**👥 ตัวละครที่อยู่จริง:** ทีมที่มุมอาสา ประยูรถ้าอยู่; อิงอยู่ห้องพักด้านหลัง ไม่ปรากฏจากการเปิดรูป

**🧭 Action-Driven — DM ONLY:** Visible Cue คือภาพอิงกับเสื้ออาสาที่มีรอยเย็บด้านแขน ผู้เล่นอาจอ่านบันทึกสั้น เก็บสำเนา หรือถามพ่อ ไม่มี Scripted Check; ไม่มีการทอยเพื่อรู้ชื่อเจ้าของที่เขียนชัด Fail-forward ถ้าข้ามจุดนี้ C2 มีเศษผ้าและ E2 ให้อิงพูด/ยืนยันตัวตนได้

**🎬 DM อ่านให้ผู้เล่น**

> มุมเก็บของมีภาพหญิงสาวสวมเสื้ออาสา ใต้ภาพเขียนชื่อ “อิง” แขนเสื้อในภาพมีรอยเย็บด้ายสว่างเป็นรูปเล็ก ๆ ในสมุดข้างภาพมีข้อความว่า “ของหายไว้ตรงนี้นะ เดี๋ยวหนูช่วยหาเจ้าของ” หน้าถัดไปเว้นว่างไว้

**🗣️ NPC Dialogue — ประยูรถ้าอยู่และพร้อมพูด:** “เธอชอบอาสาเก็บของคืนเจ้าของครับ รอยตรงแขนเสื้อนั่นเธอเย็บเอง ผมอยากเห็นเธอเดินออกมามากกว่าสิ่งอื่นแล้ว”

**💬 Q&A**

- **B4-Q01 เป็นรูปปัจจุบันหรือไม่?** ตรวจภาพ/ถามประยูร: ภาพสัมพันธ์งานปีนี้ตามป้ายที่ติดอยู่ พ่อจึงยืนยันเสื้อที่ลูกใส่ได้ ไม่ยืนยันว่าเธอยังใส่ครบทุกชิ้นตอนนี้
- **B4-Q02 มีข้อความขอความช่วยเหลือไหม?** เปิดดูสมุดจริง: “หน้าที่เห็นเป็นงานอาสา ไม่มีตำแหน่งขังหรือรหัสลับที่เขียนไว้” ไม่เสกแผนที่ช่วยคนจากความสำเร็จทั่วไป
- **B4-Q03 เธอรู้อะไรเรื่องโรง?** ประยูรถูกถาม: “เธอช่วยงาน ไม่ได้เป็นคนทำพิธี ผมไม่รู้ว่าเธอไปเห็นอะไรหลังเวที” การคาดคั้นไม่เพิ่มความรู้พ่อ

**🔎 เบาะแส:** พื้นฐาน ชื่อและรูป; สืบสวน ลายเย็บและข้อความ; สำคัญ E05; สำรอง C2/E2

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ของส่วนตัวสร้างจุดเปรียบเทียบ ไม่รับรองว่าร่างทุกคนที่ใส่เสื้อเดียวกันคืออิง ให้ผู้เล่นตรวจอย่างน้อยความสัมพันธ์จริงก่อนยืนยัน

**🎲 Dice Cards:** ไม่มี ไม่ทอยเพื่อปลดล็อกความผูกพัน

**🔒 DM ONLY:** ไม่ตั้งให้อิงตายเพราะทิ้งบันทึกไว้ ไม่ทำให้ประยูรสารภาพข้อเสนอนายโรงจากการเปิดรูปอัตโนมัติ

**➡️ ไปต่อ:** เส้นทางงานอาสาระบุว่าของจากหลังเวทีผ่านทางข้างโรง จึงไป B5 ได้

### B5 — สองทิศทางหลังม่าน

**🎯 เป้าหมาย:** เสนอทางเลือกจริงไป C1 โดยไม่บังคับแยกทีม

**👥 ตัวละครที่อยู่จริง:** ทีมหน้าแนวทางหลังเวที ประยูรตามตำแหน่งที่เลือก

**🧭 Action-Driven — DM ONLY:** Visible Cue เสียงคล้ายคนร้องทางหนึ่งและตู้เครื่องแต่งกายอีกทาง ผู้เล่นเลือกไปด้วยกัน แบ่งทีม หรือจัดคุ้มกันได้เอง ไม่มี Scripted Check หาทางไม่ต้องทอยเมื่อทางเปิดชัด Fail-forward ป้ายโถงกลางมีทั้งสองทางเชื่อมถึงกัน

**🎬 DM อ่านให้ผู้เล่น**

> ทางข้างโรงแยกออกสองช่อง ด้านหนึ่งมีรอยลากผ่านฝุ่นและเสียงสั้น ๆ คล้ายคนพยายามเรียก อีกด้านมีเสื้อการแสดงแขวนพ้นตู้ที่เปิดอยู่ เหนือทางแยกมีป้ายเก่าชี้ว่าเดินอ้อมจากทั้งสองด้านไปโถงกลางได้

**🗣️ NPC Dialogue — ประยูรถ้าอยู่:** “ด้านนั้นเป็นที่เก็บอุปกรณ์ อีกด้านเป็นห้องแต่งตัวครับ ผมยังไม่พบลูกในสองจุดนี้” เขาไม่ยืนยันว่าเสียงเป็นอิงจากระยะนี้

**💬 Q&A**

- **B5-Q01 ต้องไปพร้อมกันทั้งสองทางหรือไม่?** เห็นทางจริง: “ไม่มีประตูหรือกลไกที่ต้องเปิดพร้อมกัน คุณเลือกสำรวจตามวิธีของทีมได้” ไม่สร้างแรงกดดันเวลา
- **B5-Q02 ตะโกนหาเพื่อนได้หรือไม่?** ผู้เล่นเลือกลอง: Resolve ตามผังและสิ่งกีดขวางจริง ให้เฉพาะคนที่ได้ยินข้อความนั้น ไม่เปิดสมุดอีกทีม
- **B5-Q03 ประยูรจะไปกับใคร?** ถ้าอยู่และถาม: “ผมอยากตามรอยคนหาย แต่จะฟังว่าพวกคุณจัดให้ผมอยู่ตรงไหน” การย้ายต้องเกิดจริง ไม่ทำตามทุกกลุ่มพร้อมกัน

**🔎 เบาะแส:** พื้นฐาน สองทางและทางกลับ; สืบสวน รอยลาก/เสื้อ; สำคัญ เส้นไป E06/E07; สำรอง เดินสำรวจทีละด้าน

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** เสียงเป็นสิ่งได้ยิน ไม่ใช่ชื่อผู้ร้อง หลักฐาน C2 ไม่ส่งให้ C3 อัตโนมัติ

**🎲 Dice Cards:** ไม่มี

**🔒 DM ONLY:** ไม่ปิดทางเพื่อให้แบ่งทีม ไม่มีขนาดทีมตายตัวในเรื่อง รองรับ 1/1 ถึง 3/3 ด้วยการเลือกจริง

**➡️ ไปต่อ:** เมื่อทีมตกลงและเดินจริง เปิด C1 เพื่อบันทึกแผนเดินทาง ก่อนเล่าเฉพาะเส้นที่แต่ละคนถึง

## ACT C — ทางที่เลือกเอง

### C1 — หน้าทางแยกหลังเวที

**🎯 เป้าหมาย:** บันทึกการแบ่งกลุ่มจากการตัดสินใจจริง ให้ทุกคนมีตำแหน่งและขอบเขตข้อมูลชัด

**👥 ตัวละครที่อยู่จริง:** ทุกคนที่ยังอยู่ทางแยก ประยูรถ้ายังอยู่กับทีม; ไม่มีการสร้างผู้คุ้มกันเพิ่ม

**🧭 Action-Driven — DM ONLY:** Visible Cue คือป้ายสองทางและสภาพทางที่ตรวจได้ ผู้เล่นเลือกสมาชิก ลำดับสำรวจ วิธีสื่อสาร และตำแหน่งประยูร ไม่ต้องทอยเพื่อแบ่งทีม ไม่มี Scripted Check Fail-forward ถ้าไม่แบ่งให้ทุกคนเดิน C2 แล้ว C3 หรือสลับกัน โดยร่องรอยหลักยังอยู่

**🎬 DM อ่านให้ผู้เล่น**

> พื้นหลังม่านมีรอยลากเลี้ยวไปทางเก็บอุปกรณ์ ส่วนประตูห้องแต่งตัวอีกฝั่งเปิดค้างอยู่ ทางเดินทั้งสองยังผ่านได้ ป้ายโถงกลางเหนือหัวช่วยให้คุณกะทิศกลับมาพบกันได้ ตอนนี้ทุกคนยังยืนอยู่ใกล้กันพอจะตกลงแผนก่อนเดินต่อ

**🗣️ NPC Dialogue — ประยูรถ้าถูกจัดตำแหน่ง:** “ผมจะอยู่ตามที่ตกลงครับ ถ้าพบอะไรเกี่ยวกับอิง ช่วยบอกผมด้วย” เขาต้องได้ยินแผนจริงจึงรู้ว่าจะรอที่ใด

**💬 Q&A**

- **C1-Q01 แบ่งหนึ่งคนต่อทางได้ไหม?** เมื่อผู้เล่นสองคนเลือก: “ทางทั้งสองไม่ต้องใช้คนเปิดพร้อมกัน แต่คนที่แยกไปจะรับรู้เฉพาะสิ่งที่อยู่กับตัว” ไม่มีบทลงโทษลับจากจำนวนคน
- **C1-Q02 ไปด้วยกันทั้งหมดได้ไหม?** เมื่อเลือก: “ได้ คุณเลือกด้านแรกและลำดับกลับมาอีกด้านได้” ห้ามตีความว่าเลี่ยงพล็อตจึงต้องโดนดาเมจ
- **C1-Q03 ติดต่อกันอย่างไร?** ตรวจอุปกรณ์ที่มีจริง: ให้ใช้เสียง/ช่องทางเดิมที่มี ไม่สร้างวิทยุหรือแชทโทรจิต ไม่มีการส่งข้อมูลทุกชิ้นให้อีกกลุ่มเอง

**🔎 เบาะแส:** พื้นฐาน ทางเปิด; สืบสวน แนวเสียงและรอยลาก; สำคัญ แผนเดินทางที่ทุกคนรับรู้; สำรอง ป้ายโถงกลาง

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ชื่อทีม A/B เป็นข้อมูล DM ไม่ใช่สิทธิ์เห็นข้อมูลกัน แต่ละคนรู้แผนที่ได้ฟังเท่านั้น

**🎲 Dice Cards:** ไม่มี

**🔒 DM ONLY:** ขนาดแบ่งมาตรฐานรองรับ 2 คน 1/1, 3 คน 1/2, 4 คน 2/2, 5 คน 2/3, 6 คน 3/3 โดยไม่บังคับใช้สัดส่วนนี้ ความรู้เดิมคงอยู่เมื่อย้ายกลุ่ม แต่ความรู้สมาชิกอื่นไม่ไหลตาม

**➡️ ไปต่อ:** อัปเดตตำแหน่งเมื่อเดินถึงจริงแล้วเล่า C2 หรือ C3 ให้เฉพาะผู้รับ; หากประยูรรอตรงนี้ เขาไม่ตอบคำถามของกลุ่มที่เดินพ้นระยะ

### C2 — ทางเก็บอุปกรณ์

**🎯 เป้าหมาย:** ให้รอยผู้สูญหายและจุดเปรียบเทียบศัตรู โดยไม่ยืนยันว่าผู้ถูกลากตายแล้ว

**👥 ตัวละครที่อยู่จริง:** คนที่เข้าทางเก็บอุปกรณ์ ประยูรเฉพาะถ้าเดินมาด้วย; อิงยังอยู่ห้องพักที่ไกลกว่านี้

**🧭 Action-Driven — DM ONLY:** Visible Cue เศษผ้า รอยเชือก และร่องเหล็ก ผู้เล่นอาจตามรอย เปรียบเทียบเสื้อ หรือฟังหาจุดเสียง การเดินตามรอยชัดไปโถงกลางไม่ทอย; `C002-CHECK-04` ใช้แยกรอยคนกับรอยอุปกรณ์ทับซ้อน Fail-forward ประตูห้องพักมีผ้าที่ติดค้างเป็นทางไป E1 แม้ตรวจรายละเอียดไม่สำเร็จ

**🎬 DM อ่านให้ผู้เล่น**

> ทางแคบมีเชือกหล่นพาดขาหีบ ปลายเชือกครูดฝุ่นเป็นเส้นไปด้านใน เศษผ้าสีเดียวกับเสื้ออาสาติดอยู่ตรงตะปู ข้างรอยลากมีร่องเหล็กอีกแนวหนึ่งที่ลึกกว่า จากหลังฉากด้านหน้าได้ยินเสียงหายใจสะดุดแล้วเงียบลง

**🗣️ NPC Dialogue:** ไม่มีผู้พูดใหม่ ถ้าประยูรอยู่และได้ตรวจเศษผ้า เขาพูดได้เพียง “สีเหมือนเสื้อเธอครับ ขอให้ยังอยู่ข้างใน” ไม่ยืนยันตัวผู้หายจากสีผ้าอย่างเดียว

**💬 Q&A**

- **C2-Q01 รอยลากเป็นศพหรือไม่?** ตรวจรอยจริง: “รอยนี้บอกว่ามีสิ่งถูกลาก ยังไม่บอกว่าคนที่เกี่ยวข้องมีชีวิตหรือเสียชีวิต” ห้ามยืนยันความตายจาก Check
- **C2-Q02 ใช่ร่องอาวุธเดิมหรือไม่?** เทียบกับ A2/E02 ที่ผู้ถามรู้จริง: ให้ความเหมือนด้านรูปทรง/วัสดุที่ตรวจได้ ไม่ยืนยันว่าทุกร่างหน้ากากเป็นผีตัวเดียว
- **C2-Q03 เสียงมาจากไหน?** ฟังหาทิศในตำแหน่งนี้: “จากแนวห้องด้านหลังโถงกลาง ไม่ใช่จากประตูห้องแต่งตัวที่คุณเพิ่งผ่าน” ยังไม่บอกชื่ออิง

**🔎 เบาะแส:** พื้นฐาน รอยและเสียง; สืบสวน รอยเหล็กเทียบรอยคน; สำคัญ E06 และ E05 เฉพาะส่วนผ้าที่ได้ตรวจ; สำรอง E1 จุดห้องพัก

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ให้เฉพาะคนที่อยู่ C2 ถ้าผู้เล่นตะโกนบอกเพื่อน บันทึกข้อความจริงและผู้ได้ยิน ไม่ส่งรายละเอียดแฟ้มอีกฝั่งกลับมาแลกเอง

**🎲 Dice Cards:** `C002-CHECK-04` Pending; ทอยพลาดยังตามแนวไปโถงกลางได้

**🔒 DM ONLY:** ไม่ใช้เสียงหายใจเป็น countdown ถ้าผู้เล่นถึงห้องอิงก่อน D ให้รับการช่วยเหลือตามจริง ไม่ย้ายอิงหนีเพื่อบังคับ ACT D

**➡️ ไปต่อ:** เดินไป C4 หรือกลับสำรวจ C3 ได้ หากตามรอยถึงห้องจริง เปิด E1 ก่อนลำดับบทได้โดยบันทึกสิ่งที่ข้ามเป็นยังไม่เกิด

### C3 — ห้องแต่งตัวและกระดาษเก่า

**🎯 เป้าหมาย:** ปูการหลอกให้ฆ่ากันผ่านหลักฐานอดีตและเครื่องแต่งกาย ไม่มี NPC อดีตโผล่มาเล่าทั้งหมด

**👥 ตัวละครที่อยู่จริง:** ทีมที่ถึงห้อง ประยูรเฉพาะถ้ามา; ครูสิงห์ ศักดิ์ และชดมีเพียงชื่อ/ภาพในเอกสาร

**🧭 Action-Driven — DM ONLY:** Visible Cue หน้ากากแขวนกับภาพที่เห็นคนเดียวกันก่อนและหลังสวม ผู้เล่นอาจตรวจอุปกรณ์ อ่านแฟ้ม หรือเทียบประวัติ อ่านหน้ากระดาษที่ชัดไม่ทอย; `C002-CHECK-05` ใช้จัดความสัมพันธ์จากหน้าที่ขาด/ซ้อน Fail-forward สำเนาข้อความสำคัญ E4 อ่านได้อีกครั้งโดยไม่กลับมาห้องนี้

**🎬 DM อ่านให้ผู้เล่น**

> หน้ากากไม้แขวนเรียงเหนือโต๊ะเครื่องแป้ง ใต้กระจกมีภาพคนสองคนในชุดธรรมดา กับอีกภาพที่คนหนึ่งสวมหน้ากาก ใบข่าวเก่าถูกพับใส่สมุดการแสดง ชื่อ “ศักดิ์” และ “ชด” ถูกขีดเส้นไว้ ใต้ชื่อครูสิงห์มีประโยคว่า “คนถืออาวุธเชื่อว่ากำลังช่วยพี่น้องของตน”

**🗣️ NPC Dialogue:** ไม่มีคนในเอกสารพูดสด ให้ DM อ่านข้อความในฐานะเอกสารเท่านั้น ประยูรถ้ามีอยู่ตอบได้ว่า “ผมเคยเห็นของพวกนี้ แต่ไม่ได้รู้เรื่องของทุกคนในรูป”

**💬 Q&A**

- **C3-Q01 ศักดิ์กับชดเป็นใคร?** อ่านหน้าที่มีชื่อ: “เอกสารระบุว่าเป็นพี่น้อง ศักดิ์ลงมือฆ่าชดโดยเชื่อว่าร่างใต้หน้ากากเป็นปีศาจ” ระบุที่มาของข้อกล่าว ไม่สวมว่าผู้เล่นเห็นเหตุจริง
- **C3-Q02 ครูสิงห์ทำอะไร?** ตรวจเอกสารที่เกี่ยวข้อง: “ข้อความกล่าวว่าเขาเป็นผู้จัดฉากให้เกิดความเข้าใจผิด แล้วเรียกมันว่าการแสดง” หากอ่านเพียงรูปยังไม่แจกข้อมูลหน้านี้
- **C3-Q03 ถอดหน้ากากแล้วภาพลวงหมดทุกครั้งไหม?** ตรวจหน้ากากจริง: “หน้ากากในห้องเป็นสิ่งของ การถอดชิ้นนี้พิสูจน์ได้เฉพาะผู้สวมชิ้นนี้ ภาพที่เห็นคืนนี้อาจต้องตรวจมากกว่าของที่สวม” ไม่สร้างกฎถอดไอเทมแล้วล้างสถานะทั้งฉาก

**🔎 เบาะแส:** พื้นฐาน คนกับหน้ากากต่างภาพ; สืบสวน ลำดับการจัดฉาก; สำคัญ E07; สำรอง สำเนาในแฟ้มเวที E4 และการตรวจเชิงกายภาพ D/E

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** รูปให้ข้อสงสัย เอกสารให้เรื่องอดีต การตรวจภาพลวงปัจจุบันจึงให้ E08 อย่าให้ประวัติทำให้เห็นเพื่อนจริงทันทีโดยไม่มี Action

**D05 — อ่านสมุดอุปกรณ์จริง:** เมื่อเปิดหน้ารายการที่เกี่ยวข้อง DM อ่านว่า “หน้ากากเป็นของสวมในการแสดง ไม้ครูอยู่กับฐานข้างเสาเดิม ผู้ครองโรงยึดโรงผ่านของนั้น” ให้แผนผังตำแหน่งเป็นเอกสาร ไม่ตั้ง State ว่าจุดยึดถูกตัด ประยูรไม่รู้กลไกนี้ก่อนรับข้อมูล E4 มีสำเนา ไม่ต้องย้อนหา NPC

**🎲 Dice Cards:** `C002-CHECK-05` Pending; ข้อเตือนว่าอย่าตัดสินคนจากหน้ากากไม่ถูกล็อกด้วยการทอย

**🔒 DM ONLY:** สำเนาผังพิธี E04 มีอยู่เพื่อเส้นสำรอง ไม่ต้องเก็บสำเนาครบสองชิ้น ห้ามขยายเป็นวิญญาณศักดิ์/ชดมาเป็นมนุษย์ปัจจุบันหรือศัตรูใหม่

**➡️ ไปต่อ:** ผังทางหลังเวทีและร่องอุปกรณ์นำสู่โถงกลาง C4 ถ้าเป็นทีมเดียว ให้เลือกสำรวจ C2 เพิ่มหรือไปต่อได้

### C4 — ทางกลับที่ยังเป็นทางเดิม

**🎯 เป้าหมาย:** ให้กลุ่มกลับพบกันด้วยการเดินจริง และเปิด ACT D เมื่อมีเป้าหมายรับรู้ที่อยู่จริง

**👥 ตัวละครที่อยู่จริง:** คนที่เดินถึงขอบโถงกลางตามลำดับ ประยูรตามตำแหน่งที่บันทึก ไม่ทำให้สมาชิกที่ยังอยู่ห้องอื่นมาถึงพร้อมกัน

**🧭 Action-Driven — DM ONLY:** Visible Cue ทางเดินเปิดถึงโถงและเสียงฝีเท้าจากอีกด้าน ผู้เล่นอาจเรียก ใช้รหัส หรือรอเพื่อน ไม่มี Scripted Check เพื่อย้ายกลุ่ม Fail-forward กลุ่มไม่แยกเดินเข้าต่อกันได้; D ใช้ฉบับทีมเดียวหรือข้ามโจมตีโดยไม่บังคับแยกใหม่

**🎬 DM อ่านให้ผู้เล่น**

> ทางเดินเปิดสู่โถงที่มีม่านเก่าห้อยเป็นแถบ ตำแหน่งประตูตรงกับป้ายที่คุณผ่านมา แสงจากเวทีส่องลอดช่องผ้าเป็นเส้นบนพื้น คุณได้ยินเสียงฝีเท้าจากทางเชื่อมอีกฝั่งเมื่อมีคนเดินเข้ามาถึงจริง

**🗣️ NPC Dialogue:** ไม่มีบทพูดบังคับ ถ้าประยูรมาถึงพร้อมทีม เขาพูด “จากโถงนี้ไปห้องพักด้านหลังได้ครับ” ตามผังที่รู้ ไม่บอกว่าอิงอยู่ประตูไหนแน่

**💬 Q&A**

- **C4-Q01 เพื่อนมาถึงแล้วหรือ?** ตรวจตำแหน่งจริง: ตอบเฉพาะสิ่งที่เห็น/ได้ยิน ไม่ยืนยันชื่อก่อนตรวจ หากยังไม่มีใครเข้ามา ห้ามใช้เสียงคนเดินเป็นหลักฐานว่าเพื่อนอยู่ตรงนั้น
- **C4-Q02 เรียกชื่อกันก่อนได้ไหม?** เมื่อประกาศ: ให้ข้อความไปถึงผู้ที่ได้ยินจริง และ Resolve การตอบตามผู้เล่นอีกฝ่าย ไม่สร้างคำตอบแทนเพื่อน
- **C4-Q03 ถ้าไม่เคยแยกทีมจะเกิดอะไร?** DM ใช้บทฉบับทีมเดียว: เห็นเงาคนที่เดินในแถวถูกบิดรูปลักษณ์ แต่ตำแหน่ง/อุปกรณ์ต่อเนื่องทำให้ตรวจได้ง่าย ไม่ต้องสร้างกลุ่มปลอม

**🔎 เบาะแส:** พื้นฐาน ผังทางตรงกัน; สืบสวน เสียง/อุปกรณ์ต่อเนื่อง; สำคัญ ตำแหน่งจริงของผู้มาถึง; สำรอง เดินกลับมารวมโดยไม่ปะทะ

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** DM เห็นตำแหน่งจริง ผู้เล่นได้เพียงภาพ/เสียงของฝ่ายตน การเปิดฉากไม่รวมความรู้ C2/C3

### D3 — มุมของฝ่ายถูกโจมตี

**🎯 เป้าหมาย:** เปลี่ยนมุมมองหลังฝ่ายโจมตีทอย ให้ฝ่ายรับใช้เฉพาะการตอบสนองที่กฎอนุญาต

**🗣️ NPC Dialogue:** ไม่มีบทบังคับ ฝ่ายรับพูดเตือนเพื่อนได้ตามสถานการณ์ แต่คำพูดไม่ย้อนยกเลิกผลทอยที่เกิดแล้ว การหยุดการโจมตีต้องมาจากหน้าต่างตอบสนองที่กฎรองรับ

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** เปิดชื่อผู้โจมตีให้ฝ่ายรับหลัง Attacker Roll ไม่ส่ง mapping จริงของผู้รับกลับให้ฝ่ายโจมตีก่อนเงื่อนไขเปิดโปง ผล miss ไม่ทำ HP หาย

**🎲 Dice Cards:** ไม่มี; `CASE002_DEFENSIVE_ROLL` อนุมัติด้านแบบแล้วและแยกจาก Dice Cards ยังไม่เปิด runtime

**🔒 DM ONLY:** ฉากนี้ไม่อนุญาต Guard ฟรีย้อนหลัง ไม่ให้ป้องกันสองชั้น หาก Runtime ยังแยก roll กับ resolve ไม่ได้ ต้องทำระบบรองรับก่อนเปิดฉากจริง ห้ามแก้ผลด้วยมือเพื่อจำลองว่ามี Reaction

**➡️ ไปต่อ:** บันทึกการตอบสนองหรือการผ่านหน้าต่าง แล้ว Resolve D4 หนึ่งครั้งจากผลโจมตีและการป้องกันชุดเดียวกัน

### D4 — ผลที่เกิดกับคนจริง

**🎯 เป้าหมาย:** คงผลทางกายภาพและแยกการพลาด บาดเจ็บ หมดสติ และตายอย่างถูกต้อง

**👥 ตัวละครที่อยู่จริง:** คู่เหตุการณ์เดิมและผู้ที่อยู่ในตำแหน่งเห็นผล

**🧭 Action-Driven — DM ONLY:** Trigger คือข้อมูลโจมตี/รับมือครบตามกฎ Commit Damage หนึ่งครั้ง ผู้เล่นอาจหยุดต่อสู้ เรียกชื่อ ช่วยเหลือ หรือคุ้มกันหลังผลจริง ไม่มี Scripted Check เปลี่ยนผลย้อนหลัง Fail-forward พลาดก็ยังตรวจเสียง รหัส หรืออุปกรณ์เพื่อรวมทีมได้

**🎬 DM อ่านให้ผู้เล่น — เลือกเฉพาะผลจริง**

> **พลาด/ป้องกันได้:** การโจมตีไม่ทำอันตรายเป้าหมายตามผลที่ตัดสิน คุณได้ยินเสียงจากร่างตรงนั้นชัดขึ้น ขณะนี้คุณยังเลือกหยุดแล้วฟังสิ่งที่อีกฝ่ายพยายามบอกได้
>
> **โดนผู้เล่นร่วมทีมจริงและยังมีชีวิต:** เมื่อการโจมตีถึงตัว สิ่งที่คุณเห็นกับบาดแผลตรงหน้ากลับไม่สอดคล้องกัน ใต้ภาพหน้ากากคือเพื่อนร่วมทีมของคุณ เขาได้รับผลบาดเจ็บตามที่ผู้ดำเนินเรื่องยืนยันจริง
>
> **โดน NPC มนุษย์จริงและยังมีชีวิต:** เมื่อการโจมตีถึงตัว ภาพหน้ากากไม่สอดคล้องกับมนุษย์ที่ได้รับบาดเจ็บตรงหน้าอีกแล้ว ผู้ดำเนินเรื่องยืนยันผลบาดเจ็บจากการโจมตีของคุณตามจริง แต่ชื่อและความเกี่ยวข้องต้องอาศัยสิ่งที่คุณได้ตรวจหรือได้รับบอกแล้ว
>
> **เสียชีวิตที่ Resolve แล้ว — ใช้ได้ทั้งเป้าหมายผู้เล่นและ NPC:** ภาพที่บิดรูปลักษณ์ไม่อาจปิดบังผลที่เกิดกับร่างมนุษย์ตรงหน้าได้อีก ผู้ดำเนินเรื่องยืนยันผลเสียชีวิตจากเหตุการณ์ที่เพิ่งตัดสิน ไม่มีการลบผลนั้นด้วยการเปลี่ยนฉาก ชื่อของผู้เสียชีวิตให้ทวนเฉพาะเมื่อคุณรู้ตัวตนจริงแล้ว

**🗣️ NPC Dialogue:** ให้ผู้เล่นพูดเอง ประยูรเฉพาะถ้าเห็นเหตุและยังตอบได้: “หยุดก่อนครับ อย่าลงมืออีก ลองเรียกกันก่อน” ไม่ชุบชีวิตหรือประกาศสังเวยแทน Server

**💬 Q&A**

- **D4-Q01 เขาตายแล้วหรือ?** ตอบตามผล Lethal จริงเท่านั้น ถ้า HP หมดแต่กฎระบุหมดสติ ให้ตอบหมดสติและสิทธิ์ช่วยเหลือ ห้ามเรียกตายเพื่อดราม่า
- **D4-Q02 กดซ้ำแล้วเจ็บอีกไหม?** DM ใช้ผล Intent เดิม: “เหตุโจมตีครั้งนี้มีผลเดียว” Network retry ไม่ใช่ Action ใหม่และไม่เสียทรัพยากรซ้ำ
- **D4-Q03 ถ้าพลาดจะพิสูจน์กันได้อย่างไร?** ผู้เล่นขอหยุดตรวจ: ให้ช่องเรียกชื่อ รหัส การสัมผัสอย่างปลอดภัย และอุปกรณ์เดิม ไม่บังคับให้ต้องยิงโดนก่อนรู้ทัน

**🔎 เบาะแส:** พื้นฐาน ผลจริง; สืบสวน ตัวตนผ่านเสียง/อุปกรณ์; สำคัญ E08 และ Friendly Fire Event เมื่อเกิดจริง; สำรอง ตรวจแบบไม่โจมตี

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** เปิดตัวตนให้ฝ่ายโจมตีเมื่อโดน/หลักฐานตรวจถึงแล้ว ไม่เผยตำแหน่งผู้เล่นอื่นที่ยังไม่เห็นจาก log เดียว

**🎲 Dice Cards:** ไม่มี การช่วยเหลือใช้ Ability/กติกาปัจจุบัน ไม่เพิ่ม Check เพื่อกู้ผลตายที่ไม่มีสิทธิ์แก้

**🔒 DM ONLY:** หากมนุษย์ฆ่ามนุษย์จริงในเขตการแสดงที่ล็อกไว้ ให้ประเมินสังเวยจาก cause ID ทันที หาก completed แล้วเป็นค่าถาวร บท E/F ต้องใช้ branch หลังสังเวย แม้ความตายเกิดก่อนพบอิง

**➡️ ไปต่อ:** เมื่อเหตุโจมตีปิดและผู้เล่นหยุด/ประเมินแล้วเปิด D5 โดยคง HP ทรัพยากร ผู้เสียชีวิต และตำแหน่งทั้งหมด

### D5 — ชื่อที่พูดให้กันฟัง

**🎯 เป้าหมาย:** รวมทีมตามการเดินและการตรวจจริง ให้บาดแผล/ความรู้คงอยู่ และใช้บทเรียนช่วยคนต่อ

**👥 ตัวละครที่อยู่จริง:** คนที่เดินถึงกันจริง ประยูรถ้ามาถึง ผู้บาดเจ็บ/หมดสติยังมีสถานะเดิม

**🧭 Action-Driven — DM ONLY:** Visible Cue คืออุปกรณ์และเสียงเพื่อนที่พิสูจน์แล้ว ผู้เล่นอาจรักษา บอกสิ่งพบ วางรหัสใหม่ คุ้มกัน หรือเดินไปห้องพัก ไม่มี Scripted Check บังคับรู้ทัน Fail-forward แม้ไม่พบ E07 ก็สรุปเฉพาะการบิดรูปลักษณ์ที่ตรวจจริงได้ แล้วตาม E06 ไปช่วยคน

**🎬 DM อ่านให้ผู้เล่น**

> เมื่อพวกคุณตรวจและเรียกตอบกันจนมั่นใจ คนที่อยู่ตรงนี้กลับมีชื่อและเรื่องราวที่รู้จัก บาดแผลยังคงอยู่ถ้ามันเกิดขึ้นจริง ทางสู่ห้องพักด้านหลังยังเปิด คุณมีโอกาสตกลงว่าจะยืนยันตัวกันอย่างไร ก่อนเดินต่อไปหาคนที่ยังไม่พบ

**🗣️ NPC Dialogue — ประยูรถ้าอยู่และรู้ว่าทีมช่วยกันได้:** “ผมขอโทษที่พามาถึงตรงนี้ ถ้าเจอใครข้างใน ขอให้ตรวจให้แน่ก่อนครับ” ถ้าถามเรื่องข้อตกลงและเงื่อนไขถึง ให้ใช้ E5 บทสารภาพ ไม่เปิดเองทุกกรณี

**💬 Q&A**

- **D5-Q01 เพื่อนรู้อะไรจากอีกทาง?** ให้ผู้เล่นบอกกันเอง DM ทวนเฉพาะสิ่งที่มีคนเล่าจริง แล้วเพิ่มผู้รับตามที่ได้ยิน ไม่รวมสมุดให้อัตโนมัติ
- **D5-Q02 รหัสทำให้กันภาพลวงตาได้เลยไหม?** ตอบตามข้อเท็จจริง: “รหัสช่วยตรวจตัวตนผ่านการตอบจริง ไม่ได้ลบภาพหรือป้องกันอาวุธให้เอง” ไม่ให้โบนัสตัวเลขที่ยังไม่อนุมัติ
- **D5-Q03 ถ้าไม่เคยโจมตีกันล่ะ?** “คุณรู้ทันจากวิธีที่เลือกและไม่มีบาดแผลจากเหตุที่ไม่ได้เกิด” ห้ามสร้าง Friendly Fire Result เพื่อให้บทครบ

**🔎 เบาะแส:** พื้นฐาน ตัวตนที่พิสูจน์; สืบสวน การเปรียบเทียบสองเส้นทาง; สำคัญ E08 ตามที่รับจริง; สำรอง หลักฐานอิง E05/E06

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ความรู้ว่ามีภาพลวงตาไม่เท่ากับรู้ทุกคนในโรงหรือรู้แผนสังเวย ให้ผู้เล่นใช้วิธีตรวจใหม่เองใน E2

**🎲 Dice Cards:** ไม่มี

**🔒 DM ONLY:** ไม่รีเซ็ตอาการบาดเจ็บ ไม่ฟื้นทรัพยากรจากการจบ ACT ถ้าบางคนยังแยก ให้คงกลุ่มและบอกเฉพาะคนที่รับข้อมูลจริง

**➡️ ไปต่อ:** ตามรอย/ผังสู่ E1 ได้ ไม่ต้องย้อนหาประยูรหรือบังคับเก็บเอกสารครบก่อนช่วยอิง

## ACT E — ผู้สูญหายที่ยังเลือกช่วยได้

### E1 — ประตูห้องพักด้านหลัง

**🎯 เป้าหมาย:** ให้เข้าถึงอิงจากร่องรอยจริงได้ โดยไม่ผูกกับการถูกหลอกหรือการทำร้ายเพื่อน

**👥 ตัวละครที่อยู่จริง:** ทีมที่ถึงห้อง ประยูรถ้าเดินมาถึง อิงอยู่หลังประตูในตำแหน่งที่ซ่อนไว้ตั้งต้น

**🧭 Action-Driven — DM ONLY:** Visible Cue คือผ้าติดขอบประตู รอยลาก และเสียงขยับ ผู้เล่นอาจเรียก เปิดทาง ตรวจประตู หรือจัดคนคุ้มกัน ประตูที่เปิดได้ปกติไม่ต้องทอย; ใช้ Situational Check เฉพาะสิ่งติดขัดที่เห็นจริงตาม Core ไม่สร้างอุปสรรคใหม่เพราะข้าม C2 Fail-forward มีทางเรียกผ่านช่องผ้าและเข้าถึงตัวคนโดยวิธีไม่ทำร้าย

**🎬 DM อ่านให้ผู้เล่น**

> รอยลากมาสิ้นสุดใกล้ห้องพักหลังโรง ผ้าสีเดียวกับเสื้ออาสาติดอยู่ระหว่างบานประตูกับวงกบ ข้างในมีเสียงเชือกเสียดสีกับขาเก้าอี้ เมื่อคุณหยุดเดิน เสียงนั้นก็หยุดไป ก่อนมีเสียงเบา ๆ ว่า “มีใครอยู่ข้างนอกไหม”

**🗣️ NPC Dialogue — อิงเมื่อมีคนเรียกจริง:** “ช่วยด้วยค่ะ หนูออกไปไม่ได้ อย่าเพิ่งทำร้ายหนู” ชื่อผู้พูดใน Player UI ใช้เสียงจากด้านใน จนตรวจตัวตนแล้ว ไม่ติดป้าย “อิง” ล่วงหน้า

**💬 Q&A**

- **E1-Q01 เสียงเหมือนอิงหรือไม่?** ถ้าผู้ฟังมีฐานจำเสียงจริงจึงเทียบได้ หากมีแค่รูปให้บอกว่าเสียงเป็นผู้หญิงร้องขอช่วย ยังไม่ยืนยันตัวตน
- **E1-Q02 ต้องทำพิธีก่อนช่วยหรือไม่?** ตรวจสิ่งกีดขวาง: “จากสิ่งที่เห็น ประตูและเชือกเป็นสิ่งที่คุณเข้าถึงได้ ไม่มีข้อความหรือกลไกที่บังคับทำพิธีก่อนช่วยคนตรงนี้” ไม่สร้างผนึกสองชั้น
- **E1-Q03 ถ้าเปิดแล้วอันตรายจะปิดหนีได้ไหม?** ให้ข้อมูลทางเดินจริงและสิ่งกีดขวางก่อนเลือก ไม่รับรองว่าร่างข้างในไม่มีภัย แต่ไม่ปิดทางหนีเพราะผู้เล่นลังเล

**🔎 เบาะแส:** พื้นฐาน มีเสียงขอช่วยและสิ่งผูกมัด; สืบสวน เสื้อ/รอยตรงกับทาง C2; สำคัญ E06; สำรอง คำพูดและการเข้าถึงประตูเอง

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** การพบเสียงไม่เท่ากับช่วยสำเร็จ ไม่เปิดชื่อจริงผ่านชื่อผู้พูด หัวข้อฉาก หรือรูป Portrait ก่อนพิสูจน์

**🎲 Dice Cards:** ไม่มีการ์ดเปิดประตูบังคับ ถ้าตรวจตัวตนหลังเห็นใช้ E2 ตาม Trigger

**🔒 DM ONLY:** อิงไม่ตายเพราะมาช้าหรือถามนาน หากอิงถูกพบ/ย้ายแล้วจาก Action ก่อนหน้า ให้ใช้ตำแหน่งปัจจุบัน ไม่สร้างอิงอีกคนหรือผูกกลับเพื่อเข้าบท

**➡️ ไปต่อ:** เมื่อเปิดมุมมองเห็นร่างในห้อง เปิด E2; หากทีมรู้ทันและช่วยไปแล้ว ให้ข้ามไป E3 พร้อมเหตุการณ์ช่วยเหลือเดิม

### E2 — ร่างหน้ากากที่ไม่มีอาวุธ

**🎯 เป้าหมาย:** ให้ทีมใช้การสังเกตและการสื่อสารช่วยมนุษย์ที่ถูกบิดรูปลักษณ์

**👥 ตัวละครที่อยู่จริง:** อิงในห้อง ทีมที่มองถึง ประยูรถ้าอยู่; ไม่มีผีตัวใหม่แทนอิง

**🧭 Action-Driven — DM ONLY:** Visible Cue ไม่มีอาวุธ รอยเชือก เสื้ออาสา และท่าขอช่วย ผู้เล่นอาจลดอาวุธ เรียกชื่อ ถามเรื่องส่วนตัว เทียบรูป สัมผัสอย่างระวัง หรือแก้เชือก วิธีตรวจที่ได้หลักฐานตรงไม่ต้องทอย; `C002-CHECK-07` สำหรับแยกรายละเอียดท่ามกลางภาพบิดเบือน Fail-forward อิงยังตอบและขอความช่วยเหลือได้ การทอยพลาดครั้งเดียวไม่ทำให้ต้องโจมตี

**🎬 DM อ่านให้ผู้เล่น**

> ในห้องมีร่างสวมหน้ากากไม้ขาวนั่งห่อตัวอยู่ มือทั้งสองว่าง ไม่มีอาวุธเหล็ก ข้อมือมีรอยเชือก เสื้อที่สวมมีด้ายเย็บสีสว่างตรงแขน ร่างนั้นพยายามถอยพ้นแนวอาวุธของคุณ แล้วพูดติดขัดว่า “อย่าทำหนู หนูอยากออกไป”

**🗣️ NPC Dialogue — อิงเมื่อเรียกชื่อ/แสดงหลักฐานอย่างปลอดภัย:** “หนูชื่ออิงค่ะ รอยตรงแขนนั่นหนูเย็บเอง พ่ออยู่ข้างนอกหรือคะ?” ใช้ชื่อใน UI หลังข้อความนี้ถูกรับและการตรวจยืนยันถึงจริง ไม่ใช้การเปิด Q&A เป็นเงื่อนไขยืนยัน

**💬 Q&A**

- **E2-Q01 ทำไมไม่มีอาวุธเหมือนผีตัวแรก?** สังเกตจริง: “มือทั้งสองว่าง การเคลื่อนไหวเหมือนพยายามปกป้องตัวเองจากคนข้างหน้า” นี่เป็นข้อสังเกต ไม่ใช่สั่งว่าต้องเชื่อ
- **E2-Q02 ขอให้เล่าเรื่องในรูปได้ไหม?** แสดงรูป/รายละเอียดที่ได้จริง: อิงตอบเรื่องเสื้อและหน้าที่อาสาของตัวเอง ไม่รู้ข้อมูลลับของทีม หากไม่มี E05 เธอให้ชื่อพ่อและเล่าเหตุถูกพาตัวตามประสบการณ์ได้
- **E2-Q03 ถามวิธีทำพิธีปิดโรงได้ไหม?** อิงที่ได้ยินคำถาม: “หนูไม่ใช่คนทำพิธี หนูรู้แต่ว่าตอนเข้าไปมีคนบอกให้ยืนตามตำแหน่ง แล้วหนูก็ถูกพาเข้ามาที่นี่” ข่มขู่ไม่ทำให้เธอรู้สูตรพิธี

**🔎 เบาะแส:** พื้นฐาน ไม่ถืออาวุธ รอยเชือก; สืบสวน เสื้อ/เสียง/รายละเอียดส่วนตัว; สำคัญ E09 และ E08 ตามวิธีพิสูจน์; สำรอง เปรียบเทียบการสัมผัสกับคำตอบหลายส่วน

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ความรู้ ACT D ช่วยตั้งคำถาม ไม่ทำให้ Auto-reveal E2 ทุกฝ่าย หากเลือกโจมตีก่อนพิสูจน์ ใช้เฉพาะลำดับกลไก pipeline D2–D4 กับเป้าหมายอิงจริง ไม่ยกบทผู้เล่นถูกโจมตีมาแทน NPC ใช้ branch NPC มนุษย์ของ D3/D4 และไม่เผยชื่อก่อน Attacker Roll การบาดเจ็บไม่ให้สิทธิ์ระบุชื่ออิงจนมีการยืนยันชื่อจริงตามหลักฐาน/คำตอบ

**🎲 Dice Cards:** `C002-CHECK-07` Pending; ไม่มี Check “ยอมเชื่อว่าเป็นคน” ที่บังคับทอยเพื่ออนุญาตช่วยเหลือ

**🔒 DM ONLY:** การ์ดไม่สร้างบาดแผลเชิง HP จากรอยเชือกที่ใช้เป็น cue ห้ามใส่ Damage ไว้ในบทพูด อิงเริ่มมีชีวิตและมีโอกาสได้รับการช่วยจริง

**➡️ ไปต่อ:** เมื่อช่วย/โจมตี/เคลื่อนย้าย/เกิดเหตุ Physical ที่ Resolve แล้ว เปิด E3 ตามผลนั้น ถ้ายังถาม ให้ตอบต่อ ไม่หัก HP เพราะคุยนาน

### E3 — ผลของการช่วยหรือการลงมือ

**🎯 เป้าหมาย:** ให้ชะตาอิงเกิดจากเหตุจริง และเปิดการคุ้มกันเมื่อถูกนายโรงขัดขวาง

**👥 ตัวละครที่อยู่จริง:** อิงตามสถานะล่าสุด ทีม/ประยูรตามตำแหน่ง นายโรงเฉพาะเมื่อปรากฏพร้อมสัญญาณและ Event จริง

**🧭 Action-Driven — DM ONLY:** บันทึกการปลดเชือก การพาออก การบาดเจ็บและการรักษาแยกกัน หากนายโรงเข้าขัดขวาง ให้เสียง/การปรากฏ Physical และหน้าต่าง Action ก่อน Resolve โจมตี ใช้กฎเดิม ไม่มีการ์ดสืบสวนเลือกชะตา Fail-forward อิงบาดเจ็บแต่ยังมีชีวิตย่อมช่วยตามกฎได้; ถ้าตายจริง หลักฐาน E4 ยังทำให้คดีเดินต่อได้

**🎬 DM อ่านให้ผู้เล่น — เลือกเฉพาะสภาพจริง**

> **ช่วยโดยไม่ทำร้าย:** เมื่อเชือกหลุด ร่างตรงหน้าขยับข้อมืออย่างระวังแล้วหันมาฟังคุณ เธอยังมีชีวิตและยอมเดินตามทางที่พวกคุณจัดให้ปลอดภัย การออกจากห้องต้องเกิดตามตำแหน่งจริงที่คุณเลือก
>
> **บาดเจ็บแต่ยังมีชีวิต:** อิงยังตอบสนอง บาดแผลเป็นผลจากเหตุที่เพิ่งเกิด คุณยังมีโอกาสช่วยเธอด้วยสิ่งที่ตัวละครทำได้ ไม่ใช่ปล่อยให้ฉากตัดสินแทน
>
> **เสียชีวิตที่ยืนยันแล้ว:** อิงไม่อาจตอบคำถามต่อ ผู้ดำเนินเรื่องยืนยันผู้ลงมือและเหตุเสียชีวิตตามผลที่ตัดสินแล้ว เรื่องที่เธอยังไม่ได้เล่าจะไม่กลายเป็นคำสารภาพหลังความตาย
>
> **นายโรงปรากฏจริงเพื่อขัดขวาง:** เสียงฝีเท้าหนักดังจากทางเวที ร่างชายในชุดการแสดงก้าวเข้าพ้นม่าน มือแตะวงกบจนไม้สั่น เขามองคนที่คุณกำลังพาออก แล้วเคลื่อนตัวเข้าแนวทางเดิน คุณเห็นภัยก่อนการโจมตีจะถูกตัดสิน

**🗣️ NPC Dialogue:** อิงที่ยังพูดได้: “เขาอยากให้หนูยืนตรงกลางตอนคนถืออาวุธเข้ามา หนูไม่เข้าใจว่าทำไม” ประยูรถ้าอยู่และได้ยืนยันตัวลูก: “อิง พ่ออยู่นี่” ไม่ให้สองคนอยู่ในฉากผ่านเสียงอัตโนมัติ

**💬 Q&A**

- **E3-Q01 ช่วยแล้วถือว่าปลอดภัยเลยไหม?** “การปลดเชือกสำเร็จแล้วถ้าคุณทำจริง แต่ต้องดูตำแหน่งภัยและการคุ้มกันก่อนเรียกว่าพ้นอันตราย” ไม่เท่ากับถูกฮีลหรืออพยพสำเร็จ
- **E3-Q02 นายโรงฆ่าเธอแล้วพิธีสำเร็จหรือไม่?** ถ้าทีมรู้ E10 แล้ว ทวนว่าเงื่อนไขต้องเป็นมนุษย์ฆ่ามนุษย์ หากยังไม่รู้ ให้ตอบสิ่งที่ตรวจได้ว่าผู้ลงมือคือร่างนายโรง ไม่เฉลยสูตรลับผ่านปุ่มสถานะ
- **E3-Q03 อิงบาดเจ็บแล้วรักษาได้หรือไม่?** ตรวจ HP/อาการและความสามารถจริง แจ้งทางช่วยที่ทำได้ ไม่สร้างการรักษาฟรีหรือประกาศตายจาก HP0 หากกฎนั้นไม่ได้ใช้

**🔎 เบาะแส:** พื้นฐาน สภาพอิง; สืบสวน คำให้การเฉพาะประสบการณ์; สำคัญ E09 พร้อม action cause; สำรอง แฟ้ม E4 ไม่ต้องพึ่งอิงที่อาจตอบไม่ได้

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** `rescued`, `injured`, `dead` ต้องสะท้อนเหตุจริง แยกสถานะมีชีวิตจากการปลอดภัยและการได้รับช่วยแล้ว ชื่อ cause/ผู้ลงมือให้ DM เห็น ผู้เล่นเห็นผลเท่าที่รับรู้

**🎲 Dice Cards:** ไม่มี ใช้ Combat/Ability จริง หากยังไม่มี approved lethal ให้คงบาดเจ็บ/หมดสติ ไม่สร้างทางตายใหม่

**🔒 DM ONLY:** นายโรงฆ่าอิงเองไม่นับสังเวย การโจมตีของหุ่น/บริวารไม่นับเช่นกัน หากมนุษย์ฆ่าอิงจริงในเขตที่อนุมัติจึงประเมิน completed เมื่อสำเร็จแล้วห้ามกลับ false หาก completed ตั้งแต่ D อย่าเล่นบทนายโรงว่ารอเครื่องสังเวยแรก

**➡️ ไปต่อ:** เข้าถึง E4 จากแฟ้มทางเวทีได้ ไม่ต้องรอให้ใครตายหรือบังคับให้บอสโจมตีอิงหนึ่งครั้งก่อนออกฉาก

### E4 — คำว่าเครื่องสังเวย

**🎯 เป้าหมาย:** ให้ความจริงหลักที่ใช้เลือกแผนได้ พร้อมข้อยกเว้นพิธีเดิมโดยไม่มี Roll lock

**👥 ตัวละครที่อยู่จริง:** ผู้เข้าถึงแฟ้มเวที อิง/ประยูรถ้ายังมีชีวิตและอยู่ใกล้; ไม่มีผู้เชี่ยวชาญมนุษย์เข้ามาอธิบายแทน

**🧭 Action-Driven — DM ONLY:** Visible Cue คือสำเนาประวัติหน้ากากกับหมายเหตุพิธี ผู้เล่นอ่าน เทียบกับเหตุจริง หรือถามข้อสรุปได้ ข้อกำหนดมนุษย์ฆ่ามนุษย์อ่านตรงได้ไม่ทอย; `C002-CHECK-08` สำหรับเชื่อมรายละเอียดกับแผนอย่างมีข้อจำกัด Fail-forward แฟ้มมีข้อความสำคัญซ้ำจาก C3 จึงไม่ต้องย้อนเก็บหน้าเก่า

**🎬 DM อ่านให้ผู้เล่น**

> แฟ้มข้างเวทีมีภาพร่างคนยืนกลางพื้นที่การแสดง กับภาพผู้ถืออาวุธหันเข้าหากัน ข้อความส่วนหนึ่งเขียนว่า “ให้มือของคนเป็นพรากชีวิตคนเป็น” หมายเหตุใต้ผังปิดโรงแยกอีกข้อไว้ชัดว่า เมื่อเครื่องสังเวยสำเร็จ ผู้ครองโรงจะคงอยู่ และพิธีประจำปีแบบเดิมไม่อาจสะกดกลับได้

**🗣️ NPC Dialogue:** อิงถ้ามีชีวิต อยู่ และได้รับฟังข้อมูล: “เขาไม่ยอมให้หนูออกจากตรงที่ทำเครื่องหมายไว้ แต่หนูไม่รู้ว่ามันหมายถึงแบบนี้” ประยูรถ้าถูกถามเรื่องข้อเสนอและเงื่อนไขถึง ใช้บทสารภาพ E5 ไม่ให้เขากลายเป็นผู้รู้พิธีครบ

**💬 Q&A**

- **E4-Q01 ถ้าผีฆ่าคนเองนับไหม?** อ่านคำอธิบายครบ: “บันทึกแยกมือผีออกจากมือมนุษย์ เงื่อนไขนี้ไม่สำเร็จจากการที่นายโรงหรือบริวารฆ่าเอง” ให้หลังอ่าน/ได้รับบอกจริง
- **E4-Q02 บาดเจ็บหรือหมดสตินับไหม?** ตรวจข้อความและเหตุ: “คำในบันทึกคือการพรากชีวิต ไม่ใช่การบาดเจ็บ” DM เทียบกับ lethal resolution จริง ไม่ให้เอกสารทำให้คนหมดสติตาย
- **E4-Q03 ถ้ามันได้เครื่องสังเวยไปแล้วทำอย่างไร?** ให้ข้อเท็จจริงที่มี: “พิธีเดิมไม่มีผลสะกดกลับตามหมายเหตุ แต่คุณยังจัดคนคุ้มกัน อพยพ และต่อสู้ร่างที่จับต้องได้ได้ วิธีขจัดภัยถาวรยังไม่ได้พิสูจน์จากเอกสารนี้” ไม่เสกพิธีใหม่สำเร็จแน่นอน

**🔎 เบาะแส:** พื้นฐาน เงื่อนไขหลัก; สืบสวน เขต/ผู้ลงมือ/เหตุเทียบปัจจุบัน; สำคัญ E10; สำรอง ข้อความ C3 กับร่องรอยเวที ไม่ต้องได้ Full เพื่อห้ามฆ่ามนุษย์

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ผู้ที่อ่านจึงรู้ E10 ถ้า completed เกิดแล้วและทีมมีหลักฐานพอ ให้ทวนว่าเงื่อนไขเกิดแล้ว ไม่พูดเหมือนบอสยังรอครั้งแรก หากทีมยังไม่รู้เหตุที่อีกกลุ่มพบ ต้องรับข่าวจริงก่อนเชื่อม

**D05 — อ่านคำอธิบายทางใหม่จริง:** เมื่ออ่านหมายเหตุส่วนจุดยึด DM อ่านว่า “เมื่อเครื่องสังเวยเกิด พิธีประจำปีไม่อาจกดกลับ จงแยกไม้ครูออกจากฐานที่ตรึงและตัดความเชื่อมโยงของโรง แต่ร่างที่ยังยืนอยู่ยังทำร้ายได้” ชี้ว่าทีมต้องทั้งหยุดร่างและลงมือกับของจริง ไม่ให้การอ่านทำลายของหรือย้อนล้างการตาย บันทึก E12 เฉพาะคนรับข้อมูล; ไม่ล็อกข้อความนี้หลัง Full Roll

**🎲 Dice Cards:** `C002-CHECK-08` Pending; Full คือข้อมูลเชื่อมโยง ไม่ใช่ย้อนล้างการตายหรือทำให้พิธีเดิมใช้หลัง completed

**🔒 DM ONLY:** D05 เลือกทางหยุดภัยถาวรแล้ว จุดยึดไม้ครูถูกปู B3/C3 และอธิบาย E4 ใช้ได้ทั้งก่อน/หลังสังเวย ต้องตัดจุดยึดและหยุดร่างจริง หาก completed แล้วพิธีเดิมยังใช้ไม่ได้และ completed ไม่ย้อนกลับ ดู CASE002_FINAL_Anchor_Design.md; ค่าการลงมือยังไม่เปิด runtime

**➡️ ไปต่อ:** E5 วางแผนได้แม้ผลการ์ดไม่สำเร็จหรืออิง/ประยูรตอบไม่ได้ ทุกคนยังมีสิทธิ์ช่วยคนและขัดขวางการฆ่า

## ACT FINAL — การแสดงรอบสุดท้าย

### F1 — หน้าเวทีตามแผนของทีม

**🎯 เป้าหมาย:** ยืนยันตำแหน่งและสิ่งที่จะคุ้มกันก่อนการเผชิญหน้า ไม่สร้างร่างหรือพลังบอสใหม่

**👥 ตัวละครที่อยู่จริง:** ทีม/อิง/ประยูรที่เดินมาถึงตามแผน นายโรงอยู่ในตำแหน่งที่เปิดเผยจริง ผู้ที่อพยพออกแล้วไม่ถูกดึงกลับ

**🧭 Action-Driven — DM ONLY:** Visible Cue ทางเข้าถึงเวที จุดพิธีเดิมที่รู้จาก E04 และแนวที่นายโรงคุกคามได้ ผู้เล่นเลือกแยกหน้าที่ตามตำแหน่ง คุ้มกัน ต่อสู้ หรืออพยพ ไม่มี Scripted Check บังคับก่อนเปิด Combat Fail-forward ไม่มี E04 ก็จัดการภัย Physical/ช่วยคนออกได้ ไม่มี completed ก็เข้า FINAL ได้

**🎬 DM อ่านให้ผู้เล่น — เลือกตาม State**

**DM ONLY — ตรวจผู้ที่อยู่จริงและผู้รับข้อมูลก่อนอ่าน:** ใช้บทที่กล่าวถึงร่างนายโรงเฉพาะเมื่อร่างนั้นปรากฏในระยะรับรู้จริง ทุกชื่อในบทพูด/ชื่อผู้พูด/Portrait ใช้ได้เฉพาะผู้รับที่ยืนยันตัวตนจริงแล้ว ก่อนหน้านั้นใช้ “ร่างชายในชุดการแสดง” การคุ้มกันคนอื่นเป็นทางเลือกเฉพาะเมื่อมีผู้ที่ยังมีชีวิตอยู่ในตำแหน่งนั้น หากอิง/ประยูรตายหรืออพยพไปแล้ว ห้ามใช้ข้อความว่าทั้งสองยังอยู่ให้ช่วยหรือคุ้มกันตรงเวที การมาถึงก่อน E10 ไม่ให้สิทธิ์รู้แผนหรือสถานะสังเวย

> **บทกลาง — ใช้เมื่อยังไม่รู้ E10 ไม่ว่าสังเวยสำเร็จแล้วหรือยัง และร่างปรากฏจริง:** ร่างชายในชุดการแสดงจับขอบม่านแล้วหันมามองพวกคุณ ทางที่คุณเดินมายังอยู่ข้างหลัง คุณเห็นพื้นที่และสิ่งกีดขวางตามที่เดินมาถึงจริง คุณเลือกได้ว่าจะเผชิญหน้า ตรวจสิ่งตรงหน้า หรือจัดการความปลอดภัยของสมาชิกที่อยู่ตรงนี้อย่างไร
>
> **ยังไม่มีเครื่องสังเวยสำเร็จ ผู้รับรู้ E10 แล้ว และร่างปรากฏจริง:** ร่างชายในชุดการแสดงหันมาทางพวกคุณ ข้อห้ามที่คุณได้ตรวจจากหลักฐานยังเป็นสิ่งต้องคำนึงถึง คุณเลือกได้ว่าจะเผชิญหน้า จัดการความปลอดภัยของสมาชิกที่อยู่ตรงนี้ หรือดูร่องรอยพิธีเฉพาะที่ได้รับรู้จาก E04 มาแล้วอย่างไร
>
> **เครื่องสังเวยสำเร็จ ผู้รับรู้ E10 และรู้เหตุที่ทำให้สำเร็จแล้ว และร่างปรากฏจริง:** สิ่งที่เกิดกับชีวิตคนจริงไม่ถูกลบด้วยการมาถึงเวที ร่างชายในชุดการแสดงยังขวางทางอยู่ พิธีเดิมมีข้อจำกัดที่คุณได้อ่านแล้ว แต่ทางกลับยังเป็นทางเดิม คุณยังเลือกแผนต่อสู้หรือถอนออกตามตำแหน่งจริงได้
>
> **เสริมเฉพาะมีผู้รอดชีวิตที่ต้องช่วยอยู่ในระยะจริง:** คนที่ยังอยู่กับคุณสามารถเดินออกพร้อมผู้คุ้มกันที่คุณจัดไว้ได้ การตัดสินใจว่าจะให้ใครอยู่ตรงไหนยังเป็นของทีม

**🗣️ NPC Dialogue — นายโรงเมื่อปรากฏและได้ยินจริง:** ก่อนยืนยันตัวตนใช้ชื่อผู้พูด “ร่างชายในชุดการแสดง” เท่านั้น ก่อน completed: “คนกล้าจัดการผีเดินมาถึงแล้ว เหลือเพียงเลือกให้ถูกว่าจะลงมือกับใคร” หลัง completed: “บทที่ข้ารอเกิดขึ้นแล้ว พวกเจ้าจะหยุดมองหน้ากากเสียทีหรือยัง” ประโยคหลังเป็นคำกล่าวของตัวละคร ไม่ใช่การยืนยันสถานะสังเวยให้ผู้ที่ยังไม่มีหลักฐาน ไม่ใช้ประโยคแรกหลังสังเวยสำเร็จ

### F2 — ต่อสู้กับร่างและคุ้มกันคน

**🎯 เป้าหมาย:** ให้ Final มีการช่วยทีมและคุ้มกันตำแหน่งจริง ไม่ใช่โจมตี HP บอสอย่างเดียว

**🧭 Action-Driven — DM ONLY:** ใช้ Combat Lite ที่เลือก/อนุมัติและ Enemy Preset จริง ผู้เล่นอาจโจมตี ป้องกัน ช่วยเพื่อน ปิดแนวเข้าถึง พาผู้รอดชีวิตเดินออก หรือดำเนินพิธีเดิมเฉพาะ branch ที่ใช้ได้ เป้าหมายคุ้มกันนับจากตำแหน่ง/Action ไม่เพิ่ม AP objective ใหม่ ไม่มี Scripted Check เปลี่ยน hit ให้โดน Fail-forward ถ้าปิดพิธีไม่ได้ยังถอยและช่วยคนออกได้

**🎬 DM อ่านให้ผู้เล่น — เปิดเหตุ ไม่อ่านผลล่วงหน้า**

**DM ONLY — เลือกตามผู้ที่ยังอยู่ในพื้นที่:** บทหลักใช้เมื่อมีการปรากฏ/การขยับคุกคามและภาพลวงตาที่บันทึกแล้วจริง ใช้ชื่อ “นายโรง” แทนชื่อกลางได้เฉพาะผู้รับที่ยืนยันตัวตนจริงแล้ว หากอิง/ประยูรตายหรือออกไปแล้ว เป้าหมายคุ้มกันที่เหลือมีเฉพาะสมาชิกที่ยังอยู่จริง ไม่สร้างร่างหรือเสียงขอช่วยของ NPC เหล่านั้นเพื่อให้มีเป้าหมายรอง หากไม่มีภาพลวงตารอบใหม่ ให้ตัดประโยคเงาผิดรูปร่าง ไม่เปิดสถานะจากการอ่าน

> ร่างชายในชุดการแสดงขยับเข้าหาแนวที่มีผู้ร่วมเหตุการณ์อยู่จริง ม่านข้างเวทีแกว่งจนเงาบางร่างดูผิดรูปร่างไป แต่เสียง อุปกรณ์ และทางเดินยังมีร่องรอยให้ตรวจ คุณเห็นทิศที่มันเตรียมโจมตี ทางกลับอยู่ด้านเดิม บอกสิ่งที่แต่ละคนจะทำตามลำดับที่ผู้ดำเนินเรื่องให้
>

**🗣️ NPC Dialogue:** ก่อน completed นายโรงชี้นำให้โจมตีร่างที่อาจเป็นคน โดยเป็นเพียงคำโกหกที่ผู้เล่นตรวจได้ หลัง completed มันเยาะผลที่เกิดแล้ว ไม่ต่อรองหาเครื่องสังเวยแรก อิง/ประยูรพูดขอความช่วยเหลือเฉพาะเมื่อยังมีชีวิต อยู่ และมีเหตุ ไม่ใช้เสียงหลอกแทนคำสั่งเปลี่ยนตัวตนจริง

- **F2-Q01 ใช้รหัสและตรวจอุปกรณ์ได้ไหม?** รับ Action ตามตำแหน่ง/ช่องทางจริง การยืนยันได้ช่วยเลือกเป้าหมายถูก แต่ไม่แจก hit/Defense เพิ่มเป็นตัวเลข

**🔎 เบาะแส:** พื้นฐาน ทิศภัยและทางหนี; สืบสวน วิธีตรวจที่เคยได้ผล; สำคัญ Combat/Protection/Evacuation Events; สำรอง ถอนตัวพร้อมคนที่เข้าถึงได้จริง

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** ภาพลวงตาแต่ละครั้งต้องมี representation แยกฝ่ายและวิธีตรวจ ไม่เปลี่ยน friendly target ที่ล็อกแล้วกลาง Resolution เว้นกฎที่อนุมัติรองรับและผู้เล่นเห็นเหตุจริง

**🔒 DM ONLY — ทิศทาง D05 อนุมัติแล้ว; รายละเอียดกลไกยังเป็น Draft:**

2. **หลังสังเวย:** พิธีเดิมใช้ไม่ได้ แต่ทีมยังตัดจุดยึดไม้ครูและหยุดร่างที่เป็นภัยเพื่อยุติภัยถาวรได้ ทั้งสองผลต้อง Resolve จริงและสลับลำดับได้ หากสำเร็จให้ C เพราะมีผู้ตายจริง ไม่ใช่ A; หากหยุดเพียงร่างและอพยพโดยจุดยึดยังอยู่จึงยังเป็น D ตามภัยที่เหลือ

**➡️ ไปต่อ:** เปิด F3 เมื่อภัย/การอพยพ/ความพ่ายแพ้มีผลยืนยันจริง ไม่มีเงื่อนไขต้องตายให้ครบหรือเสียสละคนเพื่อจบ Combat

### F3 — คนที่กลับออกมาและสิ่งที่ยังเหลือ

**🎯 เป้าหมาย:** สรุปตาม State จริง แยกชะตาคน ภัยที่เหลือ และความรับผิดประยูร

**👥 ตัวละครที่อยู่จริง:** ผู้ที่อยู่ในจุดสรุปตามการเคลื่อนที่จริง ผู้ตายไม่มีบทพูด ผู้ที่อยู่ไกลไม่ถูกนำมารวมในภาพโดยไม่มีการเดินทาง

**🧭 Action-Driven — DM ONLY:** ตรวจ Outcome Snapshot จาก Server, cause ของผู้ตาย, ความปลอดภัยรายคน, completed และผลหยุดภัยจริงก่อนเลือกบท ไม่มี Ending จากผล Check เดียว ผู้เล่นยังบอกต่อหลักฐาน/จัดการคนที่ช่วยไว้ได้ตามจริง ไม่มี Scripted Check ทอยเลือกระดับตอนจบ Fail-forward กรณีผสมที่ resolver ยังไม่ล็อกต้องบันทึก pending outcome ไม่เดาความปลอดภัย/ความตายให้เข้าตัวอักษร

**🎬 DM อ่านให้ผู้เล่น — เลือกเฉพาะ branch ที่ผ่าน guard**

**DM ONLY — ตรวจตัวตนและผลออกจากพื้นที่แยกกัน:** ทุกชื่อใช้เฉพาะผู้รับที่รู้ตัวตนจริงแล้ว หากยังไม่รู้ชื่อ ให้ใช้คำเรียกตามที่ผู้รับรู้จัก ห้ามเปิดชื่อผ่านป้ายบทส่งท้าย เลือกบท D ตามผู้ที่รอดและออกจริง ไม่สรุปว่ามีคนกลับไม่ครบหรือมีผู้รอดเพียงเพราะเลือก Ending D ถ้าผู้เล่นเสียชีวิตทั้งหมด ให้ใช้รายงาน DM ไม่ส่งข้อความเหมือนตัวละครเหล่านั้นยังยืนรับฟัง

> **A — ปิดโรงสำเร็จ:** ภัยที่พวกคุณจัดการหยุดลงตามผลที่ยืนยันแล้ว อิงและประยูรออกมาอยู่ในที่ปลอดภัย สมาชิกทีมทุกคนยังมีชีวิต การไม่ปล่อยให้ภาพลวงตาตัดสินแทนการตรวจสอบทำให้ไม่มีเครื่องสังเวยสำเร็จ เรื่องที่ประยูรปิดบังยังต้องได้รับคำตอบจากเขา
>
> **B — ช่วยคนไว้ได้ แต่ภัยยังไม่สิ้นสุด:** คนที่คุณช่วยออกมาอยู่ในตำแหน่งปลอดภัยตามที่ตรวจแล้ว ไม่มีเครื่องสังเวยสำเร็จ แต่หลักฐานและสิ่งที่เห็นยังไม่ยืนยันว่านายโรงหมดอำนาจไปทั้งหมด ภารกิจครั้งนี้ช่วยชีวิตคนไว้ได้ พร้อมความจริงที่ต้องบอกต่ออย่างระมัดระวัง
>
> **C — การแสดงที่แลกด้วยชีวิต:** ภัยถูกหยุดตามวิธีที่ยืนยันแล้ว แต่ชีวิตที่เสียไปจากเหตุจริงไม่กลับมา ผู้ดำเนินเรื่องทวนชื่อผู้เสียชีวิตและสาเหตุที่ทีมรับรู้ โดยไม่เปลี่ยนว่าใครลงมือ ความสำเร็จส่วนที่ทำได้ยังอยู่พร้อมราคาที่เกิดขึ้นจริง
>
> **D — การแสดงยังไม่จบ / ทุกคนมีชีวิตและออกครบจริง:** ทุกคนออกจากพื้นที่มาถึงตำแหน่งปลอดภัยตามที่ตรวจแล้ว แต่ภัยจากโรงยังไม่ถูกยุติ การช่วยคนได้ครบเป็นผลสำเร็จของทีม ส่วนอันตรายที่ยังเหลือเป็นอีกข้อเท็จจริงหนึ่ง
>
> **D — มีผู้กลับออกมาบางส่วนจริง:** ผู้ที่เดินทางออกมาถึงจุดนี้มีรายชื่อตามที่ผู้ดำเนินเรื่องยืนยัน คนที่ยังไม่กลับต้องแยกตามสถานะที่ทราบ ไม่เรียกว่าเสียชีวิตหากยังไม่ยืนยัน ภัยจากโรงยังไม่ถูกยุติ การออกมาของคนกลุ่มนี้ไม่ได้ย้อนแก้เหตุที่เกิดขึ้นข้างใน
>
> **D — ยังไม่มีผู้กลับออกมา แต่มีตัวละครยังมีชีวิตอยู่จริง:** ตอนนี้ยังไม่มีใครออกจากพื้นที่สำเร็จ ผู้ที่ยังมีชีวิตคงอยู่ตามตำแหน่งและสภาพล่าสุด ภัยยังไม่ถูกยุติ ผู้ดำเนินเรื่องจะทวนเฉพาะผลที่ Resolve แล้ว ไม่ถือว่าการตัดบทพาทุกคนออกมาได้เอง
>
> **D — ไม่มีผู้รอดชีวิตจริง / รายงาน DM ไม่ใช่บทพูดถึงผู้เล่นที่ยังมีชีวิต:** ผลเหตุการณ์ที่ยืนยันแล้วไม่เหลือมนุษย์มีชีวิตจากทีม ประยูร และอิง ภัยจากโรงยังไม่ถูกยุติ รายงานบันทึกผู้เสียชีวิต ผู้ลงมือ และเหตุแต่ละรายตามจริง ไม่มีการบรรยายว่ามีผู้กลับออกมาหรือผู้รอดนำข่าวไปบอกต่อ
>
> **เสริม D เมื่อ completed ผู้รับรู้ E10 และรู้เหตุสำเร็จจริงแล้ว:** เครื่องสังเวยที่เกิดขึ้นทำให้ผู้ครองโรงคงอยู่ถาวรตามหลักฐานที่คุณพบ การหยุดร่างครั้งนี้หรือพิธีเดิมไม่ได้สะกดมันกลับไป ความจริงนี้เป็นส่วนหนึ่งของข้อเท็จจริงที่คุณรับรู้แล้ว
>
> **Fallen Agent Modifier เมื่อมีผู้เล่นเสียชีวิตจริง:** ที่นั่งของผู้ร่วมทีมที่ไม่กลับมาทำให้การตรวจรายชื่อช้าลง ผู้ดำเนินเรื่องระบุผู้เสียชีวิตตามเหตุจริง ไม่มีใครถูกเรียกว่าเสียสละโดยอัตโนมัติ หากเจ้าตัวไม่ได้เลือกเช่นนั้น

**🗣️ NPC Dialogue:** ประยูรที่รอด ปลอดภัย และเคยสารภาพจริง: “สิ่งที่ผมปิดบังทำให้พวกคุณเสี่ยง ผมจะเล่าส่วนที่ผมรู้ ไม่โยนความผิดให้คนที่ไม่อยู่ตอบแล้ว” หากยังไม่สารภาพ ให้ใช้เพียงความรู้สึกต่อชะตาลูก ไม่ใส่ E11 ย้อนหลัง อิงที่รอดและพูดได้: “ขอบคุณที่ถามก่อนตัดสินว่าหนูเป็นอะไร” ใช้เฉพาะทีมช่วยด้วยการตรวจจริง ไม่ใช้สรรเสริญการกระทำที่ไม่ได้เกิด

**💬 Q&A**

- **F3-Q01 ใครทำให้คนตาย?** ให้ข้อมูลตาม cause และพยานที่ผู้ถามรู้ ผู้เล่นฆ่า/นายโรงฆ่า/เหตุอื่นต้องแยก ไม่โทษภาพลวงตาจนลบผู้ลงมือจริง
- **F3-Q02 ประยูรพ้นผิดหรือยัง?** “ผลช่วยคนกับเรื่องที่เขาปิดบังเป็นคนละประเด็น พวกคุณตัดสินใจรายงานข้อเท็จจริงที่พิสูจน์ได้” ไม่เพิ่มคดีอาญาหรือโทษกฎหมายที่ไม่มีข้อมูล
- **F3-Q03 ทุกคนรู้ความลับทั้งหมดแล้วหรือ?** ให้ทวนสมุดตามผู้รับจริง “สิ่งที่ยังไม่ถูกเล่าหรือพิสูจน์ยังเป็นเรื่องที่บางคนไม่รู้” ไม่เท DM Secret ทั้งไฟล์ท้ายเกม

**🔎 เบาะแส:** พื้นฐาน ผู้กลับมา/สภาพจริง; สืบสวน รายงานแยกหลักฐานกับคำให้การ; สำคัญ Outcome Snapshot และ cause IDs; สำรอง ข้อมูลที่ยังไม่ทราบต้องระบุว่าไม่ทราบ

**🧩 การเปิดเผยข้อมูลเป็นชั้น:** บทส่งท้ายไม่ใช่สิทธิ์เผยข้อมูลของคนที่ยังแยกหรือข้อมูลลับที่ไม่เคยพบ ให้รายงาน DM ฉบับเต็มแยกจาก Player Ending

**🎲 Dice Cards:** ไม่มี ห้ามทอยให้ผลตาย/สังเวย/ตัวอักษรตอนจบย้อนหลัง

**🔒 DM ONLY — Draft Priority Resolver:**

1. ประเมิน **D** ก่อน เมื่อภัยร้ายแรงยังอยู่ หรือทีมแพ้/ถอนโดยยังควบคุมไม่ได้ `completed=true` กับเพียงสลายร่าง/อพยพยังเป็น D ในแนวทาง FINAL ที่เสนอ
2. เมื่อภัยหยุดสำเร็จจริง (`stopped`) ด้วยวิธีที่อนุมัติ และมีมนุษย์เสียชีวิตที่ Resolve แล้วอย่างน้อยหนึ่งคน ให้ **C** โดยแยก cause รายคน การควบคุมไว้ชั่วคราว (`contained`) ไม่ผ่าน C ถ้าจะให้ C หลัง completed ต้องมีวิธีหยุดภัยถาวรที่ใช้ได้จริงหลัง completed ซึ่งฉบับนี้ยังไม่ล็อก
3. เมื่อภัยหยุดจริง `completed=false` อิงและประยูรมีชีวิตและปลอดภัย และไม่มีมนุษย์เสียชีวิตจากเหตุจริงทั้งหมด ทั้งสมาชิกทีม อิง และประยูร ให้ **A**
4. เมื่อภัยถูกควบคุมชั่วคราว (`contained`) ตามนิยามที่อนุมัติ อพยพมนุษย์ที่ยังมีชีวิตออกอย่างปลอดภัยจริง `completed=false` และไม่มีมนุษย์เสียชีวิตจากเหตุจริงทั้งหมด ให้ **B** ห้ามใช้ B กลบการถอนตัวทิ้งภัยที่ควบคุมไม่ได้
5. เมื่อเหตุและข้อเท็จจริงที่จำเป็น Resolve ครบแล้ว แต่ผลผสมยังไม่เข้าเงื่อนไข A/B/C ให้ **D เป็น fallback แบบ conservative draft** ตาม D06 และ State Contract บรรยายเฉพาะสิ่งที่ทราบ ไม่แต่งความตาย ความปลอดภัย หรือชัยชนะเพื่อให้เข้าตัวอักษร หากยังมี Pending Attack การตายที่ยังไม่ยืนยัน หรือข้อเท็จจริงที่ DM ยังต้อง Resolve ให้คงผลตอนจบเป็น Pending จนตัดสินเหตุครบ ไม่บังคับเลือก D เพื่อปิดช่องว่างข้อมูล **Priority และ fallback นี้ยังเป็นข้อเสนอรออนุมัติ ไม่เปิดใช้ใน Runtime**
