# CASE002 — ชุดภาพตัวละครและฉาก

วันที่ 15 พฤศจิกายน 2026 · **DM ONLY — มีตัวตนลับ**

เปิด [แกลเลอรีภาพทั้งหมด](ARTWORK_GALLERY.html) เพื่อดูภาพและกดเปิดไฟล์เต็ม ชุดที่เลือกมี **16 ภาพ: ตัวละคร/รูปลักษณ์ 5, ฉาก 10, ผู้คนลวงแยกชั้น 1** ยังไม่เชื่อมกับ runtime CASE002

สร้างด้วยเครื่องมือ image_gen ในแอป เก็บ prompt จริงและที่มาแต่ละภาพใน [manifest ต้นฉบับ](../../assets/source/case-002/manifest.dm.json) ไม่ใช้ภาพแทนจาก CASE001 และไม่แก้ไฟล์ภาพเดิม

## ตำแหน่งไฟล์

- ต้นฉบับ PNG: `assets/source/case-002/characters/`, `scenes/`, `perceptions/`
- สำเนาสำหรับนำเข้าเกม: `packages/client/src/assets/case-002/characters/`, `scenes/`, `perceptions/`
- [ผังภาพกับฉาก](CASE002_Art_Map.dm.json) ครอบคลุม 25 ฉาก เป็นข้อมูล DM สำหรับเชื่อมภายหลัง ไม่ใช่ public snapshot
- [ผลตรวจไฟล์ภาพ](CASE002_Artwork_Validation.json) ระบุขนาด alpha และ SHA-256 ของต้นฉบับ/สำเนา

เก็บภาพต้นฉบับเต็มโดยไม่ลดขนาดหรือแปลง alpha ตัวละครก่อนเลือกวิธีโหลดจริง ไฟล์ PNG นี้ยังไม่ถูก import เข้าหน้าผู้เล่น จึงไม่อ้างว่าขนาดดาวน์โหลดเกมได้รับการตรวจแล้ว

ภาพตัวละครเต็มตัวและชั้นผู้คนมี alpha โปร่งใสจริง ภาพอิงกับรูปลักษณ์ลวงคงเสื้อ กางเกง รองเท้า และมือว่างให้ผู้เล่นใช้สังเกตได้ ส่วนอายุ/เสื้อผ้าที่เลือกวาดเป็นการออกแบบภาพ ไม่เพิ่ม Stat ความสามารถ หรือประวัติใหม่ในกฎ

ชื่อไฟล์และ manifest ที่บอกตัวตนจริงเป็นข้อมูลทำงานฝั่ง DM การเชื่อม runtime ต้องให้ผู้เล่นรับ opaque appearanceRef/ชื่อกลาง ไม่ส่งตารางไฟล์ทั้งหมดหรือ mapping ตัวจริงไปก่อนเปิดเผย

ภาพฉากเป็นแนวกว้าง โทนหมึกและภาพวาดกึ่งสมจริง แสงจันทร์น้ำเงินเทากับหลอดงานวัดสีอำพัน เว้นพื้นที่เดินและวางตัวละคร ไม่มีคน ผี เหยื่อ หรือผลชนะ/ตายฝังในพื้นหลัง แสงและผู้คนที่เห็นในงานต้องเปิดตามภาพการรับรู้จริง ไม่ใช้ภาพลานว่างเป็นการเฉลยว่าคนทั้งหมดไม่มีตัวตนตั้งแต่แรก

`final-stage-v2.png` ใช้โรงเก่าเป็นภาพอ้างอิงเพื่อคงตำแหน่งกล้อง โครงเวที เสาและบันได ภาพ `final-stage.png` รุ่นแรกเก็บเป็นตัวเลือกที่ไม่ได้ใช้ ไม่เขียนทับทิ้ง และไม่ได้จับคู่กับบทปัจจุบัน

พื้นหลังไม่แสดงไม้ครูด้วยแสงเรือง ชื่อเฉลย หรือปุ่มแก้ปริศนา ข้อมูลจุดยึดอยู่ใน [แบบ FINAL](CASE002_FINAL_Anchor_Design.md) และเปิดจากการตรวจจริง ไม่ใช่เห็นภาพแล้ว State เปลี่ยน

## ผลตรวจและข้อจำกัด

- ตรวจภาพที่เลือกด้วยตาครบชุด รวมความต่อเนื่องโรงเดิมและรูปลักษณ์อิง
- ไฟล์ต้นฉบับ/สำเนาของทุกภาพมีจริงและ SHA-256 ตรงกัน
- ฉากทั้ง 10 มีสัดส่วนแนวกว้าง; ตัวละครและชั้นผู้คนมี pixel alpha โปร่งใส
- ทุกฉากทั้ง 25 มีภาพที่ผ่านเงื่อนไข หรือระบุให้คงสถานที่จริงอย่างชัดเจน
- แกลเลอรีเป็นไฟล์ตรวจภาพในเครื่อง ไม่ใช่ demo ของ State, multiplayer, combat หรือ privacy ที่ทำงานแล้ว
- ยังไม่ได้เปิดทดสอบแกลเลอรีผ่าน browser และยังไม่มี runtime/browser playtest ของ CASE002 ไม่มี commit/push/deploy
