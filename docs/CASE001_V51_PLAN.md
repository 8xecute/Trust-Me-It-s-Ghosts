## ลำดับทำงาน

1. บันทึกแกนเรื่องและสารบัญก่อนแก้ (CASE001_V51_STORY_MAP.md)
2. นำเข้าบท A, B, C, D, E/H1, FINAL และ Ending ทีละบทเป็นข้อมูล runtime แยกจากต้นฉบับ
3. เชื่อม state และ delivery ที่มีข้อกำหนดครบ ใช้กลไกเดิมสำหรับทอย/ต่อสู้
4. เพิ่มเครื่องมือ DM บันทึกเหตุจริงและเปิด lethal variant ชัดเจน ไม่ทำให้ทอยพลาดฆ่าคนอัตโนมัติ
5. ทดสอบเส้นทางและ save/resume พร้อมตรวจข้อมูลไม่รั่ว แล้วสรุปไฟล์และข้อค้าง

## Needs Rules Decision

- นิยาม controlled หลังหยุดแกนเดียวกัน, วิธี sealed/departed และการฟื้นร่างหลัง D4
- Critical Fail และ HP0 ที่ทำให้ผู้เล่นตาย: Core ระบุ HP0 ไม่ตายทันที จึงไม่เพิ่ม death rule
- เกณฑ์หลักฐานเพียงพอและการเปิดเผยจริง: ให้ DM ยืนยันเหตุที่เกิดจริง ไม่อนุมานจาก collected
- การปลด tether รายคนและผลของ stopped ต่อสายทั้งหมด: ไม่ให้ปุ่มปลดสำเร็จฟรี ไม่มีตัวเลขใหม่
- Editorial props ของ C5 ยังรออนุมัติ ไม่สร้างเอกสารที่ไม่มีแหล่ง

## Proposed Improvement (v5.2 ยังไม่อนุมัติ)

ไม่ย้ายเป็น hostage record แบบใหม่ ไม่เพิ่ม met_but_no_conversation ไม่แต่ง recovery/โบนัส/penalty เสนอการแปลง save และ invariant ของ tether แยกในรายงานส่งมอบ
